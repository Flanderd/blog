# 财务管理

> **一句话概括**：财务管理研究企业"钱从哪来、钱往哪投、赚了怎么分"。它不讲会计做账，讲的是**决策**——每一个决策都要回答同一个问题：这笔钱花出去，能不能给股东创造超过其风险应得的回报。

## 这门课的主线

财务管理的全部内容，可以压缩成一张图：

```
                  ┌── 投资决策（钱投到哪）：资本预算、证券估值
  企业价值 = f(   ├── 融资决策（钱从哪来）：资本成本、资本结构、融资方式
                  ├── 股利决策（赚了怎么分）：股利政策、股票回购
                  └── 营运资本（日常怎么转）：现金、应收、存货
                 )
```

四个决策互相牵制：

- 投资项目的风险决定**资本成本**（第七章）；
- 资本成本又是投资决策的**折现率**（第六章），形成闭环；
- 融资方式改变**杠杆**，杠杆放大风险，又反过来推高资本成本（第八章）；
- 赚到的现金是分红还是再投资，取决于有没有**净现值为正的项目**（第九章）。

一条贯穿全书的铁律：**风险与收益对等**。天下没有"高收益低风险"的项目，如果有，要么是风险没被识别，要么是有人在骗你。

## 学习路径

1. **打地基（1–3 章）**：先弄清"财务管什么"，再把货币时间价值练到条件反射。第三章的六个系数公式，后面每一章都会用到。
2. **估值与决策（4–7 章）**：风险定价 → 证券估值 → 项目决策 → 资本成本。这四章是一条完整链路，建议连着学。
3. **结构（8–9 章）**：杠杆与股利回答"钱怎么来、怎么分"，理论性最强，考题也最集中。
4. **运营（10–11 章）**：营运资本与融资方式，偏实务，计算不难但细节多。
5. **综合（12–13 章）**：预测与估值，把前面所有工具串起来用一次。

## 符号约定

| 符号 | 含义 |
| --- | --- |
| $PV,\ FV$ | 现值、终值 |
| $i$ 或 $r$ | 利率 / 折现率 / 必要报酬率 |
| $n$ | 期数 |
| $A$ | 年金（每期等额现金流） |
| $E(R)$ | 期望收益率 |
| $\sigma$ | 标准差；$\sigma^2$ 方差 |
| $\beta$ | 系统风险系数 |
| $R_f,\ R_m$ | 无风险利率、市场组合收益率 |
| $K_d,\ K_e,\ K_p$ | 债务、普通股、优先股资本成本 |
| $WACC$ | 加权平均资本成本 |
| $T$ | 所得税税率 |
| $NPV,\ IRR$ | 净现值、内含报酬率 |
| $EBIT$ | 息税前利润 |
| $D_1,\ P_0$ | 下期股利、当前股价 |
| $g$ | 增长率 |

::: tip 三个学习建议
1. **画时间轴**。凡是涉及多期现金流，先在纸上画一条轴，标清每笔钱发生在第几期，错误率会下降一半。
2. **分清"时点"与"期间"**。年金是期末还是期初、股利是 $D_0$ 还是 $D_1$，这两处是考试失分重灾区。
3. **每算完一个指标，问一句"这个数说明什么"**。财务管理考的不是算术，是解释能力。
:::
