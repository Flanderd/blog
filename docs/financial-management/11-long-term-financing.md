# 第十一章 长期融资

> **本章定位**：前十章一直在算"这笔钱该不该花"，这一章转向"这笔钱从哪来"。长期融资是一张菜单：股权、债务、混合证券、租赁。每一项都标着三个价签——**稀释多少控制权、抬高多少财务风险、暴露多少信息**。融资决策的本质是在这三个价签之间做取舍，而不是找一个"最便宜"的选项。

## 11.1 融资决策的全景图

### 11.1.1 四类工具

企业拿到长期资金只有两条路：**权益**（出让所有权）与**债务**（承诺还本付息）。介于两者之间的是**混合证券**，租赁则是"以租代买"，本质为有抵押的分期付款。

| 工具 | 性质 | 资金成本 | 控制权 | 还本压力 | 典型使用者 |
| --- | --- | --- | --- | --- | --- |
| 留存收益 | 内源权益 | 机会成本（≈$K_e$） | 无影响 | 无 | 所有盈利企业 |
| 银行贷款 | 债务 | 最低（有抵押） | 无 | 刚性 | 中小企业 |
| 公司债券 | 债务 | 较低 | 无 | 刚性 | 大型、有评级企业 |
| 可转换债券 | 混合 | 票面极低，实际不低 | 潜在稀释 | 较软 | 高成长、股价波动大 |
| 融资租赁 | 债务替代 | 接近担保贷款 | 无 | 刚性 | 重资产、缺抵押物 |
| 优先股 | 混合 | 高于债务 | 通常无表决权 | 可累积、可递延 | 杠杆已高、不愿稀释普通股 |
| IPO / 增发 | 权益 | 最高 | 稀释 | 无 | 成长期、VC 退出 |

### 11.1.2 选择的四个维度

**控制权**。发新股会稀释持股比例与表决权。持股 51% 的创始人增发 30% 新股后降到 39%，失去绝对控股。

**财务风险**。利息与本金是刚性义务，经营下滑时会把企业推向违约；权益没有到期日，亏损只是股价下跌。

**信息不对称**。管理层比外部投资者更了解企业真实价值，股价被低估时发新股等于"贱卖"老股东。投资者也知道这一点，于是把增发公告读成"管理层认为股价偏高"，股价应声下跌——这就是**逆向选择**。

**市场时机**。牛市发行同样的股份能募到更多钱，熊市可能直接发不出去。

::: tip 工具要匹配现金流的形态
现金流稳定的高速公路公司应多用债务：利息能抵税，股东不必被稀释。还在烧钱研发的创新药企只能用股权：它没有稳定的息税前利润去覆盖利息。**没有最优工具，只有最合适的工具。**
:::

## 11.2 股权融资

### 11.2.1 IPO 的动机与代价

| 收益 | 代价 |
| --- | --- |
| 募集大额长期资金 | **股权稀释**：发 25% 新股，原股东所有权降至 75% |
| 为 VC 与创始人提供退出通道 | **披露成本**：年报、公告、审计、投资者关系，一年数百万至数千万 |
| 提升知名度与银行授信 | **商业机密外泄**：毛利率、客户结构、研发管线全部公开 |
| 后续增发、发债、股权质押更便利 | **短期业绩压力**：为不 miss 预期而砍研发、压账期、推迟资本开支 |
| 股权激励有了市价基准 | **控制权受限**：重大事项需董事会/股东大会，决策变慢，还可能被敌意收购 |

最后一项代价最隐蔽：**长期价值让位于短期报表**，这是上市公司最典型的代理成本。

### 11.2.2 发行流程要点

1. **改制与辅导**：有限公司改股份公司，清理历史沿革、关联交易、资金占用；
2. **申报与受理**：提交招股说明书，信息披露的真实性是生命线；
3. **审核问询**：多轮问询，重点在收入确认、毛利率异常、关联方；
4. **注册与路演询价**：向机构推介，通过累计投标确定发行价；
5. **发行上市**：网上网下申购，挂牌交易。

**定价是核心**：定高了发不出去，定低了老股东吃亏（"IPO 折价"现象）。发行价本质是承销商、发行人与机构投资者三方博弈的结果。

### 11.2.3 配股：向老股东要钱

**配股**是按现有持股比例、以低于市价的价格向老股东发行新股。老股东可以参与，也可以把**配股权**卖掉。因为发行价低于市价，配股后股价要"除权"：

$$
P_{ex}=\frac{P_0+r\cdot S}{1+r}
$$

$P_0$ 为配股前市价，$S$ 为配股价，$r$ 为**配股比例**（配股数 ÷ 原股数，10 配 3 即 0.3）。

**推导**：配股前总市值 $P_0N_0$，配股收现 $S\cdot rN_0$，配股后总股数 $N_0(1+r)$，两者相加除以总股数即除权价。**配股不创造价值，只是把股价切开**。

老股东的补偿是**配股权价值**：

$$
\text{每股原股含权价值}=P_0-P_{ex},\qquad \text{每份配股权价值}=P_{ex}-S
$$

不参与配股者财富正好损失 $P_0-P_{ex}$，卖出配股权即可等额收回。所谓"配股损害老股东"，前提是他连配股权也放弃了。

### 11.2.4 增发与定向增发

| | 公开增发 | 定向增发 |
| --- | --- | --- |
| 发行对象 | 不特定公众 | 不超过 35 名特定投资者 |
| 价格 | 接近市价 | 通常折价 10%–30% |
| 锁定期 | 无 | 6–18 个月 |
| 审核 | 较严，易发行失败 | 相对灵活 |
| 常见用途 | 项目融资 | 引入战投、整体上市、并购配套融资 |

折价的合理性在于**流动性补偿**：锁定期内不能卖出，投资者承担了股价下跌风险，需要折价弥补。

### 11.2.5 发行成本

股权发行成本（承销、律师、审计、路演）通常占募资额 3%–8%，远高于债券的 1%–2%。它有两层影响。

**募资额打折**：想净得 $N$ 元，成本率 $f$，必须发行 $N/(1-f)$。

**资本成本抬升**：

$$
K_e=\frac{D_1}{P_0(1-f)}+g
$$

直觉是：企业卖出一股只收到 $P_0(1-f)$，却要按 $P_0$ 的水平付股利，实际收益率自然更高。

## 11.3 债务融资

### 11.3.1 银行贷款

银行的核心手段不是利率，而是**条件**：

| 手段 | 内容 |
| --- | --- |
| 抵押 | 厂房、土地、设备、存货、应收账款；有抵押则利率明显更低 |
| 担保 | 母公司担保、关联方互保、担保公司；互保链条在经济下行时会连锁爆雷 |
| 否定性条款 | 不得新增有息负债、分红不超过净利润 30%、不得处置核心资产 |
| 肯定性条款 | 流动比率 ≥ 1.5、资产负债率 ≤ 60%、按期报送报表 |
| 加速到期 | 违反任一约定，全部贷款立即到期 |

条款越严，利率越低，经营灵活性越差。**这是一笔明码标价的交易**。

### 11.3.2 公司债券

**公司债券**是向社会发行的长期债务凭证，期限 3–10 年，投资者分散、可二级市场交易、发行门槛高于贷款。

**发行条件**（实务要点）：净资产达到规定规模、最近三年可分配利润足以覆盖债券一年利息、累计债券余额不超过净资产的一定比例、信用评级达标。

**评级决定利差**，利差决定利率：

$$
K_d=R_f+\text{信用利差}
$$

5 年期国债 2.8%、AA 级利差 1.5%，则发行利率约 4.3%。评级下调一档，利差可能扩大 80–150 个基点——**评级是有商业价值的资产**。

::: warning 票面利率 ≠ 资金成本
票面利率只是付息比例。真实成本还要考虑发行折价、发行费用与税盾，进入 WACC 的是税后债务成本 $K_d(1-T)$。
:::

### 11.3.3 可转换债券

**可转债**是"债券 + 看涨期权"：持有人可按约定价格把债券换成股票。三个核心概念：

$$
\text{转换比率}=\frac{\text{面值}}{\text{转股价}},\qquad
\text{转换价值}=\text{转换比率}\times\text{股价}
$$

$$
\text{转换平价}=\frac{\text{转债市价}}{\text{转换比率}}
$$

转换平价高于股价，转股不划算，持有人继续持债；低于股价，转股有利，转债价格跟随股价上涨。转债价格还有**下限**：不低于**纯债价值**（不转股、只拿本息的现值）。于是收益结构"下有债底、上不封顶"，票面利率才能低到 1% 甚至 0.5%。

**稀释**要两面算：转股增加股本摊薄 EPS，同时省下利息。净效应见例题 2。

国内转债常附三个条款：**向下修正**（股价长期低于转股价一定幅度，可下调转股价促转股）、**回售**（股价长期低迷，持有人可把债券卖回公司）、**强制赎回**（股价连续高于转股价 130%，公司可按面值加利息赎回，逼持有人转股）。

### 11.3.4 可分离交易可转债

把"债"与"权"拆开：买一张债券，同时免费获得若干份**认股权证**，两者分别上市交易。债券按纯债定价，权证单独定价，所以票息可以极低。

| | 普通可转债 | 可分离交易可转债 |
| --- | --- | --- |
| 债与权 | 绑定，转股后债券消失 | 分离，行权后债券仍在 |
| 行权 | 换股，不需额外付钱 | 需另掏现金认购新股 |
| 到期 | 转股后不用还本 | **仍要还本** |

最后一条是关键：**可分离转债只降低利息负担，不解决本金负担**。

## 11.4 混合证券：优先股

| 特征 | 说明 |
| --- | --- |
| 股利 | 通常固定，**税后支付，不能抵税** |
| 清偿顺序 | 债权人之后、普通股股东之前 |
| 表决权 | 一般无，除涉及优先股权益的重大事项 |
| 累积性 | 多数为累积优先股，欠付股利累积至以后年度 |
| 赎回 | 常设发行人赎回条款 |

$$
K_p=\frac{D_p}{P_0(1-f)}
$$

分子不乘 $(1-T)$——股利不能税前扣除，这是优先股比债务"贵"的根本原因。

**适用场景**：①负债率已高，再借债会触发契约或降级，又不愿稀释普通股；②银行、保险等受资本充足率监管的机构，优先股可计入其他一级资本；③并购中作为不稀释表决权的对价工具；④创始人想保留控制权又需引入资金。

::: tip 一个工具，三种身份
对发行方它是权益（不增负债率、不强制还本），对投资者它像债（固定收益、优先受偿），会计上归权益、税务上不能抵税、监管上可能计入资本。**同一工具在三套规则里身份不同**，这正是它被广泛使用的原因。
:::

## 11.5 租赁融资

### 11.5.1 判定标准：看实质不看名称

唯一标准是：**与资产所有权有关的风险和报酬是否实质转移**。

| 迹象 | 指向融资租赁 |
| --- | --- |
| 租期占资产使用寿命的大部分（通常 ≥ 75%） | 是 |
| 租金现值几乎等于公允价值（通常 ≥ 90%） | 是 |
| 租期结束所有权转移，或承租人有低价购买权 | 是 |
| 资产专用性强，只有承租人能用 | 是 |
| 承租人承担维修、保险、余值风险 | 是 |

满足一条或多条实质特征，即使合同叫"租赁"，会计与税务上也应按融资租赁处理。

**经营租赁**：租期短、可撤销、出租人承担余值风险，本质是买服务（短期租车、租会议场地）。

**融资租赁**：本质是分期付款购买，出租人只提供融资，不承担资产风险。

### 11.5.2 会计与税务影响

| | 经营租赁 | 融资租赁 |
| --- | --- | --- |
| 资产负债表 | 不入表，仅披露 | 确认使用权资产与租赁负债 |
| 利润表 | 租金全额计入费用 | 折旧 + 利息费用 |
| 税前扣除 | 租金全额扣除 | 折旧与利息分别扣除 |
| 负债率 | 表外，指标好看 | 表内，负债率上升 |

融资租赁费用前高后低（利息按余额递减），经营租赁租金各期均匀。**总扣除金额通常相同，差别只在时间分布**——这是租赁决策的核心。

### 11.5.3 租赁决策：增量现金流法

问题不是"租还是租"，而是"**租，还是借钱买**"。先假定企业已决定使用该资产，只比较取得方式的现金流差异。以"租赁相对购买"为口径：

- $t=0$：不买设备，省下购置成本 $C$（流入）；
- $t=1\ldots n$：支付租金 $L$，税后 $L(1-T)$（流出）；
- $t=1\ldots n$：不能提折旧，失去抵税 $D\cdot T$（流出）；
- 期末：失去残值（流出，若有）。

$$
NPV_{\text{租}}=C-\sum_{t=1}^{n}\frac{L(1-T)+D\cdot T}{\left[k_d(1-T)\right]^{t}}
$$

**折现率为什么是税后债务成本**？租赁现金流（固定租金、刚性支付）的风险与担保债务相当：用 WACC 会高估风险、低估租赁价值；用税前债务成本会高估折现率。**$k_d(1-T)$ 才是与现金流风险匹配的那一个**。

判据：$NPV>0$ 租，$<0$ 买。也可反解"租金临界值"，报价高于它就不该租。

## 11.6 融资顺序与发行方式选择

### 11.6.1 优序融资理论

Myers（1984）用**逆向选择**解释融资偏好：

1. **内源融资**（留存收益）：不需向任何人解释，无发行成本；
2. **债务**：信息敏感度低，投资者不太担心被"高估的股权"坑到；
3. **可转债等混合证券**：介于两者之间；
4. **股权**：信息敏感度最高，发行公告常被读作负面信号。

这解释了实证之谜：**盈利能力越强的企业负债率反而越低**——它按优序自然不需要借钱。这与权衡理论（追求最优负债率）的预测相反。

**实务顺序**：内部积累 → 银行借款 → 债券 → 可转债 → 定向增发 → 公开增发/配股。

### 11.6.2 影响因素

| 因素 | 倾向债务 | 倾向股权 |
| --- | --- | --- |
| 控制权 | 不愿稀释 | 愿意引入新股东 |
| 财务风险 | 现金流稳定、负债率低 | 现金流波动、负债率已高 |
| 信息不对称 | 股价被低估（不愿贱卖） | 股价被高估（趁机发行） |
| 市场时机 | 利率低位 | 股市估值高位 |
| 资产结构 | 有形资产多，可抵押 | 无形资产多，难抵押 |
| 成长阶段 | 成熟期、现金流充沛 | 成长期、投入大、利润薄 |

### 11.6.3 定稿前的五个问题

1. 这笔钱的用途能产生稳定现金流吗？能则债务可行，否则用股权。
2. 负债率离契约红线还有多远？余量不足优先股权。
3. 大股东愿意稀释到多少？设持股底线，倒推可发行股数。
4. 当前股价与利率处于历史什么位置？这是时机判断，不是价值判断。
5. 发行失败有没有备选方案？**永远准备 Plan B**。

## 11.7 典型例题

### 例题 1（配股除权价与配股权价值）

> 某公司配股前总股本 1 亿股，股价 12 元。方案为每 2 股配 1 股，配股价 6 元。求：除权价、每份配股权价值、募资总额；若某股东持 1000 股且不参与配股，其财富损失多少？

**解**：

配股比例 $r=0.5$。

$$
P_{ex}=\frac{12+0.5\times6}{1+0.5}=\frac{15}{1.5}=10\ \text{元}
$$

每份配股权（可认购 1 股）价值 $=P_{ex}-S=10-6=4$ 元。每 2 股含 1 份权，故每股原股含权 $4/2=2$ 元，与 $P_0-P_{ex}=12-10=2$ 元一致。

配股数 $=1\times0.5=0.5$ 亿股，募资 $=0.5\times6=3$ 亿元。

**校验**：配股前市值 12 亿 + 新投入 3 亿 = 15 亿；配股后 1.5 亿股 × 10 元 = 15 亿。价值守恒。

该股东持 1000 股，市值由 $1000\times12=12000$ 元降为 $1000\times10=10000$ 元，损失 2000 元。他本可获得 500 份配股权，按 4 元卖出正好得 2000 元——**补偿是完整的，前提是他处置了配股权**。

### 例题 2（可转债的转换价值与稀释）

> 某公司发行 10 亿元可转债，面值 100 元，票面利率 2%，转股价 20 元。当前股价 24 元，转债市价 126 元，纯债价值 88 元。原股本 2 亿股，上年净利润 4 亿元，税率 25%。求转换比率、转换价值、转换平价与溢价率；全部转股后的 EPS。

**解**：

$$
\text{转换比率}=\frac{100}{20}=5\ \text{股/张},\qquad \text{转换价值}=5\times24=120\ \text{元}
$$

$$
\text{转换平价}=\frac{126}{5}=25.2\ \text{元},\qquad \text{溢价率}=\frac{126}{120}-1=5\%
$$

转换平价 25.2 元 > 股价 24 元，此刻转股不划算（相当于花 25.2 元买 24 元的股票）。126 元中 120 元是转股价值，高出 6 元的部分是转换溢价（内含期权价值）；下方 88 元的纯债价值则构成价格下限。

转股数 $=10/20=5000$ 万股，转股后股本 $2+0.5=2.5$ 亿股。不转股 $EPS=4/2=2.00$ 元。

全部转股后省利息 $10\times2\%=0.2$ 亿元，税后增利 $0.2\times0.75=0.15$ 亿元：

$$
EPS=\frac{4+0.15}{2.5}=1.66\ \text{元}
$$

EPS 由 2.00 降至 1.66，稀释 17%，小于股本扩张的 25%——利息节省抵消了一部分。原股东持股由 100% 降至 80%。

### 例题 3（租赁决策 NPV）

> 某设备购置价 100 万元，5 年直线折旧、残值为 0；也可租 5 年，每年年末付租金 24 万元。税率 25%，税前借款利率 8%。租还是买？

**解**：

税后折现率 $=8\%\times(1-25\%)=6\%$。年折旧 $100/5=20$ 万元，抵税 $20\times25\%=5$ 万元。

增量现金流：$t=0$ 省下购置支出 $+100$；$t=1\sim5$ 租金税后 $-24\times0.75=-18$，失去折旧抵税 $-5$，合计 $-23$。

$$
PVIFA(6\%,5)=\frac{1-1.06^{-5}}{0.06}=\frac{1-0.7473}{0.06}=4.2124
$$

$$
NPV_{\text{租}}=100-23\times4.2124=100-96.88=3.12\ \text{万元}>0
$$

**应租赁**。

**临界租金**：令 $100-(0.75L+5)\times4.2124=0$，得 $0.75L=18.74$，$L=24.99$ 万元。当前 24 万元低于临界值；若出租方报价超过约 25 万元，应改为借款购买。

**交叉校验**：租赁隐含成本满足 $PVIFA(r,5)=100/23=4.3478$，试算 $r\approx4.85\%$，低于税后债务成本 6%，结论一致。

### 例题 4（发行成本的影响）

> 某公司股价 20 元，下年每股股利 1.2 元，增长率 5%，股权发行费率 5%。（1）净募 10 亿元需发行多少？（2）发行新股资本成本多少？（3）项目投资 10 亿元，其中股权 6 亿、债务 4 亿，项目本身 NPV 为 0.8 亿元，考虑发行成本后是否仍可投？

**解**：

（1）发行额 $=10/(1-5\%)=10.5263$ 亿元，成本 $=0.5263$ 亿元。

（2）不考虑发行成本 $K_e=1.2/20+5\%=11.00\%$；考虑后：

$$
K_e'=\frac{1.2}{20\times0.95}+5\%=\frac{1.2}{19}+5\%=6.32\%+5\%=11.32\%
$$

升 0.32 个百分点。若权益占 60%，WACC 升 $0.6\times0.32\%\approx0.19$ 个百分点。

（3）股权需净得 6 亿元，实际发行 $6/0.95=6.3158$ 亿元，多出 0.3158 亿元属发行费用，应计入初始投资：

$$
NPV=0.8-0.3158=0.4842\ \text{亿元}
$$

仍大于 0，可以投资，但安全边际缩水 40%。

### 例题 5（融资方案比较：EBIT-EPS）

> 某公司股本 1 亿股，需融资 5 亿元。方案 A：增发 5000 万股，价 10 元；方案 B：发债 5 亿元，利率 7%。税率 25%，预计 EBIT 1.2 亿元。求两方案 EPS、无差别点 EBIT；若 EBIT 下滑 30%，EPS 各变化多少？

**解**：

B 方案年利息 $5\times7\%=0.35$ 亿元。

$$
EPS_A=\frac{1.2\times0.75}{1.5}=0.60\ \text{元},\qquad
EPS_B=\frac{(1.2-0.35)\times0.75}{1}=0.6375\ \text{元}
$$

无差别点：

$$
\frac{EBIT\times0.75}{1.5}=\frac{(EBIT-0.35)\times0.75}{1}\ \Rightarrow\ \frac{EBIT}{1.5}=EBIT-0.35
$$

$$
0.5EBIT=0.525\ \Rightarrow\ EBIT^{*}=1.05\ \text{亿元}
$$

**校验**：EBIT = 1.05 时 $EPS_A=0.7875/1.5=0.525$，$EPS_B=0.7\times0.75=0.525$，相等。

EBIT 降至 0.84 亿元：$EPS_A=0.84\times0.75/1.5=0.42$（−30%），$EPS_B=(0.84-0.35)\times0.75=0.3675$（−42.4%）。

**结论**：债务在好年景放大收益、差年景放大损失。EBIT 每变动 1%，B 的 EPS 变动 $1.2/(1.2-0.35)=1.41\%$。选哪个取决于企业对盈利波动的承受力，而非单一情景下的 EPS。

### 例题 6（可分离转债的价值拆分）

> 某公司发行 5 年期可分离转债，面值 100 元，票面利率 1%，年付息、到期还本，每张附送 20 份认股权证，行权价 10 元。同评级纯债利率 6%，股价 11 元。求纯债价值、权证总价值与每份价值、权证内在价值与时间价值。

**解**：

$$
PV_{\text{债}}=1\times PVIFA(6\%,5)+100\times PVIF(6\%,5)=4.21+74.73=78.94\ \text{元}
$$

权证总价值 $=100-78.94=21.06$ 元，每份 $=21.06/20=1.05$ 元。

内在价值 $=\max(11-10,\ 0)=1.00$ 元，时间价值 $=1.05-1.00=0.05$ 元。

**解读**：票面利率仅 1%（市场 6%），投资者买的是权证。对发行人，期间利息支出被压到极低；代价是到期仍要还本 5 亿元，且行权会带来新的股权稀释。**它降低利息负担，不降低本金负担。**

## 11.8 常见易错点

::: warning 八条高频错误
1. **配股除权价漏掉配股比例**。写成 $(P_0+S)/2$，或把 $r$ 当成配股数。$r$ 必须是"配股数 ÷ 原股数"，10 配 3 就是 0.3。
2. **转换价值算反**。是"转换比率 × 股价"，不是"转股价 × 股数"；转股价只出现在转换比率的分母。
3. **转换价值与转换平价混用**。前者是"这张债值多少钱"（元），后者是"相当于每股多少钱"（元/股）。
4. **租赁折现率用错**。用 WACC 会低估租赁价值，用税前债务成本会高估折现率。正确是**税后债务成本**。
5. **租赁现金流漏掉折旧抵税**。租设备就不能提折旧，"失去的抵税"是实实在在的机会成本。
6. **融资租赁只看合同名称**。判定看风险与报酬是否实质转移，叫"服务协议"也可能构成租赁。
7. **发行成本只当费用**。它同时抬高 $K_e$ 并减少净募资额，两处都要算。
8. **优序融资顺序记反**。是"内源 → 债务 → 混合 → 股权"。股权在投资者眼里信息风险最高，所以排最后。
:::

## 11.9 本章要点总结

::: tip 一页纸回顾
- **四类工具**：股权（稀释、无还本压力）、债务（税盾、刚性）、混合（优先股、可转债）、租赁（有抵押的分期付款）。
- **IPO**：收益是募资、退出、声誉、再融资便利；代价是稀释、披露成本、短期业绩压力、控制权受限。
- **配股**：$P_{ex}=(P_0+rS)/(1+r)$，老股东补偿为 $P_0-P_{ex}$，可卖出配股权兑现。
- **可转债三价**：转换比率 = 面值/转股价；转换价值 = 比率 × 股价；转换平价 = 转债价/比率。下有债底、上随股价。
- **可分离转债**：债与权分开交易，票息极低，但到期仍要还本。
- **优先股**：股利税后支付、不能抵税，$K_p=D_p/[P_0(1-f)]$，适合"不加杠杆又不稀释表决权"。
- **租赁判定看实质**：租期占比、租金现值占比、所有权转移、购买选择权。融资租赁入表，短期经营租赁费用化。
- **租赁决策**：$NPV=C-\sum[L(1-T)+DT]/[k_d(1-T)]^t$，折现率用**税后债务成本**。
- **优序融资**：内源 → 债务 → 可转债 → 股权，根源是信息不对称下的逆向选择。
- **一条主线**：融资方式的选择，是在控制权、财务风险、信息成本三者之间定价。
:::

## 11.10 习题

**一、概念题**

1. 列举 IPO 的四项主要代价，哪一项最难量化？
2. 配股、公开增发、定向增发在发行对象、定价、锁定期上有何区别？
3. 说明经营租赁与融资租赁的判定标准，会计上为什么要区分？

**二、辨析题**

4. 判断对错并说明理由：
   （1）配股会损害不参与配股的老股东利益；
   （2）可转债票面利率低，所以资金成本一定低于普通债券；
   （3）融资租赁的租金可以全额税前扣除，所以比借款购买更节税。

**三、计算题**

5. 某公司配股前股价 10 元，总股本 2 亿股，每 10 股配 2 股，配股价 7 元。求除权价、每份配股权价值、募资总额。
6. 某可转债面值 100 元，转股价 12.5 元，股价 14 元，转债价 118 元。求转换比率、转换价值、转换平价与溢价率。
7. 某设备 80 万元，5 年直线折旧、无残值；每年末租金 19 万元；税率 25%，税前借款利率 8%。判断租还是买。
8. 某公司需净募 8 亿元，股权费率 4%。求发行总额与成本；若股价 16 元、下年股利 0.96 元、增长率 4%，求 $K_e$。
9. 某优先股年股利 8 元，发行价 100 元，费率 3%。求资本成本，并解释为何高于同利率债券。

**四、应用题**

10. 一家光伏组件企业处扩产期，资产负债率 68%，股价处历史高位，银行授信已用八成。请为 20 亿元扩产项目设计融资方案并说明理由。

::: details 参考答案
1. 稀释、披露成本、短期业绩压力、控制权受限。**短期业绩压力最难量化**，它表现为"没有发生的长期投资"，无法直接观测。

2. 配股：面向全体老股东、按持股比例、价格显著低于市价、无锁定期。公开增发：面向不特定公众、接近市价、无锁定期。定向增发：面向不超过 35 名特定投资者、通常折价、锁定期 6–18 个月。

3. 标准是风险与报酬是否实质转移，迹象包括租期占寿命大部分、租金现值接近公允价值、所有权转移、低价购买权、资产专用性。区分原因：融资租赁实质是分期购买，须确认资产与负债，费用为折旧加利息；经营租赁是购买服务，租金直接费用化。不区分会造成表外融资、隐瞒真实杠杆。

4. （1）**错**。除权价下降幅度正好等于配股权价值，不参与者可卖出配股权获得补偿；只有连配股权一起放弃才受损。
   （2）**错**。低票息是因为含了期权价值，投资者总回报 = 利息 + 期权收益；若股价大涨触发转股，发行人实际成本可能高于普通债。
   （3）**错**。融资租赁租金通常不能全额扣除（税务按折旧加利息），且总额与借款购买一致，差别只在时间分布。

5. $r=0.2$，$P_{ex}=(10+0.2\times7)/1.2=11.4/1.2=9.50$ 元；每份配股权 $9.50-7=2.50$ 元（每 5 股含 1 份，折每股 0.50 元，与 $10-9.50$ 一致）；配股 0.4 亿股，募资 $0.4\times7=2.8$ 亿元。

6. 转换比率 $=100/12.5=8$ 股；转换价值 $=8\times14=112$ 元；转换平价 $=118/8=14.75$ 元；溢价率 $=118/112-1=5.36\%$。

7. 税后折现率 6%，年折旧 16 万元、抵税 4 万元，年流出 $19\times0.75+4=18.25$ 万元。
   $NPV=80-18.25\times4.2124=80-76.88=3.12$ 万元 > 0，**应租赁**。临界租金 $80/4.2124=18.99$，$L=(18.99-4)/0.75=19.99$ 万元。

8. 发行总额 $=8/0.96=8.3333$ 亿元，成本 0.3333 亿元；$K_e=0.96/(16\times0.96)+4\%=6.25\%+4\%=10.25\%$（不考虑发行成本为 10.00%）。

9. $K_p=8/[100\times(1-3\%)]=8/97=8.25\%$。高于同利率债券，因为优先股股利**税后支付、不能抵税**；若债券利率 8%、税率 25%，税后成本仅 6%。

10. 以**股权为主、债务为辅**：①负债率 68% 已高，继续举债会触发契约条款与评级下调；②股价处高位，此时发股对老股东最划算，是难得的窗口；③扩产期现金流回收慢，与债务的刚性付息不匹配；④可用"定向增发 + 可转债"组合，定增引入产业资本锁定大部分资金，可转债以低票息补足并延迟稀释。风险提示：定增稀释控制权，需设大股东持股底线；若股价回落导致转股失败，须保留还本预案。
:::
