# 第四章 非流动资产

**本章主要内容**

- 无形资产
  - 无形资产取得
  - 无形资产摊销
  - 无形资产出售和报废
  - 无形资产减值
- 长期待摊费用
- 长期股权投资
  - 初始计量
  - 后续计量
    - 成本法
    - 权益法
- 投资性房地产
  - 初始计量
  - 后续计量
    - 成本模式
    - 公允价值模式
- 固定资产
  - 固定资产取得
  - 固定资产折旧
  - 固定资产发生的后续支出
  - 固定资产处置
    - 出售转让——资产处置损益
    - 报废清理——营业外收支
  - 固定资产清查
    - 盘盈
    - 盘亏
  - 固定资产减值

非流动资产，即流动资产以外的资产，是指不能在 1 年或者超过 1 年的一个营业周期内变现或耗用的资产，主要包括债权投资、其他债权投资、长期应收款、长期股权投资、投资性房地产、固定资产、在建工程、使用权资产、无形资产、开发支出、长期待摊费用、递延所得税资产、其他非流动资产等。
