# 第一章 概述

**本章主要内容**

- 会计概念、职能和目标：会计概念、会计职能、会计目标
- 会计基本假设和会计核算基础：会计基本假设、会计核算基础
- 会计信息质量要求：会计信息、会计信息质量要求
- 会计人员职业道德：会计职业及其特征、会计职业道德概述、会计职业道德相关规定
- 会计准则制度体系概述：企业会计准则体系概述、政府会计准则制度体系概述

经济越发展，会计越重要。在现代市场经济和现代企业制度环境下，会计在保护财产和产权安全、落实经管责任、有效配置经济资源、合理分配经济利益等方面发挥着越来越重要的作用。本章主要介绍会计的概念、会计职能和会计目标、会计的基本假设和核算基础、会计信息质量要求、会计职业道德和会计准则制度体系。
