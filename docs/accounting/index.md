## 《初级会计实务》内容结构

1. **会计基础**（第 1–2 章）：会计概念与职能、基本假设与核算基础、信息质量要求、职业道德、会计准则体系；会计要素与等式、科目与借贷记账法、凭证账簿、财产清查、账务处理程序、会计信息化。
2. **资产**（第 3–4 章）：货币资金、交易性金融资产、应收及预付款项、存货；长期股权投资、投资性房地产、固定资产、无形资产和长期待摊费用。
3. **负债与所有者权益**（第 5–6 章）：短期借款、应付及预收款项、应付职工薪酬、应交税费、非流动负债；实收资本、资本公积与其他综合收益、留存收益。
4. **收入费用利润与报告**（第 7–8 章）：收入、费用、利润；财务报告概述、资产负债表、利润表、现金流量表、所有者权益变动表、附注。
5. **成本与政府会计**（第 9–10 章）：成本核算概述、产品成本的归集和分配、产品成本计算方法；政府会计要素与核算模式、行政事业单位常见业务、政府决算报告和财务报告。

## 阅读约定

1. 每节以 `# 第X节 节名` 开头，层级 `## 一、` → `### （一）` → `#### 1.`；
2. **会计分录**统一为 `text` 代码块，保留科目全称、借贷层级与金额：

   ```text
   借：其他货币资金——银行汇票　250 000
     贷：银行存款　250 000
   ```

3. **例题**为 `::: info 【例4-12】` 提示框，框内含题干与账务处理；
4. 表格（资产负债表、利润表、成本计算表）为 Markdown 表格，跨页续表标注「（续表）」；
5. 每节末尾以 HTML 注释标注对应 PDF 页码。
