# 税法知识体系

> **一句话概括**：税法研究"对什么征税、谁来缴、缴多少、什么时候缴"。本知识库按中国税务师（CTA）考试科目组织——《税法一》偏流转税与资源环境税，《税法二》偏所得税与财产行为税，两者共同构成我国现行税制的主体框架；《涉税服务相关法律》则是税务执法的法律框架与涉税交易的民商法基础（行政法、民商法、刑事法三编）。

## 为什么分"税法一"和"税法二"

这是税务师考试的经典划分，背后有清晰的逻辑：

- **《税法一》**：以**货物和劳务税（流转税）**为主——增值税、消费税、关税，加上城市维护建设税、土地增值税、资源税、车辆购置税、环境保护税、烟叶税、社会保险费、非税收入。核心是**在生产、流通环节对交易额征税**。
- **《税法二》**：以**所得税**为主——企业所得税、个人所得税，加上国际税收、印花税、房产税、车船税、契税、城镇土地使用税、耕地占用税、船舶吨税。核心是**对所得额或财产持有/转让行为征税**。

记忆口诀：**"一"看流转（买东西收的税），"二"看所得（赚了钱收的税），"法律"看程序（谁有权、走什么程序、担什么责）。**

## 学习路径建议

**主线（重点掌握）**：

1. **先啃两块硬骨头——增值税（税法一）与企业所得税（税法二）**。这两个税种几乎占了考试分值的一半，也是理解其他税种的钥匙。
2. **消费税、关税、个人所得税**紧随其后，与增值税、企业所得税共同构成"四大主力税种"。
3. **土地增值税、国际税收**难度高、分值也不少，属于拉开差距的章节。
4. **其余小税种**（城建税、资源税、车辆购置税、环保税、印花税、房产税、契税、土地使用税、车船税等）记忆为主，性价比高，适合考前集中突破。

**每章内的阅读顺序**：

```
1. 概述（税种定位、立法依据）
   ↓
2. 纳税人 / 征税范围（对谁征、征什么）
   ↓
3. 税率 / 计税依据（怎么算的"量"和"率"）
   ↓
4. 税收优惠（减免情形）
   ↓
5. 应纳税额计算（把税率×计税依据落到实处）
   ↓
6. 征收管理（申报、缴纳、纳税期限）
```

::: tip 学习建议
1. **每个税种先画"四要素"表格**：纳税人、征税对象、税率、纳税环节。四个要素抓准，税额计算就不会偏。
2. **抓住"计税依据"这一核心**。增值税的销售额、所得税的应纳税所得额、关税的完税价格，是三个最容易出错的地方，务必对照例题手算。
3. **注意税种之间的衔接**。消费税是价内税、增值税是价外税；城建税依附于增值税和消费税；关税是进口环节增值税和消费税的计税基础。税种不是孤立的，是一张网。
4. **优惠要"记条件"**，不要只记"有优惠"。很多减免是有范围、有期限、有比例限制的。
:::

## 常用符号与术语约定

| 术语 | 含义 |
| --- | --- |
| 价内税 | 税款包含在价格中，如消费税 |
| 价外税 | 税款在价格之外单独列示，如增值税 |
| 从价计征 | 以金额为计税依据 |
| 从量计征 | 以数量（吨、辆、件）为计税依据 |
| 复合计征 | 既从价又从量，如卷烟、白酒 |
| 税基 | 计税依据，据以计算税额的基础 |
| 税率 | 应纳税额与计税依据的比例 |
