# 第十章 关税

**【本章导读】**

本章系统阐述我国关税税收制度。其核心要点涵盖纳税人与征税对象、税率体系、计税价格确定、应纳税额计算、税收优惠及征收管理等多个要素，主要内容包括：

1. 关税概念、特点与分类。关税是由海关依法对准许进出口的货物和进出境物品征收的税种，具有征收对象特定、单一环节价外税、涉外性强等特点。按征税对象分为进口关税和出口关税；按计税方式分为从价税、从量税和复合税；按征税性质分为普通关税、优惠关税和差别关税。

2. 纳税人与征税对象。进口货物的收货人、出口货物的发货人、进境物品的携带人或收件人是关税纳税人。从事跨境电子商务的企业等可作为扣缴义务人。征税对象为准许进出口的货物和进出境物品。

3. 税率体系及适用规则。进口关税设置最惠国税率、协定税率、特惠税率、普通税率、关税配额税率和暂定税率；出口关税设置出口税率和暂定税率。

4. 计税价格的确定。进口货物以成交价格为基础确定计税价格，需满足特定条件并调整相关费用。出口货物以成交价格及输出地点装载前相关费用为基础确定。

5. 应纳税额计算。关税采用从价计征、从量计征和复合计征三种计征方式。

6. 税收优惠政策。关税的优惠政策包括法定减免（无商业价值货样、国际无偿捐赠物资等）、专项优惠（科教用品等）以及保税货物、暂时进出境货物等特殊的关税征收规则。

7. 征收管理。关税的征收管理包括关税征收程序、缴纳期限、滞纳金征收、税收强制措施、税款追征与退还等规定。

8. 法律责任与权益保护。明确纳税人未履行义务的法律后果，以及通过行政复议和行政诉讼等途径保护纳税人合法权益的救济程序。

通过本章的学习，有助于了解关税的立法原则，全面熟悉关税计税价格如何确定，需要与增值税、消费税章节中进口环节税收政策有机联系。
