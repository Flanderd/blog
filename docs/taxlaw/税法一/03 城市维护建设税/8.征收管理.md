# 第八节 征收管理

城市维护建设税的纳税义务发生时间、纳税地点、纳税期限比照增值税、消费税的相应规定，城市维护建设税的纳税义务发生时间与“两税”的纳税义务发生时间一致，分别与“两税”同时缴纳。同时缴纳是指在缴纳“两税”时，应当在“两税”同一缴纳地点、同一缴纳期限内，一并缴纳对应的城市维护建设税。

采用委托代征、代扣代缴、代收代缴、预缴、补缴等方式缴纳“两税”的，应当同时缴纳城市维护建设税。代扣代缴，不含因境外单位和个人向境内销售服务、无形资产代扣代缴增值税情形。

对增值税免抵税额征收的城市维护建设税，纳税人应在税务机关核准免抵税额的下一个纳税申报期内向主管税务机关申报缴纳。
