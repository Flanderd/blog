# 第四章 城市维护建设税

**【本章导读】**

本章系统阐述我国城市维护建设税税收制度。其核心要点涵盖纳税人、征税范围、税率、计税依据等多个要素，主要内容包括：

1. 城市维护建设税纳税人。缴纳增值税、消费税的单位和个人为纳税人。

2. 城市维护建设税征税范围。城市市区、县城、镇及税法规定征收增值税、消费税的其他地区。

3. 城市维护建设税税率。实行地区差别比例税率。

4. 城市维护建设税税收优惠。原则上不单独规定减免税，财政部和国家税务总局针对特殊情况做出特别税收优惠规定。

5. 城市维护建设税计税依据。以依法实际缴纳的增值税、消费税税额为基础，加上增值税免抵税额，扣除直接减免的“两税”税额和期末留抵退税退还的增值税税额后的金额。不包括加收的滞纳金和罚款。

6. 城市维护建设税征收管理。纳税义务发生时间、纳税地点、纳税期限，比照增值税、消费税规定，与增值税、消费税同时缴纳。

本章学习时应厘清城市维护建设税与增值税、消费税的关系，采用关联分析方法掌握其以增值税、消费税税额为计税依据的核心逻辑；注意城市维护建设税征收管理与增值税、消费税的协同性，区分城市维护建设税在不同缴税方式（预缴、代扣代缴等）下的缴纳规定。
