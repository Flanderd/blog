# 第五章 土地增值税

**【本章导读】**

本章围绕土地增值税税制要素进行系统阐述，其核心要点涵盖土地增值税纳税人、征税范围、税率、税收优惠、计税依据、应纳税额计算、土地增值税清算和征收管理等多个要素，主要内容包括：

1. 土地增值税纳税人。土地增值税的纳税人具有“全范围覆盖”特性。转让国有土地使用权、地上建筑物及附着物并取得收入的单位和个人，均为纳税人。

2. 征税范围。土地增值税的征税范围应注意“三个核心前提”的严格限定。土地增值税采用“限定性征税”模式，需同时满足“国有土地”、“转让行为”和“取得收入”三个前提才征收土地增值税。即仅对国有土地使用权转让征税（集体土地需征用为国有后转让才征税）；仅对转让行为征税（出租、代建房、评估增值等未转移产权的行为不征税）；仅对有偿转让征税（继承、公益赠与等无偿转让不征税）。同时，对合作建房、房地产抵押等特殊情形明确征税界限，如“合作建房，自用暂免，转让征税”，抵押的房地产，“抵押期间不征，转让时征税”。

3. 税率。土地增值税采用四级超率累进税率，税率分别为 30%、40%、50% 和 60%，并配套速算扣除系数。土地增值率越高、税负越重。

4. 计税依据。土地增值税的计税依据核心是“增值额”，即转让房地产收入减除扣除项目金额后的余额。收入包括货币收入、实物收入和其他收入。

5. 扣除项目。土地增值税扣除项目需要分场景归集。新建房（房地产开发项目）的扣除项目包括土地款、开发成本、开发费用、相关税金及加计扣除（非房地产开发企业不得加计扣除）。旧房转让的扣除项目要分三种情况：能取得评估价格的，按“评估价格＋土地款＋税金”扣除；能提供购房发票的，按“发票金额逐年加计 5%＋税金”扣除；两者均无的，可实行核定征收。

6. 优惠政策适用规则。土地增值税税收优惠政策，如普通住宅增值额未超过扣除项目金额 20% 的免征，超过 20% 的，全部增值额均应计算纳税；国家建设征收房地产免征等，兼顾调控与民生。

7. 土地增值税清算。明确房地产开发项目需清算以及税务机关可以要求清算的条件、清算时间要求、清算时收入和扣除项目的确定、报送的资料、清算的受理、鉴证和审核等。

通过本章的学习，在全面掌握土地增值税现行政策的基础上，把握土地增值税与增值税的关系，精准判定土地增值税征税范围、扣除项目归集的标准以及土地增值税清算等相关政策。
