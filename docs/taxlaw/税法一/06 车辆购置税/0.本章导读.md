# 第七章 车辆购置税

**【本章导读】**

本章系统阐述我国车辆购置税税收制度。其核心要点涵盖纳税人、征税范围、税率、计税依据等多个要素，主要内容包括：

1. 车辆购置税纳税人。在我国境内购置汽车、有轨电车、汽车挂车、排气量超过 150 毫升摩托车的单位和个人是车辆购置税的纳税人。

2. 车辆购置税征税范围。车辆购置税是对纳税人购置车辆的行为征税，征税范围包括汽车、有轨电车、汽车挂车、排气量超过 150 毫升的摩托车。

3. 车辆购置税税率。车辆购置税实行固定比例税率 10%。

4. 车辆购置税税收优惠。具体包括法定减免税规定、其他减免税规定。

5. 车辆购置税计税依据。购买自用应税车辆按纳税人购买应税车辆实际支付给销售者的全部价款（不含增值税税款）计税；进口自用应税车辆按组成计税价格计税；其他方式自用应税车辆按同类应税车辆（车辆配置序列号相同）销售价格（不含增值税税款）或组成计税价格计税。

6. 车辆购置税征收管理。车辆购置税实行一车一申报制度。征税环节在车辆的最终消费环节。纳税义务发生时间为纳税人购置应税车辆的当日。

本章学习时掌握车辆购置税的各项税制要素，理解车辆购置税筹集交通专项资金、调节社会消费、引导产业发展的作用。
