# 第六章 资源税

**【本章导读】**

本章系统阐述我国资源税税收制度。其核心要点涵盖资源税纳税人、税目税率、税收优惠、计税依据与应纳税额计算、征收管理以及水资源税等多个维度，主要内容包括：

1. 资源税纳税人。在中华人民共和国领域和管辖的其他海域开发应税资源的单位和个人为资源税的纳税人。

2. 资源税税目和税率。资源税的税目采取正列举方式，涵盖能源矿产、金属矿产、非金属矿产、水气矿产和盐 5 个一级税目，共 164 个具体税目。税率形式包括比例税率和定额税率。

3. 资源税税收优惠。包括免征、减征及地方可决定的减免情形。例如，开采原油用于加热、煤炭企业安全生产抽采煤成气等免征资源税；从低丰度油气田、高含硫天然气、三次采油、深水油气田、稠油、高凝油、衰竭期矿山开采的矿产品享受不同比例减征；小规模纳税人等可享受减半征收优惠。

4. 资源税计税依据和应纳税额计算。资源税实行从价计征或从量计征。从价计征的计税依据为应税产品销售额，应纳税额按销售额乘以适用税率计算；从量计征的计税依据为销售数量，应纳税额按销售数量乘以单位税额计算。纳税人外购应税产品与自采产品混合销售或加工的，可按规定扣减外购应税产品的购进金额或数量。

5. 资源税征收管理。资源税的纳税义务发生时间分别为销售收讫款项当日和移送使用当日。纳税期限分为按月、按季或按次申报。纳税地点为矿产品开采地或海盐生产地。

6. 水资源税制度。水资源税针对取用地表水或地下水的单位和个人征收，实行从量计征，根据水资源状况、取用水类型和经济发展情况实行差别税额。

通过本章的学习，全面系统的把握我国对资源产品的税收政策，有助于了解资源税和水资源税在绿色税收体系中的重要地位。
