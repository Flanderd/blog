# 第九章 烟叶税

**【本章导读】**

本章系统阐述我国烟叶税税收制度。其核心要点涵盖纳税人、征税对象、税率、计税依据等多个要素，主要内容包括：

1. 烟叶税纳税人。在中华人民共和国境内收购烟叶的单位为烟叶税纳税人。
2. 烟叶税征税对象。征税对象为烟叶，具体包括烤烟叶和晾晒烟叶两类。
3. 烟叶税税率。烟叶税采用固定比例税率形式，税率为 20%。
4. 烟叶税计税依据。计税依据为收购烟叶实际支付的价款总额，由烟叶收购价款和价外补贴两部分构成。其中，价外补贴统一按烟叶收购价款的 10% 计算，即实际支付的价款总额 = 收购价款 ×（1 + 10%）。
5. 烟叶税应纳税额计算。应纳税额 = 实际支付的价款总额 × 税率。
6. 烟叶税征收管理。纳税人收购烟叶当天为纳税义务发生时间，向烟叶收购地的主管税务机关申报纳税。烟叶税按月计征。

本章学习时掌握纳税人、征税对象、税率、计税依据、税收征管等核心规定，有助于对特定农产品征税意义和立法原则的理解。
