# 第八章 环境保护税

**【本章导读】**

本章系统阐述我国环境保护税税收制度。其核心要点涵盖纳税人、征税对象、税目税率、税收优惠、计税依据及征收管理等多个要素，主要内容包括：

1. 纳税人与征税对象。环境保护税的纳税人是直接向环境排放应税污染物的企业事业单位和其他生产经营者。征税对象为大气污染物、水污染物、固体废物和噪声四类应税污染物。同时，法规明确规定了三种不属于直接向环境排放污染物的情形。

2. 税目与税率。环境保护税税目对应税污染物进行具体划分，大气污染物包括 44 种具体物质，水污染物区分第一类和其他类共 65 种，固体废物包括煤矸石、尾矿、危险废物等，噪声包括工业噪声。税率采用定额税率，其中大气和水污染物实行幅度定额税率，具体标准由各省确定；固体废物和噪声实行全国统一税额。

3. 税收优惠。制度规定了五类暂予免税的情形，包括农业生产排放、流动污染源排放、合规的城乡污水生活垃圾集中处理场所排放等。同时，纳税人排放应税大气或水污染物浓度值低于规定标准 30%和 50%的，分别享受减按 75%和 50%征税的优惠。

4. 计税依据与应纳税额计算。应税污染物的计税依据各不相同：大气污染物和水污染物按污染当量数确定，固体废物按排放量确定，噪声按超标分贝数确定。应纳税额的计算为污染当量数、排放量、超标分贝数分别乘以相应的适用税额。

5. 征收管理。环境保护税由税务机关征收管理，生态环境主管部门负责配合。纳税义务发生时间为排放应税污染物的当日，纳税地点为应税污染物排放地，税款按月计算，按季申报缴纳。

通过本章的学习，有助于了解环保税的立法原则，全面熟悉环境保护税现行政策。
