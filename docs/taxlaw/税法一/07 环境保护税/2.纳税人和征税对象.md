# 第二节 纳税人和征税对象

## 一、纳税人

环境保护税的纳税人是指在中华人民共和国领域和中华人民共和国管辖的其他海域，直接向环境排放应税污染物的企业事业单位和其他生产经营者。

依法设立的城乡污水集中处理、生活垃圾集中处理场所超过国家和地方规定的排放标准向环境排放应税污染物的，应当缴纳环境保护税。城乡污水集中处理场所，是指为社会公众提供生活污水处理服务的场所，不包括为工业园区、开发区等工业聚集区域内的企业事业单位和其他生产经营者提供污水处理服务的场所，以及企业事业单位和其他生产经营者自建自用的污水处理场所。

企业事业单位和其他生产经营者贮存或者处置固体废物不符合国家和地方环境保护标准的，应当缴纳环境保护税。

达到省级人民政府确定的规模标准并且有污染物排放口的畜禽养殖场，应当依法缴纳环境保护税。

::: tip 【提示】
环境保护税的纳税人遵循“直接排放”原则，只有直接向环境排放应税污染物的行为主体才可能构成纳税人。

不同情形环境保护税纳税人的身份判断见表 8-1。
:::

**表 8-1　环境保护税纳税人判断**

| 主体/行为 | 是否构成纳税人 | 关键条件与例外 |
| :--- | :--- | :--- |
| 一般企业 | 是 | 直接向环境排放应税污染物 |
| 个人/家庭 | 否 | 非“企业事业单位和其他生产经营者” |
| 政府机关 | 否 | 非“企业事业单位和其他生产经营者” |
| 城乡污水/垃圾集中处理场 | 有条件的是 | 超标排放则征税；符合标准则免税 |
| 工业园区污水处理厂 | 是 | 其排放直接视为工业企业排污 |
| 贮存处置固废 | 有条件的是 | 不符合环保标准则征税；符合标准则不征税 |
| 畜禽养殖场 | 有条件的是 | 规模达标且有排污口 |

## 二、征税对象

环境保护税的征税对象为纳税人直接向环境排放的应税污染物，是《环境保护税法》所附《环境保护税税目税额表》《应税污染物和当量值表》规定的大气污染物、水污染物、固体废物和噪声。

根据 2025 年 10 月 28 日第十四届全国人大常委会第十八次会议通过的《关于修改〈中华人民共和国环境保护税法〉的决定》，我国将正式启动对挥发性有机物（VOCs）征收环境保护税的试点工作。

## 三、不征税项目

有下列情形之一的，不属于直接向环境排放污染物，不缴纳相应污染物的环境保护税：

1. 企业事业单位和其他生产经营者向依法设立的污水集中处理、生活垃圾集中处理场所排放应税污染物的；

2. 企业事业单位和其他生产经营者在符合国家和地方环境保护标准的设施、场所贮存或者处置固体废物的；

3. 畜禽养殖场依法对畜禽养殖废弃物进行综合利用和无害化处理的。

::: tip 【提示】
不征税的核心原则在于阻断原则。这三种情形的共同点在于污染物没有“直接”进入环境，而是在一个受控的、合规的环节中被阻断、转移或转化了。环境治理鼓励这种行为，因此不予征税。
:::
