# 第一节 社会保险费概述

## 一、社会保险费的概念

社会保险，是指国家通过立法、多渠道筹集资金，保障公民在年老、疾病、工伤、失业、生育等减少收入时给予经济补偿，保证其能够享有基本生活保障的一项社会保障制度。我国的社会保险主要包括养老保险、医疗保险、工伤保险、失业保险、生育保险等险种。

社会保险包含于社会保障体系之中，是社会保障体系的核心内容，两者均由国家立法确定。社会保障一般包括社会保险、社会救济、社会福利、社会优抚和社会互助等多种保障政策。

社会保险费，是指在社会保险基金筹措过程中，参保单位、参保人员按照规定缴纳的社会保险资金，或者其他资金代参保个人缴纳的费用。

## 二、社会保险费费制要素

### （一）参保范围

社会保险的参保范围，是指根据国家法律、法规和有关政策规定，应当参加和可以参加社会保险的对象，包括参保单位和参保个人。

### （二）缴费人

缴费人是指按照国家法律法规和有关政策规定，负有缴纳社会保险费义务的单位和个人。社会保险费一般不得转嫁。

按照缴费群体分类，我国社会保险费缴费人可以分为单位缴费人和个人缴费人。其中，企业职工基本养老保险、机关事业单位工作人员基本养老保险、职工基本医疗保险和失业保险由用人单位和职工个人共同缴费，工伤保险、生育保险的缴费人是用人单位，职工个人不缴费；以个人身份参加基本养老保险、基本医疗保险的，个人为缴费人。

::: tip 【提示】
不同的社会保险费的缴费主体不同，有的险种的缴费主体由用人单位及其职工个人双方均按规定缴纳；有的险种由用人单位缴纳，职工个人不缴纳。
:::

### （三）缴费基数

缴费基数是计算应缴费额的依据。我国社会保险费的计算规则是以工资作为计费依据，分为个人缴费基数和单位缴费基数。一般而言，职工个人缴费基数原则上为本人上年度月平均工资，用人单位缴费基数根据险种与单位类型，采用本单位职工工资总额或职工个人缴费基数之和两个口径。职工伤害保障费缴费基数为平台企业上月总单量。

新招职工（含应届毕业生、再就业人员等）以起薪当月工资收入作为缴费工资基数。从第二年起，按上一年度实发工资的月平均工资作为缴费工资基数。

### （四）缴费比例

缴费比例，是指按照规定应缴纳的社会保险费占缴费基数的比例。

我国现行社会保险费率分为固定比例费率、浮动比例费率，大部分险种采用固定比例费率，工伤保险实行行业差别费率和浮动费率。试点实施的职业伤害保障费缴费基准额根据不同行业的职业伤害保障风险程度确定。

### （五）应缴费额

社会保险费应缴费额，是指缴费主体按照规定应承担的费用支出。不同险种的应缴费额计算方式存在一定差别，主要有三种方式。

1. 职工社会保险费应缴费额等于缴费基数乘以费率，属于定率计征。

2. 城乡居民基本养老保险费和城乡居民基本医疗保险均为定额缴费。其中，城乡居民基本养老保险的应缴费额为各地公布的缴费档次，城乡居民可以自主选择缴费档次；城乡居民基本医疗保险的应缴费额为各地每年公布的个人缴费标准，属于定额计征。

3. 职业伤害保障费的应缴费额为平台企业统筹地区上月总单量与省级社会保险经办机构确定的每单缴费标准之积。
