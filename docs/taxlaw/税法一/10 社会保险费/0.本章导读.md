# 第十一章 社会保险费

**【本章导读】**

本章围绕社会保险费的各个费种展开系统阐述，其核心要点涵盖各个社会保险费的参保范围、缴费人、缴费基数、缴费比例、应缴费额计算等多个要素，主要内容包括：

1. 社会保险费概述。社会保险是社会保障体系的核心，涵盖养老、医疗、工伤、失业、生育五大基本险种。社会保险费是社会保险基金的重要来源。社会保险费费制要素包括参保范围、缴费人、缴费基数、缴费比例和应缴费额，明确了社会保险费征收的核心依据和规则。

2. 基本养老保险费。基本养老保险可分为企业职工基本养老保险、机关事业单位工作人员基本养老保险、城乡居民基本养老保险三类，分别明确了不同群体的参保范围、缴费基数及缴费比例。

3. 基本医疗保险费与生育保险费。基本医疗保险分为职工基本医疗保险和城乡居民基本医疗保险，缴费基数与缴费比例因参保主体不同有所差异；生育保险由用人单位按规定缴纳。

4. 工伤保险费与新就业形态人员职业伤害保障费（以下简称职业伤害保障费）。工伤保险费由用人单位缴纳，实行行业差别费率和浮动费率；职业伤害保障是在工伤保险制度框架下，解决新就业形态人员职业伤害保障不平衡不充分等问题，目前，在部分省份和部分平台企业开展试点。

5. 失业保险费。参保范围包括城镇企业事业单位及其职工等，缴费基数以工资总额和本人工资为依据，用人单位与职工个人按规定比例缴费。

6. 征缴流程。明确了用人单位、平台企业及个人的社会保险登记要求，规定社会保险费统一由税务机关征收，同时细化了不同主体的申报缴费期限和流程，确保征缴工作规范有序。

通过本章学习，全面系统掌握我国社会保险费相关政策，有助于深刻认识我国社会保险制度在社会保障体系中的重要地位。
