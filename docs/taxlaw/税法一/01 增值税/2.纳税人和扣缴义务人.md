# 考点1：增值税纳税人和扣缴义务人

## 一、纳税人

| 项目   | 内容                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 一般情况 | 在中华人民共和国**境内**（以下简称境内）**销售货物、服务、无形资产、不动产**（以下称**应税交易**），以及**进口货物**的单位和个人（**包括**个体工商户），为增值税的纳税人，应当依照《增值税法》规定缴纳增值税  <br />**【注意】**  ①销售＋货物、服务、无形资产、不动产＋单位和个人  ②进口＋货物＋单位和个人  <br />**【提示】**  ①单位，包括企业、行政机关、事业单位、军事单位、社会组织及其他单位  <br />②个人，包括个体工商户和自然人                                                                                                                                                                       |
| 特殊情况 | （1）单位以承包、承租、挂靠方式经营，承包人、承租人、挂靠人**以发包人、出租人、被挂靠人名义对外经营**并**由发包人、出租人、被挂靠人承担相关法律责任**的，发包人、出租人、被挂靠人为纳税人：其他情形下，承包人、承租人、挂靠人为纳税人  **【甜甜说】**特殊的纳税人界定技巧  ①以谁的名义对外经营  ②由谁承担相关法律责任  （2）资管产品运营过程中发生的应税交易，★**资管产品****管理人****（不是购买者）**为纳税人。法律另有规定的，从其规定  （3）对报关进口的货物，以**进口货物的****收货人****或****办理报关手续的单位和个人**为进口货物的纳税人  （4）对代理进口货物，以**海关开具的完税凭证上的纳税人**为增值税纳税人  **【甜甜提示】**对报关进口货物，凡是海关的完税凭证开具给委托方的，对代理方不征增值税；凡是海关的完税凭证开具给代理方的，对代理方应按规定征收增值税 |

## 二、扣缴义务人（★★）

1. 境外单位和个人在境内发生应税交易，以**购买方**为扣缴义务人；境外单位或个人按照国务院的规定，委托了境内代理人来申报缴纳税款，那么就由该代理人负责申报，购买方就不再是扣缴义务人。
	【举例】英国A公司向中国B公司提供设计服务。

2. 自然人发生符合规定的应税交易，**支付价款的境内单位**为扣缴义务人。代扣代缴的具体操作办法，由国务院财政、税务主管部门制定。

   > 【举例】著名设计师“魏恒超”向A公司提供连衣裙设计服务，由A公司在支付价款时代扣代缴增值税。

3. 境外单位或者个人向自然人出租境内不动产，**有**境内代理人的，由**境内代理人**申报缴纳税款。

   > 【举例】美国人“詹姆斯·悦”将四川成都的一套房子出租给何小宏，因为“詹姆斯·悦”在国外工作，所以由中介帮忙收取租金，代扣代缴增值税。

> [!NOTE]- 考题演练
> **考题演练**
> 【单选·2024改编】关于增值税纳税人和扣缴义务人的说法，正确的是（  ）。
> A.资管产品运营过程中发生的增值税应税交易，以资管产品购买人为增值税纳税人
> B.自然人发生符合规定的应税交易，以支付价款的境内单位为扣缴义务人
> C.承包人以发包人名义对外经营并由发包人承担相关法律责任的，以承包人为增值税纳税人
> D.境外单位在境内发生应税交易，以购买方为纳税人
> 【答案】B 【解析】选项A，资管产品运营过程中发生的应税交易，资管产品管理人为纳税人。法律另有规定的，从其规定。选项C，单位以承包、承租、挂靠方式经营，承包人、承租人、挂靠人以发包人、出租人、被挂靠人名义对外经营并由发包人、出租人、被挂靠人承担相关法律责任的，发包人、出租人、被挂靠人为纳税人；其他情形下，承包人、承租人、挂靠人为纳税人。选项D，境外单位或个人在境内发生应税交易，一般以购买方为扣缴义务人，而不是纳税人。
