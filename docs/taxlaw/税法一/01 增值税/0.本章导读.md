# 第二章　增值税

**【本章导读】**

本章系统阐述我国增值税税收制度，核心涵盖纳税人、应税交易、税率、税收优惠、应纳税额计算等多个要素，主要内容包括：

1. **纳税人和扣缴义务人**。增值税纳税人包括境内销售货物、服务、无形资产、不动产及进口货物的单位和个人。增值税纳税人分为一般纳税人和小规模纳税人。境外单位和个人在境内发生应税交易，以购买方为扣缴义务人，按照国务院的规定委托境内代理人申报缴纳税款的除外；境外单位或者个人向自然人出租境内不动产，有境内代理人的，由境内代理人申报缴纳税款。

2. **征税范围**。我国增值税征税范围包括在境内销售货物、服务、无形资产、不动产和进口货物。同时，《中华人民共和国增值税法》及相关规定明确了增值税视同应税交易、不属于应税交易和特殊应税交易。
   
3. **税率和征收率**。增值税税率分13%、9%、6%和零税率四档：征收率为3%。

4. **税收优惠**。增值税的税收优惠包括起征点、法定免税项目、专项税收优惠项目和阶段性税收优惠项目。

5. **一般计税方法应纳税额计算**。按照一般计税方法计算缴纳增值税的，应纳税额为当期销项税额抵扣当期进项税额后的余额。销项税额是纳税人发生应税交易，按照销售额或组成计税价格与税率计算的乘积。进项税额分为准予从销项税额中抵扣的进项税额和不得抵扣的进项税额。准予从销项税额抵扣的进项税额可以根据两种方法确定：凭票扣税和计算扣税。用于简易计税项目、免税项目、集体福利或个人消费以及非正常损失项目等对应的进项税额不得从销项税额中抵扣，已抵扣进项税额的应按规定计算转出。另有农产品核定扣除、长期资产进项税额扣除、先进制造业加计抵减以及留抵退税等特殊规定。

6. **简易计税方法应纳税额计算**。小规模纳税人以3%征收率按照简易计税方法计算纳税。一般纳税人的特定业务也可以选择适用简易计税方法。

7. **进出口业务增值税政策**。进口环节纳税人为收货人或报关单位和个人，应纳税额=组成计税价格 ×税率。出口业务增值税政策包括退（免）税政策、免税政策和征税政策。需要关注跨境电商出口海外仓以及国际运输船舶等特殊情形的出口退免税政策。

8. **预缴税款及特定交易的增值税政策**。跨地级行政区（直辖市下辖县区）提供建筑服务，采取预收款方式提供建筑服务，采取预售方式销售房地产项目，转让或者出租与纳税人机构所在地不在同一县（市、区、旗）内的不动产，油气田企业跨省、自治区、直辖市销售与生产原油、天然气相关的服务应按规定预缴税款。特定交易的增值税政策涉及资管产品、黄金交易、成品油零售加油站。

9.  **增值税征收管理**。包括增值税纳税义务发生时间、纳税期限和纳税地点。

通过本章的学习，全面掌握增值税现行政策，系统厘清增值税的税制要素及相互关系，准确把握增值税计税原理，为以后各个税种的学习打下坚实基础。
