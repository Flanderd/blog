# 【本章导读】

本章系统阐述我国消费税税收制度。其核心要点涵盖纳税人、征税范围、税率、计税依据等多个要素，主要内容包括：

1. 消费税纳税人和扣缴义务人。在我国境内生产、委托加工和进口应税消费品的单位和个人，国务院确定的销售应税消费品的其他单位和个人为消费税纳税人；受托方（个体工商户和个人除外）为委托加工环节消费税的代收代缴义务人，电子商务企业、电子商务交易平台或物流企业为跨境电子商务零售进口环节消费税的代收代缴义务人。
2. 消费税征税范围包括烟、酒、高档化妆品等 15 种应税消费品。
3. 消费税税率有比例税率、定额税率两种形式。
4. 生产经营应税消费品的税务处理。消费税的计税方式分别是从价计税、从量计税、复合计税。从价计税方式的计税依据是销售额；从量计税方式的计税依据是销售数量，复合计税方式的计税依据分别是销售额和销售数量。纳税人以外购或委托加工收回的应税消费品连续生产应税消费品的，按照当期生产领用数量计算准予扣除的已纳消费税。
5. 自产自用应税消费品消费税的税务处理。纳税人以自产的应税消费品用于连续生产应税消费品，不缴纳消费税。用于其他方面的，于移送使用时纳税。
6. 委托加工应税消费品的税务处理。受托方代收代缴消费税的，应按受托方同类应税消费品的售价计算纳税；没有同类价格的，按照组成计税价格计算纳税。委托方收回已税消费品直接对外销售的，不再征收消费税；以高于受托方计税价格对外出售的，需按照规定申报缴纳消费税，计税时准予扣除受托方已代收代缴的消费税。
7. 进口环节应纳消费税的规定。进口的应税消费品，于报关进口时由海关代征进口环节的应纳消费税。进口的应税消费品，按照组成计税价格计算纳税。
8. 批发环节应纳消费税的规定。卷烟和电子烟在生产环节征收消费税的基础上，在批发环节加征消费税。
9. 零售环节应纳消费税的规定。金银等首饰消费税在零售环节征收。超豪华小汽车在生产（进口）环节征收消费税的基础上，在零售环节加征消费税。

本章学习时应厘清消费税与增值税的交叉关系，采用对比分析方法深入掌握消费税与增值税计税依据的关系和计税方法的差别；关注增值税与消费税避免重复征税的税务处理区别；聚焦委托加工业务的税负判定，明确委托方和受托方的涉税责任及已税消费品后续销售的处理规则。
