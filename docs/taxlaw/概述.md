# 大数定律

::: tip 一句话概括

在大量**相互独立**的重复随机试验中，样本均值会稳定地趋近于总体均值（数学期望）。
这就是"频率稳定性"的严格数学表述，也是保险精算、抽样调查、蒙特卡洛方法的理论基石。

:::

## 一、为什么需要大数定律

抛一枚均匀硬币，理论上正面概率是 $0.5$。但只抛 10 次，正面出现 7 次一点也不奇怪；抛 1000 次，正面比例通常会非常接近 $0.5$；抛 10000 次，偏差会进一步缩小。

这种"次数越多，频率越稳定"的直觉，需要一条定理来保证：**它成立的条件是什么、以什么方式收敛、收敛速度如何**。大数定律回答的正是前两个问题。

## 二、预备概念

| 概念 | 含义 |
| --- | --- |
| 随机变量 $X$ | 取值由随机试验决定的量 |
| 数学期望 $E(X)$ | 随机变量的"理论平均值"，即总体均值 |
| 独立同分布（i.i.d.） | 各次试验互不影响，且服从同一分布 |
| 依概率收敛 | 偏差超过任意 $\varepsilon$ 的概率趋于 $0$ |
| 几乎必然收敛 | 偏差趋于 $0$ 的概率为 $1$ |

依概率收敛记作 $X_n \overset{P}{\longrightarrow} X$，定义为：对任意 $\varepsilon > 0$，

$$
\lim_{n \to \infty} P\left(\left|X_n - X\right| \ge \varepsilon\right) = 0
$$

几乎必然收敛记作 $X_n \overset{\text{a.s.}}{\longrightarrow} X$，定义为：

$$
P\left(\lim_{n \to \infty} X_n = X\right) = 1
$$

两者区别：依概率收敛允许"偶尔大幅偏离"，只是偏离的概率越来越小；几乎必然收敛要求除一个零概率集合外，每条样本路径最终都收敛。

### 切比雪夫不等式

设 $X$ 的期望 $E(X)$ 与方差 $D(X)$ 存在，则对任意 $\varepsilon > 0$：

$$
P\left(\left|X - E(X)\right| \ge \varepsilon\right) \le \frac{D(X)}{\varepsilon^2}
$$

它把"偏离期望超过 $\varepsilon$"的概率用方差控制住，是证明弱大数定律最常用的工具。

## 三、三个常用版本

### 1. 伯努利大数定律（频率趋近概率）

设 $n$ 次独立重复试验中事件 $A$ 发生了 $n_A$ 次，每次试验中 $A$ 发生的概率为 $p$，则对任意 $\varepsilon > 0$：

$$
\lim_{n \to \infty} P\left(\left|\frac{n_A}{n} - p\right| < \varepsilon\right) = 1
$$

**含义**：试验次数足够多时，频率 $\frac{n_A}{n}$ 与概率 $p$ 的偏差超过任意给定精度的可能性趋于零。

### 2. 辛钦大数定律（独立同分布）

设 $X_1, X_2, \dots, X_n$ 独立同分布，且 $E(X_i) = \mu$ 存在，则：

$$
\frac{1}{n}\sum_{i=1}^{n} X_i \overset{P}{\longrightarrow} \mu
$$

**注意**：只要求期望存在，不要求方差存在，这是它比切比雪夫版本更强的地方。

### 3. 切比雪夫大数定律（方差一致有界）

设 $X_1, X_2, \dots$ 相互独立，且存在常数 $C$ 使 $D(X_i) \le C$，则：

$$
\frac{1}{n}\sum_{i=1}^{n} X_i \overset{P}{\longrightarrow} \frac{1}{n}\sum_{i=1}^{n} E(X_i)
$$

**注意**：不要求同分布，只要求独立且方差有界。

### 三个版本的对比

| 版本 | 独立性 | 同分布 | 对矩的要求 |
| --- | --- | --- | --- |
| 伯努利 | 独立重复试验 | 是（两点分布） | 只需概率 $p$ |
| 辛钦 | 独立 | 是 | 期望存在 |
| 切比雪夫 | 独立 | 否 | 方差一致有界 |

## 四、弱大数定律与强大数定律

| | 弱大数定律 | 强大数定律 |
| --- | --- | --- |
| 收敛方式 | 依概率收敛 | 几乎必然收敛 |
| 直观说法 | 对很大的 $n$，偏差大的概率很小 | 对几乎每条样本序列，$n$ 足够大后偏差必然很小 |
| 典型结论 | 辛钦大数定律 | 柯尔莫哥洛夫强大数定律 |
| 强度 | 较弱 | 较强（能推出弱版本） |

柯尔莫哥洛夫强大数定律：若 $X_1, X_2, \dots$ 独立同分布且 $E|X_1| < \infty$，则

$$
\frac{1}{n}\sum_{i=1}^{n} X_i \overset{\text{a.s.}}{\longrightarrow} E(X_1)
$$

反过来，如果几乎必然收敛到有限常数，则期望必定存在——所以 $E|X_1| < \infty$ 这个条件不能再削弱。

## 五、证明思路（以切比雪夫版本为例）

令 $\bar{X}_n = \frac{1}{n}\sum_{i=1}^{n} X_i$。

1. 由期望的线性性，$E(\bar{X}_n) = \frac{1}{n}\sum E(X_i)$；
2. 由独立性，$D(\bar{X}_n) = \frac{1}{n^2}\sum D(X_i) \le \frac{C}{n}$；
3. 对 $\bar{X}_n$ 用切比雪夫不等式：

$$
P\left(\left|\bar{X}_n - E(\bar{X}_n)\right| \ge \varepsilon\right) \le \frac{D(\bar{X}_n)}{\varepsilon^2} \le \frac{C}{n\varepsilon^2} \to 0
$$

方差随 $n$ 增大而衰减，是整条证明的核心：**平均会抵消随机波动**。

::: details 为什么"平均能抵消波动"

若各次试验独立，方差相加：$D\left(\sum X_i\right) = \sum D(X_i)$。
但平均之后要再除以 $n^2$，于是 $D(\bar{X}_n) = \frac{1}{n^2}\sum D(X_i) \approx \frac{D(X)}{n}$。
标准差按 $\frac{1}{\sqrt{n}}$ 衰减——这就是"样本量翻 4 倍，误差减半"的来源。

:::

## 六、常见误区

::: warning 误区一：大数定律会"补偿"之前的偏离

这是**赌徒谬误**。硬币连续出现 10 次正面，不代表第 11 次更可能出现反面。
大数定律说的是"后面的试验会把**比例**稀释回 $0.5$"，而不是"欠下的反面会补回来"。
即使接下来全是正面，比例依然会慢慢趋近 $0.5$，只是趋近得很慢。

:::

::: warning 误区二：只要样本够大就一定准

大数定律要求**独立同分布**（或至少弱相关、方差可控）。
如果样本存在系统性偏差（比如只调查某一类人），样本量再大也只会更精确地估计错误的总体的均值。

:::

::: warning 误区三：期望不存在时定律失效

柯西分布没有期望。对它取样本均值，无论 $n$ 多大，均值都不会稳定下来。
这说明"独立同分布"本身不足以保证大数定律，矩条件不可省略。

:::

## 七、与中心极限定理的区别

大数定律和中心极限定理经常一起出现，但回答的是不同问题：

| | 大数定律 | 中心极限定理 |
| --- | --- | --- |
| 回答的问题 | 样本均值**收敛到哪里** | 样本均值**围绕均值如何波动** |
| 结论 | $\bar{X}_n \to \mu$ | $\frac{\sqrt{n}(\bar{X}_n - \mu)}{\sigma} \overset{d}{\longrightarrow} N(0,1)$ |
| 需要的矩 | 期望（或方差） | 方差存在 |
| 用途 | 说明估计的一致性 | 构造置信区间、做假设检验 |

简言之：大数定律保证"估得准"，中心极限定理告诉你"误差有多大、服从什么分布"。

## 八、典型应用

- **保险精算**：大量同质风险单位汇聚后，实际赔付率会接近预期赔付率，保费才能按期望损失定价。
- **抽样调查**：样本量足够大时，样本均值可以作为总体均值的可靠估计。
- **蒙特卡洛方法**：用大量随机样本的平均值近似积分或期望，误差按 $\frac{1}{\sqrt{n}}$ 收敛。
- **质量控制**：批量抽检的平均不合格率会稳定在真实不合格率附近。

## 九、自测

::: details 题目一

设 $X_1, \dots, X_n$ 独立同分布，$E(X_i) = 2$，$D(X_i) = 4$。用切比雪夫不等式估计 $P\left(\left|\bar{X}_n - 2\right| \ge 0.5\right)$ 的上界。

**解**：$D(\bar{X}_n) = \frac{4}{n}$，故上界为 $\frac{4/n}{0.25} = \frac{16}{n}$。当 $n = 100$ 时不超过 $0.16$。

:::

::: details 题目二

抛硬币 10000 次，正面出现 5200 次。这个结果是否说明硬币不均匀？

**思路**：若硬币均匀，$p = 0.5$，频率 $0.52$ 与 $0.5$ 相差 $0.02$。仅凭大数定律只能说明"偏差会趋于零"，判断显著性需要中心极限定理：标准差约为 $\frac{0.5}{100} = 0.005$，偏差达到 $4$ 个标准差，属于小概率事件，有理由怀疑硬币不均匀。

:::
