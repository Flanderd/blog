# 第六章 行政诉讼法律制度

## 本章导读

本章作为行政救济法的重要组成部分，主要内容包括行政诉讼的概念和特征、基本原则以及有关行政诉讼受案范围、诉讼参加人、管辖、证据以及行政诉讼程序的一些基本制度。学习本章时，应首先理解行政诉讼的概念和特征、基本原则，理解行政诉讼受案范围的规定并把握其实践运用。其中，行政诉讼参加人部分需要侧重学习原告和被告资格确定规则及其实践运用；管辖主要是学习和把握级别管辖和地域管辖规则；证据制度主要是理解和学习倒置举证特殊性及其要求；有关行政诉讼程序，主要是理解和把握一审、二审以及审判监督程序的基本要求。

## 学习方法提示

行政复议法律制度与行政诉讼制度存在衔接关系，二者的具体规定在法律程序层面既有法理共性又存在规范差别，因此需要从行政争议法律救济机制和整体制度设计的角度，对行政复议法律制度与行政诉讼法律制度开展对照学习。对于诉讼程序相关范畴，宜采用对比学习法。比如，驳回诉讼请求和驳回起诉，行政诉讼管辖、证据制度与民事诉讼管辖、证据制度既有区别又有联系，较易混淆。此外，学习本章内容还需运用案例学习法，结合税务诉讼实际案例，理解并运用行政诉讼程序权利和诉讼程序规范，以提高有效应对和解决具体涉税争议的实际工作能力。
