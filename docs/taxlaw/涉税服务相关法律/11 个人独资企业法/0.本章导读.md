# 第十一章 个人独资企业法

## 本章导读

个人独资企业，是由一个自然人投资，全部资产为投资人所有的营利性经济组织。个人独资企业是一类特殊的商事主体。它是一种企业组织形态，性质上属于非法人组织。投资人对企业债务承担无限责任。个人独资企业法是规范个人独资企业设立、运营、终止等行为的基本法律。本章内容包括个人独资企业的概念与特征、个人独资企业的设立条件、个人独资企业的事务管理、个人独资企业的权利与义务、个人独资企业的解散与清算、法律责任等。

## 学习方法提示

在本章学习中，应通过个人独资企业与个体工商户、一人有限公司、外商独资企业、全资国有企业的比较，认识其在组织、出资人、责任方式承担等特点，辨析其与其他主体的不同。还应当熟悉个人独资企业设立，掌握个人独资企业事务管理、对外关系，了解解散与清算等方面的法律特殊规定。例如，个人独资企业的投资人以其个人财产对企业债务承担无限责任，但是根据《个人独资企业法》第 18 条规定，个人独资企业在申请企业设立登记时明确以家庭共有财产作为个人出资的，应当依法以家庭共有财产对企业债务承担无限责任。个人独资企业解散后，原投资人对个人独资企业存续期间的债务仍承担偿还责任，但债权人在 5 年内未向债务人提出偿债请求的，该责任消灭。
