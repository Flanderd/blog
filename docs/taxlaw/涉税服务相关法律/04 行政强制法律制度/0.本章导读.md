# 第四章 行政强制法律制度

## 本章导读

本章作为行政行为法的重要组成部分，主要内容包括有关行政强制的种类和方式、基本原则，以及行政强制设定、实施程序等一些基本制度。学习本章时，应当从行政强制的概念和种类、基本原则出发，系统学习行政强制设定权限划分以及实施程序的基本要求，侧重对行政强制措施和行政强制执行的程序要求进行理解，并能在相关税务实践活动中加以运用。有关行政强制实施，主要是在全面理解行政强制措施和行政强制执行的规范要求基础上，把握税务执法领域税收保全措施和税收强制执行的实践要求及其实际操作。

## 学习方法提示

学习本章内容，切忌死记硬背、机械学习，应遵循“理念先行、侧重程序、突出税务”的逻辑思路，在厘清立法意图和法律原则精神的基础上，侧重理解和运用行政强制措施和行政强制执行的程序规范。同时，学习本章还应注意运用对比学习法。比如，行政强制措施与行政强制执行，税收保全措施与税收强制执行措施，有关行政强制设定权限与行政许可、行政处罚的设定权限，有关期限的规定与行政处罚法律制度部分内容等，均需要对照辨析。此外，对于查封、扣押及冻结决定文书，以及催告书、行政强制执行决定书等重要法律文书，需要结合税收征管执法实践，具体把握其使用规范和操作层面的要求。
