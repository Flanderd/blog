# 第三章 行政处罚法律制度

## 本章导读

本章作为行政行为法的重要组成部分，主要内容包括有关行政处罚的法律定义、法律原则以及行政处罚设定、实施程序的一些基本制度。学习本章时，应当从行政处罚的概念和种类、行政处罚的基本原则出发，全面学习行政处罚设定权限划分及实施程序的基本要求，并结合国务院有关文件及税务行政处罚实践活动进行理解并加以运用。其中，有关行政处罚实施，主要是在全面理解行政处罚主体及管辖和适用、行政处罚简易程序和一般程序包括听证程序的规范要求基础上，把握税务实践中针对各种税收违法行为的税务行政处罚规范做法以及税务行政处罚裁量权行使的要求。

**【学习方法提示】**

学习本章内容，应遵循从一般到特别，再由特别回归一般的逻辑思路，将行政处罚法的一般规定，与税收征管法律法规、发票管理的特别规定融会贯通进行学习，并关注税务稽查案件办理、重大税务案件审理、税务行政处罚裁量权行使等政策，以及税务实践操作层面的要求。同时，行政处罚设定权限与行政许可、行政强制的设定权限，行政处罚追究时效与税务行政处罚追究时效等内容较易混淆，需要对照辨析加以理解学习。
