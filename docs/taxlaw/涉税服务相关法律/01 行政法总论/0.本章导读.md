# 第一章 行政法总论

## 本章导读

作为行政法的总论部分，本章阐述有关行政法的基本原理，以及有关行政组织法和行政行为法的一些基本理论。其中，行政法的基本原理主要包括行政法的概念和特征、行政法的基本原则、行政法的法律渊源以及行政法律关系；行政组织法的基本理论主要阐述行政主体及其行政职权、行政机关及其工作人员，以及其他行使行政职权的组织；行政行为法的基本理论主要阐述行政行为的概念和特征、分类、内容及效力，具体行政行为的主要类型及合法要件，以及行政程序和行政程序法的基本原则和基本制度。

## 学习方法提示

学习本章内容时，需要从行政法整体框架和宏观体系角度，理解行政组织法、行政行为法和行政救济法各部分的基本结构及内在逻辑关系，进而把握行政主体及其职权、行政行为及效力、行政程序法基本原则和基本制度，以及其在税务行政执法实践中的具体运用。对于本章涉及的行政法基本范畴，需要侧重结合相关示例加强理解，这是形成涉税行政法律的基本认知、基本能力和基本法律价值的前提和起点。对比学习法是本章学习的基本方法：如学习和理解行政法的基本原则，需要与行政机关依法行政的基本原则要求进行比照；学习理解派出机构，需要与派出机关进行对比区分；学习和理解行政协议，需要与民事合同进行对照辨析；等等。此外，学习本章还应结合有关涉税法律法规规定和税务行政执法实际工作进行理解，从法理层面开展思考、判断和分析。
