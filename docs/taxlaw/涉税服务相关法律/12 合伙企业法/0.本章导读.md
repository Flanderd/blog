# 第十二章 合伙企业法

## 本章导读

本章是关于合伙企业法的内容。

合伙企业是一类重要的商事主体，它属于非法人组织。《合伙企业法》是规范合伙企业设立、运营、终止等行为的法律。该法以普通合伙企业作为典型规范形态，有限合伙企业以及特殊的普通合伙企业为特殊形态。本章内容包括合伙企业的设立要件和程序、合伙企业财产关系、内部事务执行、对外关系、入伙和退伙要件、程序和法律后果、解散和清算制度、特殊的普通合伙企业和有限合伙企业的特殊规则等。

## 学习方法提示

在本章学习中，应结合《民法典》认真学习《合伙企业法》的一些具体和特殊的规则，与公司法人制度进行比较，尤其在学习企业的设立要件与程序、合伙企业财产和份额、内部事务执行债务清偿规则入伙和退伙的内容时作正确的辨析区别。在本章学习中，可以结合一些具体案例，理解规则在实际生活中的适用。例如，特殊的普通合伙企业与有限合伙企业这两类特殊的合伙企业，可以通过对实际案例分析，在比较中理解两类企业在设立、合伙人地位、责任承担上的不同。
