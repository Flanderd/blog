# 第十章 婚姻家庭和继承法

## 本章导读

本章是关于婚姻家庭法和继承法的内容，共二节。

第一节是婚姻家庭法的内容。《民法典》调整自然人身份关系的内容主要在婚姻家庭编中，包括婚姻法和家庭法。婚姻法是关于结婚、离婚的法律规范，调整婚姻关系的产生和消灭。家庭法是关于亲属关系的法律规范，调整夫妻关系、父母子女关系，以及其他近亲属的身份关系和财产关系。收养法调整因收养产生民事关系的法律规范，属于家庭法的范畴。婚姻法的基本原则是婚姻家庭法律制度的基石和法律适用的指引。它是维护婚姻家庭秩序的法律保障，也是弘扬婚姻家庭伦理道德的载体。亲属制度是婚姻家庭法的重要组成部分，明确了亲属之间的法律关系和身份地位。在学习亲属制度时，应当正确认识和理解亲属范围、亲等计算以及亲属关系的种类（如血亲和姻亲等），能够辨析不同亲属间的权利义务关系，为处理家庭内部事务提供法律依据。结婚制度的主要内容包括结婚的条件、结婚的程序，以及婚姻无效和可撤销情形。家庭关系的内容包括夫妻关系、父母子女关系、其他亲属关系，学习相关内容有助于正确认识解决家庭纠纷的法律依据，准确适用法律规则。学习离婚制度应当掌握我国法律上有关离婚的条件、离婚的方式、离婚的程序、离婚的法律后果等内容。设立收养制度的核心目的是为失去父母或无法得到适当照顾的未成年人提供一个稳定、温暖的家庭环境。学习时，应当熟悉收养行为应遵循的法律规范。

第二节是继承法的内容。《民法典》继承编是调整因继承而发生的民事关系的法律规范。继承制度是自然人死亡时所遗留的个人合法财产依法律规定或者由死者指定的人取得的制度。继承制度包括法律的基本原则、取得遗产的根据、遗产处理的方法和程序。继承权是继承法律关系的核心要素。继承方式有法定继承和遗嘱继承。依据法律直接规定取得遗产的是法定继承；根据死者意愿取得遗产的是遗嘱继承和遗赠。遗产的处理涉及继承的程序性规范，包括遗产的范围、遗产管理、遗产分割以及遗产债务清偿等制度。

## 学习方法提示

学习本章内容时，可以采取以下的学习方法：①在认真仔细研读《民法典》婚姻家庭编和继承编的条文以及相关司法解释的基础上，理解法律条文的含义和适用范围。例如，在婚姻家庭法中，正确理解结婚的条件；在继承法中，正确认识法定继承人的范围和顺序。②结合案例学习，理解和认识法律规则在实际生活中的适用。例如，在婚姻家庭法中，通过具体案例分析，正确辨析无效婚姻与可撤销婚姻的区别；在继承法中，研究遗嘱继承纠纷的案例，理解遗嘱的有效性和执行问题。③总结归纳。可以将婚姻家庭法和继承法的知识点进行系统梳理，制作思维导图便于对知识的理解和掌握；对每个章节

的重点内容进行总结，形成笔记。例如，总结婚姻家庭法中夫妻财产制的类型和适用，继承法中遗嘱的形式和效力等。
