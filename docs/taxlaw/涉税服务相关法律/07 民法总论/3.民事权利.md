# 第三节 民事权利

## 一、民事权利的概念

民事权利，是指民事主体实现其正当利益的行为依据。

权利体现为主体依其意志实施行为的自由，是主体自由意志的时空范围。在此时空范围内，法律为主体在自由意志支配下的行为提供充分保护。民事主体按照自己的意愿依法行使民事权利不受干涉。为实现正当利益，权利人可以自己实施一定的行为，也可以依约定或者法律规定请求特定他人实施一定行为。民事主体行使权利时，应当履行法律规定的或者当事人约定的义务。在正当利益因他人的行为而无法实现时，权利人可以请求司法机关予以公力救济。总而言之，权利体现为民事主体的自由意志、正当利益和法律保障三者的有机结合。

::: tip 【提示】民事权利的立法现状
为彰显对民事权利的尊重，加强对民事权利的保护，并为《民法典》各分编和其他民事特别法规定具体民事权利提供依据，《民法典》在总则编设专章对民事权利制度进行高屋建瓴的顶层设计。《民法典》总则编第五章共 24 个条文，全面系统地规定了民事权利的种类和内容、权利的取得和行使、其他民事权益的保护等。然后，通过各分编将总则编对民事权利的顶层设计予以具体化和落实。从而使《民法典》成为名副其实的“权利法典”。例如：人格权编将第五章第 109～111 条所规定的人格权制度具体化；物权编将第五章第 113～117 条所规定的物权制度具体化；合同编将第五章第 118 条、第 119 条、第 121 条、第 122 条所规定的债权制度具体化；婚姻家庭编将第五章第 112 条所规定的自然人身份权制度具体化；继承编将第五章第 124 条所规定的继承权制度具体化；侵权责任编将第五章第 120 条所规定的债权制度具体化。
:::

## 二、民事权利的分类

### （一）人身权、财产权、知识产权和成员权

根据民事权利客体所体现的利益性质划分。

人身权，是指以自然人的人格利益和身份利益为客体的权利，是人格权和身份权的合称。其中，人格权，是基于自然人之所以为人所必须具备的主体性要素所产生的权利。人格权包括生命权、身体权、健康权、姓名权、肖像权、名誉权、荣誉权、隐私权、婚姻自主权以及人格尊严、人身自由、个人信息等人格利益。《民法典》第四编规定了人格权。人格权独立成编被誉为《民法典》立法的亮点之一。身份权，是基于民事主体在婚姻和家庭关系中的特定身份所产生的权利。身份权包括配偶权、亲权、亲属权。人身权所体现的利益与个人尊严密切相关，虽非属经济价值，但当人身权受到不法侵害且不能回复原状时，尚须借助财产手段予以救济。作为专属权的人身权与其主体不可分离，故无从转让。

财产权，是以有形财产或者无形财产为客体的权利。如物权、债权和继承权等。财产权所体现的利益具有经济价值，可予以经济评价。财产权大多为非专属权，通常可以同主体发生分离。

知识产权，是以受保护的智慧产品为客体的排他性支配型权利。如著作权、专利权、商标权等。知识产权兼具人身性和财产性双重属性。知识产权的客体是人类脑力劳动的产物，即智慧产品，学理上称之为“无体物”，包括作品、专利发明、商标设计等。

成员权，是团体成员依其在团体中的地位产生的对于团体的权利。股权即典型的成员权。成员权基于成员资格而产生，包括表决权，对业务的知悉权、执行权、监督权、盈利分配权以及团体终止时的剩余财产分配权等。

### （二）支配权、请求权、形成权和抗辩权

根据民事权利的作用方式划分。

支配权，是指对客体直接支配并享受其利益的排他性权利。如人格权、身份权、物权和知识产权。支配权仅凭权利人单方意思即可实现，无须义务人以积极行为相配合。与支配权对应的义务是容忍、尊重和不干预，表现为不作为。

请求权，是指可以请求他人为一定行为或者不为一定行为的权利。如债权、返还原物请求权、回复原状请求权以及损害赔偿请求权等。请求权的行使以存在特定请求权基础为前提。所谓请求权基础，即足以支持特定请求权存在的法律规范。该法律规范通常规定请求权的成立要件，以保障请求权的正确行使。

形成权，是指权利人依其单方意思表示，就能使既存的法律关系发生变化的权利。如承认权、同意权、选择权、撤销权、解除权、抵销权及终止权等。形成权的发生或基于当事人约定，或基于法律的特别规定。形成权的特点在于，仅依权利人的单方意思表示，即足以使效力未定的法律行为生效，或者使既存的法律关系变更、终止。正因如此，为了保护相对人、维护法律关系的稳定，法律对形成权的行使予以适度限制：其一是规定形成权的除斥期间，除斥期间经过而未行使则形成权消灭；其二是规定形成权的行使原则上不得附条件或期限。

抗辩权，是指能够阻止相对人请求权效力发生的权利。抗辩权包括一时抗辩权和永久抗辩权两类。前者如先诉抗辩权、同时履行抗辩权等；后者如时效抗辩权。抗辩权主要是针对请求权的权利。抗辩权的效力在于暂时或者永久地阻止请求权效力的发生，从而使抗辩权人能够拒绝向相对人履行义务，而不在于否认相对人请求权的存在，也不在于变更或者消灭相对人的权利。可见，抗辩权属于防御性权利。

### （三）绝对权和相对权

根据民事权利的实现方式划分。

绝对权，是指无须借助他人协助即可行使、实现的权利。如人格权、身份权、物权、知识产权等。

相对权，是指须借助他人协助方可实现的权利。如债权、返还原物请求权等。

### （四）对世权和对人权

根据民事权利的效力范围划分。

对世权，是指能够请求不特定的一般人为一定行为的权利。如人格权、身份权、物权、知识产权等。在对世权关系中，权利主体是特定的，而义务主体是权利主体之外的、不特定的一切世人。义务主体所负义务的内容是对他人权利的容忍、尊重和不侵扰，表现为不作为。

对人权，是指仅能请求特定的人为一定行为的权利。如债权等请求权。在对人权关系中，权利主体是特定的，义务主体也是特定的。义务主体所负义务的内容既包括积极的作为，也包括消极的不作为，但主要体现为积极的作为。

### （五）专属权和非专属权

根据民事权利可否与其主体分离划分。

专属权，是指只能由权利主体本人享有和行使的权利。如人格权、身份权、居住权。专属权不得让与和继承。

非专属权，是指非专属于特定主体，可以与权利主体分离的权利。如物权、债权等一般财产权。非专属权可以让与和继承。

### （六）主权利和从权利

根据民事权利相互间的依存关系划分。

主权利，是指相互关联的几项权利中，不依赖其他权利而独立存在的权利。

从权利，是指相互关联的几项权利中，须以其他权利的存在为其存在前提的权利。

主权利和从权利相互对应而存在，主权利不存在，从权利也就不可能存在。没有从权利，主权利也就无从谈起。

::: tip 【主权利和从权利示例】
甲出借 50 万元给乙，丙以其房屋为甲的借款债权设定抵押担保。在此设有抵押担保的借款合同关系中，甲对乙享有的借款债权是主权利，甲对丙之房屋享有的抵押权是从权利。该抵押权作为从权利，以其所担保的借款债权的存在为存在前提。
:::

### （七）原权和救济权

在具有原生与派生关系的民事权利中，根据权利相互间的地位划分。

原权，是指原生性权利。

救济权，是指原权受到侵害或者有被侵害的危险时产生的援救原权的权利。

民法在赋予民事主体原权的同时，配套地赋予其救济权。只是救济权通常处于潜在且停止的状态，只有当原权受到侵害或者存在被侵害的危险时，救济权方启动以救济原权。

### （八）既得权和期待权

根据民事权利要件是否全部具备划分。

既得权，也称“完整权”，是指全部法律要件齐备，权利人可以现实享有和行使的权利。

期待权，也称“形成中的权利”，是指具备部分法律要件，须待其余要件具备时权利人方能现实享有和行使的权利。如清偿期届至之前的债权即为典型的期待权。

## 三、民事权利的取得、变更和消灭

民事权利作为民事法律关系的内容要素之一，其取得、变更与消灭伴随民事法律关系的变动。民事权利存在于民事法律关系之中，民事法律关系因法律事实而变动，民事权利与其同步。

### （一）民事权利的取得

民事权利的取得，是指基于一定的法律事实使某项民事权利与特定主体相结合的客观事实。《民法典》第 129 条规定，民事权利可以依据民事法律行为、事实行为、法律规定的事件或者法律规定的其他方式取得。

依是否源自前手权利的让渡，可将民事权利的取得方式划分为原始取得和继受取得。

原始取得，是指不以他人既存权利为前提的权利取得，也称“权利的最初取得”“权利的第一次发生”，是民事权利的绝对发生。原始取得的发生原因：①法律的直接规定。如善意取得动产或者不动产物权、无主物的法定归属。②事实行为。如基于先占而取得无主动产的所有权、基于添附而取得添附物的所有权、基于建造而取得不动产的所有权、基于无因管理而取得必要费用的返还请求权、基于侵权行为而取得损害赔偿请求权。③事件。如基于不当得利而取得不当利益的返还请求权。④民事法律行为。如基于合同而取得合同债权。

继受取得，是指自前手权利人处承受而来的权利取得，也称“权利的传来取得”，是民事权利的相对发生。继受取得的发生原因主要是民事法律行为。如基于交付而受让或者设定动产物权、基于登记而受让或者设定不动产物权、基于合同而设定用益物权或者担保物权。继受取得的发生原因也可以是民事法律行为之外的法律事实。如基于继承而取得遗产的所有权。民事权利的继受取得分为移转型继受取得和创设型继受取得。前者是权利原封不动地自前手移至后手，如受让取得赠与物所有权。后者则是权利前手对其权利予以权能分离的结果，如取得他人为自己设立的居住权。

### （二）民事权利的变更

民事权利的变更，是指权利的内容、效力于存续期间内发生变化的事实。

民事权利内容的变更，包括权利的量变和部分质变。前者如所有权因添附而扩大、因标的物部分灭失而缩小，债权因部分清偿而缩小等；后者如所有权因标的物出租或者抵押而产生负担从而变得不再圆满、无息债权变为有息债权等。

民事权利效力的变更，是指权利源自法律所赋予的强制性作用力的增、减变化。如原本具备公力救济请求权的债权因债务人行使时效抗辩权而成为自然债权、抵押权顺位的变化等。

### （三）民事权利的消灭

民事权利的消灭，是指基于一定的法律事实使某项民事权利与特定主体相分离的客观事实，包括绝对消灭和相对消灭。

绝对消灭，即权利本身不复存在。如所有权因标的物灭失而消灭、知识产权因保护期间届满而消灭、债权因全部清偿而消灭、形成权因除斥期间届满而消灭等。

相对消灭，是指权利由前手移转于后手，权利本身并不因此而消灭。如赠与物的所有权因交付而自赠与方移转至受赠方。对赠与方而言，谓之“权利的相对消灭”；对受赠方而言，实则“权利的继受取得”。

## 四、民事权利的行使和保护

民事权利的行使，是指民事主体旨在实现民事权利内容的行为。民事主体行使民事权利，可以通过法律行为，也可以通过事实行为。民事权利的行使是民事权利实现的前提和基础。只有符合法律规定的行使行为，其效果才能受到法律的保护。民事主体行使民事权利应当遵循自愿原则、诚信原则、禁止权利滥用原则。

自然人享有的人格权、身份权、物权、债权、知识产权、继承权、股权和其他投资性权利以及人身自由、人格尊严、个人信息等权益受法律保护。法人、非法人组织享有的名称权、名誉权、荣誉权和其他财产权利受法律保护。《民法典》第 3 条规定，民事主体的人身权利、财产权利以及其他合法权益受法律保护，任何组织或者个人不得侵犯。在税收实务工作中，对于纳税人的个人涉税信息，税务机关及税务工作人员应当依法获取和保护。

民事权利的保护通常体现在两个方面：一是权利的妨害预防，即事前保护；二是权利受侵害后的回复，即事后保护。事前保护，即在权利遭受现实侵害之前，由权利人凭借法律所设置的一系列权利保障制度自行完成。如法律行为的条件附款和期限附款、所有权保留、债的保全与债的担保、抗辩权、连带责任等。事后保护，即在权利遭受现实侵害之时或者遭受现实侵害之后，由权利人凭借自身力量捍卫权利或者请求国家公力机关依法定程序回复被侵害权利之圆满状态。事后保护，因其针对的是遭受现实侵害的权利，即圆满性已遭破坏或者正在面临破坏的权利，旨在回复权利原状或者避免权利之圆满性被破坏，故谓之救济。事前保护，重在权利侵害之防免，意在“未雨绸缪”。事后保护，重在权利侵害之救济，意在“回复原状”。关于权利的事前保护，请参见本书相关章节的内容，此处仅论及权利的事后保护，即权利的救济。权利的事后保护路径有二，即公力救济和私力救济。

### （一）公力救济

公力救济，是指经权利人申请，由专门国家机关的专职工作人员通过国家的专门力量和法定程序，对圆满性遭受破坏的权利所进行的事后保护。公力救济以民法规定的请求权基础为必要前提。

公力救济体现的是权利的国家保护，是权利救济的主要方式。当义务人不履行约定或法定义务而导致权利无法实现时，权利人即可请求国家公权力介入，藉民事责任制度而助其实现民事权利。《民法典》第 179 条规定的承担民事责任的方式包括：停止侵害、排除妨碍、消除危险、返还财产、恢复原状、修理、重作、更换、继续履行、赔偿损失、支付违约金、消除影响、恢复名誉及赔礼道歉等。公力救济的主要程序包括民事诉讼程序和强制执行程序。根据当事人诉讼请求的内容，可将民事诉讼分为给付之诉、确认之诉和形成之诉三种。其中，后两种“诉”不涉及执行问题，通常是作为提起给付之诉的前提。而给付之诉旨在实现实体请求权，因而需要执行。

### （二）私力救济

私力救济，也称“自力救济”，是指在公力救济有所不及的特定情况下，由权利人依靠自身力量强制他人，对圆满性遭受破坏之权利所进行的事后保护。

私力救济的具体方式包括自卫行为和自助行为。其中，自卫行为，是指为了防止或者避免自己或者他人所面临的现实侵害或者现实危险，不得已采取的致害他人的行为，包括正当防卫和紧急避险。自卫行为属于民事权利的保护方法，但我国《民法典》并未将其规定在民事权利部分，而是将其作为民事主体免责的抗辩事由规定在民事责任章节。自助行为，是指在权利受到损害而来不及请求公力救济时，权利人所采取的限制加害人的人身自由或者对加害人的财产予以扣押、损毁的行为，如公交车售票员扣留逃票乘客。自助行为是公力救济来不及情形下的暂时性应急措施，涉及对他人人身自由和财产利益的限制，因此，权利人实施自助行为后，应当及时请求国家强制力的介入。《民法典》第 1177 条规定，合法权益受到侵害，情况紧迫且不能及时获得国家机关保护，不立即采取措施将使其合法权益受到难以弥补的损害的，受害人可以在保护自己合法权益的必要范围内采取扣留侵权人的财物等合理措施；但是，应当立即请求有关国家机关处理。

::: tip 【提示】公力救济和私力救济的适用
公力救济是由专门国家机关的专职工作人员依照法定程序行使国家强制力对私人权利予以救济，以达公平、公正之法的目标。私力救济是由权利人依靠自身力量、仅凭一己的判断强制他人从而救济自己的权利，因而难免判断有误，救济过当，失之公允，且易滋生暴力，导致恶性循环报复，不利于社会秩序的安定与和谐。因此，随着法律文明的演进，文明社会原则上禁止私力救济，而视公力救济为权利救济的常态正途。然公力救济是以严格执行法定程序为前提的，这就难免导致公力救济对于突发急迫情形应对不及。对于此类紧急情形，反应迅捷的私力救济则具有无可替代的优势。所以，公力救济虽为权利救济的常态正途，但私力救济亦不可或缺。即以公力救济作为权利救济最主要、最普遍的方式，私力救济仅在特殊情况下方可适用，且须受法律要件的严格限制。
:::
