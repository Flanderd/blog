# 第十八章 刑事诉讼法

## 本章导读

刑事诉讼法是指国家制定的规范公安机关、检察机关和审判机关进行刑事诉讼，规范当事人和其他诉讼参与人参加刑事诉讼的法律规范。除了狭义的刑事诉讼法，还包括宪法、律师法、法律援助法等法律以及司法解释等。

刑事诉讼法的制定目的是保障刑法的正确实施，惩罚犯罪，保护人民，保障国家安全和社会公共安全，维护社会主义社会秩序。其基本理念是惩罚犯罪与保障人权相结合、实体公正与程序公正动态并重、控审分离、控辩平等对抗和审判中立，追求诉讼效率。

刑事诉讼法分总则、立案侦查和提起公诉、审判、执行、特别程序五编。本章主要介绍刑事诉讼中的的理念原则、专门机关与诉讼参与人、管辖、回避、代理、辩护、认罪认罚、强制措施，以及立案、侦查、起诉、审判等。

## 学习方法提示

学习本章应重点把握诉讼原则、诉讼参与人、辩护、认罪认罚、强制措施，以及侦查、审判等内容；熟读本章所涉的法律法规规定，关注本章中的学习提示，领会考试大纲中对了解熟悉掌握的要求，把握本章重点内容，对其中相近的概念、有关联的知识点，应采用区别比较方法加深记忆，并配合实际案例加深理解和应用。
