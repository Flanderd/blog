# 第十七章 刑法

## 本章导读

本章主要介绍刑法总则部分基础知识和分则涉税犯罪的有关规定。

刑法有狭义和广义之分。狭义上的刑法，是指国家立法机关制定的系统完整、具有统一体例的法律，即全国人大通过的《中华人民共和国刑法》。广义的刑法，泛指一切有关犯罪及其刑罚的法律规范的总称，包括刑法、刑法修正案、单行刑法和附属刑法。单行刑法，是指国家以决定、规定、补充规定、条例等名称颁布的，规定某一类犯罪及其后果或者某一事项的专门规定。附属刑法，是指在民事、经济、行政及其他部门法律中附带规定的罪刑条款。

刑法分总论和分论。总论部分有刑法论、犯罪论与刑罚论三部分，主要阐释刑法的概念、内涵、性质、任务，以及犯罪的概念、犯罪构成、刑事责任、有关犯罪和刑罚适用的一般原则，是掌握刑法分论的前提和基础；分论部分主要是规定各类犯罪的罪名和量刑标准。

本章主要介绍刑法基础知识，如刑法概述、犯罪概述、刑罚概述、刑罚适用，以及具体犯罪中的涉税犯罪与涉税职务犯罪。

## 学习方法提示

本章知识点的学习，应遵循考试大纲了解熟悉掌握的要求，结合法条和实际案例，加深对基本原则、犯罪构成、刑罚种类的理解与运用，除重点掌握刑罚适用和涉税犯罪部分的内容外，还应重点关注学习提示、本章主要法律依据及本章思考题。
