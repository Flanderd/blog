# 第八章 物权法律制度

## 本章导读

本章内容对应《民法典》第二编物权，物权编下设 5 个分编，共 20 章 258 条。

物权法，是调整人对物的占有、归属和利用关系的法律规范的总称。物权法调整财产的占有、归属和利用关系，即静态的财产关系，属于财产归属法。物权法所规定的物权具有支配性、排他性、对世性，与一般第三人直接发生利害关系，其存续与变动直接涉及第三人的利益，因此为保证物权内容的统一，以确保物权的享有与交易的安全，物权法的规定多具有强行性。除极少数的例外，物权法的规定均不允许当事人任意变更而必须绝对适用，由此可见，物权法属于强行法。物权法也正是通过强行性规范，直接给当事人设定权利和义务，划清权利边界，从而降低交易成本，促成当事人合作，促进物的效用的充分发挥。物权法以保护财产的归属秩序为目的，注重保护经济生活的“静”的安全，使财产的归属明晰、利用有度。物权法确立平等保护国家、集体、私人的物权和其他权利人的物权的原则，规范财产的占有、归属和利用关系，以期定分止争，物尽其用、物尽其利。物权法所确立的制度规则，有利于维护静态财产关系，有利于调动民众创造社会财富的积极性，有利于充分发挥稀缺资源的经济效益，有利于推动社会经济的发展和进步。

本章内容以《民法典》物权编的体系为框架展开，主要包括物权法的基本原则、物权变动规则、物权的效力，以及所有权、用益物权、担保物权和占有等内容，分五节阐述。

第一节 物权总论，主要包括物权的概念和特征、物权的客体、物权法的基本原则、物权的分类、物权的效力、物权变动等内容。

第二节 所有权，主要包括所有权的概念、特征和权能，所有权的类型、所有权的取得和消灭、共有、业主的建筑物区分所有权、相邻权等内容。

第三节 用益物权，主要包括用益物权的概念和特征、用益物权的种类、用益物权的类型构造及其变动等内容。

第四节 担保物权，主要包括担保物权的概念和特征、担保物权的分类、抵押权、质权、留置权以及数种担保并存时的效力规则等内容。

第五节 占有，主要包括占有的概念和构成、占有的分类、占有的变动、占有的效力等内容。

## 学习方法提示

物权总论部分，对于物权的特征，要联系民法总则部分有关民事权利分类的相关内容。掌握物权的特征至关重要，物权特有的效力、物权法特有的原则皆源自物权的特征。也就是说，精准把握物权的特征，有助于帮助理解物权的效力、物权法的基本原则。

对于物的分类，要掌握分类的标准及分类在物权法上的意义。物权变动的原因，实质上就是引起物权法律关系变动的法律事实，不外乎事件和行为两大类。物权变动的公示、公信原则，也是源自物权的对世权的性质。学习该部分内容，要紧紧把握物权的特征这一关键问题，掌握了物权的特征，其他问题也就迎刃而解。

所有权部分，对于所有权概念，应当联系物权总论的相关内容，并结合所有权的权能、所有权的特征等内容来理解和掌握；所有权的各种取得方法实质上就是引起所有权法律关系发生的各种法律事实，包括事件和行为两大类；对于善意取得制度，应准确把握和领会其构成要件；对于按份共有和共同共有可以采取对比的学习方法，比较两种共有制度在效力上的差异，以此明晰两种共有制度的基本内容。明确建筑物区分所有权是单独所有权与共有权及成员权的结合形态。对于相邻关系，应当了解是发生在相毗邻不动产上的法律关系，相邻权是不动产所有权或使用权在他人不动产上的合法延伸。

用益物权部分，该部分内容相对比较容易理解，只要把握用益物权的实质——使用和收益即可。用益物权是对他人所有之物予以支配的物权，属于他物权的一种。各种用益物权的具体内容不外是将“使用”和“收益”具体化而已。还需要注意的是，传统民法上用益物权的客体限于不动产，就是说，用益物权是不动产物权。而《民法典》将用益物权的客体扩展为不动产和动产。

担保物权部分，建议采取比较的学习方法。通过比较担保物权与用益物权的差异，来把握担保物权的概念和特征；通过比较三种担保物权相互间存在的不同特点，来加深对各种担保物权的理解和领会。抵押权和质权属于意定担保物权，而留置权属于法定担保物权。对于法律强制登记的抵押物的范围应有清晰记忆。对于可以出质的权利应予清楚了解。

占有部分，关键在于正确理解占有的性质。对于占有的不同分类，要注意掌握分类的标准和分类在民法上的意义。将占有作为一种事实来看待，有助于更好地理解占有的效力。

在本章学习过程中，还应注意同步了解有关物权的法律规定和司法解释。
