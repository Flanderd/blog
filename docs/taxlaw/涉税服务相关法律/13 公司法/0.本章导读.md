# 第十三章 公司法

## 本章导读

本章主要是介绍有关公司的法律规定。作为调整和规范公司的法律，公司法属于社会主义市场经济的基础性法律，其主要法律渊源是《中华人民共和国公司法》（以下简称《公司法》）。

公司是公司法规范的对象。公司是企业的一种组织形式。具有法人资格，是公司区别于个人独资、合伙两类企业的根本标志。《公司法》规定了两种公司类型，即有限责任公司和股份有限公司。这两类公司在股东人数、设立方式、公司治理、股权股份转让等方面适用不同的规则，发起人可以根据自身需要，选择设立不同类型的公司。

公司是由股东组成的，凡是出资创建公司的人都是公司的初始股东。股东以入股方式向公司投资，是公司的所有权人。公司中最重要的关系就是公司与股东之间的关系。一方面，股东对公司具有最终控制权和收益权；另一方面，股东对公司债务仅以出资为限承担有限责任。股东的出资义务、股东资格的确认和股东权利，是确认股东与公司之间法律关系的基础。公司法对公司设立、组织机构、财务会计、重大变更、解散与清算等方面的监管要求，是为了防止股东滥用公司法人地位和股东有限责任损害公司债权人等利益相关方。

为正确适用《公司法》，最高人民法院陆续发布了多项司法解释，如《关于适用〈中华人民共和国公司法〉若干问题的规定》（一）至（五）（即《公司法》解释一至五）。其中，解释一对公司法的时间效力、股东诉讼及再审案件的法律适用，解释二对公司解散和清算，解释三对公司设立、出资、股权确认，解释四对公司决议效力、股东知情权、利润分配权、优先购买权和股东代表诉讼，解释五对关联交易、董事职务解除、公司利润分配、股东分歧解决等具体法律适用问题进行了细化和补充，为公司的规范运作和股东权益保障提供了法律支持。

本章分五节对公司法进行讲解，涵盖了《公司法》绝大部分内容。其中：

第一节公司法概述，主要包括公司与公司法、公司资本、公司登记、公司人格及其否认。

第二节公司设立，主要包括公司设立概述、公司设立方式、公司设立条件、公司设立责任。

第三节股东与股权，主要包括股东概述、股东出资、股东权利、股东诉讼。

第四节公司运行，主要包括公司组织机构，公司投资、担保与财务资助，公司股权与股份转让，公司董事、监事、高级管理人员，公司财务会计。

第五节公司变更、解散与清算，主要包括公司变更、公司解散、公司清算。

## 学习方法提示

学习本章，应对公司资本、公司设立条件与设立责任、股东出资与股东权利、公司组织机构与公司董监高等内容重点掌握。对有限责任公司和股份有限公司这两类公司的规定加以比较区别，按照考试大纲了解、熟悉、掌握的要求，辨析其异同。此外，还需结合实际案例理解掌握并综合运用《公司法》有关条文及其司法解释的相关规定。
