# 第五章 行政复议法律制度

## 本章导读

本章作为行政救济法的重要组成部分，主要内容包括行政复议的概念和特征、基本原则，行政复议受理范围，行政复议管辖，行政复议参加人，行政复议证据，行政复议审理程序以及行政复议决定及其执行的一些基本制度。学习本章时，应首先理解行政复议的概念和特征、基本原则、受理范围，在此基础上结合有关税收法律法规和税务行政复议规则把握其税务实践具体运用。学习行政复议参加人部分，需要侧重学习申请人和被申请人资格确定规则及其税务实践运用。学习行政复议申请和受理部分，主要是把握行政复议申请期限和方式、复议管辖、受理条件。学习行政复议审理程序部分，侧重学习普通程序（包括听证程序）和简易程序的基本要求。学习行政复议决定部分，主要是把握行政复议决定的种类及其适用情形，以及行政复议决定书、行政复议调解书、行政复议意见书如何具体执行的基本要求。行政复议和行政诉讼既有联系又有区别，需要对照学习。

## 学习方法提示

新行政复议法与旧行政复议法相比，法律修改变动幅度很大，需要运用新旧法条比较对照的方式开展学习。行政复议法律制度与行政诉讼法律制度既有联系又有区别，同样需要对照学习。此外，学习本章内容还需运用案例学习法，尤其要结合税务行政复议典型案例，系统学习行政复议制度及其税务实践应用。
