# 第十六章 民事诉讼法

## 本章导读

民事诉讼法，是指国家制定或者认可的，规范民事诉讼活动和调整民事诉讼法律关系的法律规范的总和。本章内容包括民事诉讼法概述、民事诉讼受案范围和管辖、民事诉讼参加人、诉讼证据和证明、民事诉讼程序等。民事诉讼是解决民事纠纷的一种方式。民事诉讼法的基本原则是指导民事诉讼进行的基本准则。它是民事诉讼价值的体现，并直接反映民事诉讼法的立法意图。民事审判基本制度是法院审判民事案件必须遵循的基本操作规程，在民事诉讼中具有关键性的作用。民事诉讼管辖，是指上下级法院之间或者同级法院之间，受理第一审民事案件的分工和权限，是确定具体案件由哪个法院行使民事审判权的制度。民事诉讼参加人包括当事人、诉讼代理人。当事人，是指因民事权利义务发生争议，以自己的名义进行诉讼，要求法院行使民事裁判权的人及其相对人。诉讼代理人，是指依法或者依当事人授权为一方当事人进行诉讼的人。民事诉讼证据和证明是民事诉讼法中的核心问题。民事诉讼程序体系包含争讼程序与非讼程序。争讼程序包括第一审程序中的普通程序、简易程序、第二审程序、审判监督程序。普通程序，是指《民事诉讼法》规定的法院审理第一审民事案件和当事人进行第一审民事诉讼通常适用的程序。简易程序，是指基层法院和它的派出法庭，在审理简单的第一审民事案件时所适用的程序。第二审程序，是指民事诉讼当事人，不服地方各级法院未生效的第一审裁判，在法定期限内向上一级法院提起上诉，上一级法院对案件进行审理所适用的程序。审判监督程序（再审程序），是指法院对已经发生法律效力的判决、裁定、调解书，发现确有错误，依法再次进行审判的程序。

## 学习方法提示

在学习民事诉讼法时，应能正确辨析民事诉讼法中不同的概念、种类的区别。例如，应能正确区分有独立请求权第三人与无独立请求权第三人在诉讼中的不同地位和不同权利；能区分不同诉讼证据类型，能正确辨析普通的共同诉讼与必要的共同诉讼的不同。掌握民事诉讼证据的种类，在了解各类证据的特点的同时，能够区分各类证据的不同。在学习证据和证明内容时，应能结合具体的案例作出正确的证据证明力判断、非法证据的排除、分析证明责任的转移、电子数据的证明效力等。在学习民事诉讼程序的内容时，应认识该内容属于民事诉讼法的核心内容，熟悉起诉和受理的操作程序及其法律规则；针对审理程序的基本类型，重点掌握第一审程序及其各环节，熟悉简易程序和第二审程序，了解再审程序。
