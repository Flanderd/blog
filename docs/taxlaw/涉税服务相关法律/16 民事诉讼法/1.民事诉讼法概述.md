# 第一节 民事诉讼法概述

## 一、民事诉讼法的概念和特征

民事诉讼，是指法院在双方当事人和其他诉讼参与人参加下，审理和解决民事案件的活动，以及因这些活动而产生的诉讼法律关系的总和。

民事诉讼法，是指国家制定或者认可的，规范民事诉讼活动和调整民事诉讼法律关系的法律规范的总和。

## 二、民事诉讼法的基本原则

民事诉讼法的基本原则，是指在民事诉讼的整个过程中，或者在重要的诉讼阶段起指导作用的准则。它是民事诉讼基本制度和具体规范的基础，体现民事诉讼的目的和价值追求。

### 1. 当事人诉讼权利平等原则

当事人诉讼权利平等原则，是指民事诉讼当事人有平等的诉讼权利，法院应当保障和便利当事人行使诉讼权利，对当事人在适用法律上一律平等。该项原则内容有：①双方当事人的诉讼地位平等；②双方当事人诉讼权利义务平等；③法院应当保障和便利当事人能够平等地行使诉讼权利。

### 2. 辩论原则

辩论原则，是指双方当事人在法院的主持下，有权就案件的事实和争议的问题，各自陈述自己的主张和根据，互相进行辩驳和论证。辩论原则贯彻在整个诉讼过程中，双方当事人都可行使自己的辩论权，法院通过当事人的辩论，核实证据，查明案件事实，作出正确裁判：该项原则的内容包括：①辩论权的行使贯穿诉讼的整个过程中，并不限于开庭审理阶段；②辩论的内容包括程序事项和实体争议；③辩论的形式可以多样，既可以是口头的，也可以是书面的；④法院应当保障当事人充分行使辩论权。

### 3. 诚实信用原则

诚实信用原则，是指法院、当事人以及其他诉讼参与人在审理民事案件和进行民事诉讼时必须公正、诚实、善意。诚实信用原则不仅适用于当事人之间，还适用于法院与当事人之间。对当事人适用该项原则主要体现在：①不得滥用诉讼权利，恶意制造诉讼状态；②禁止伪证行为和虚假陈述；③禁止矛盾行为，即禁反言；④不得实施突袭诉讼行为；⑤不得实施其他滥用诉讼权利的行为。对法院适用主要体现在：①禁止滥用审判权；②禁止突袭裁判；③禁止滥用自由裁量权；④法官裁判民事案件对于判决应当说明理由，对法律适用作出正确合理的解释。

### 4. 处分原则

处分原则，是指当事人有权在法律规定的范围内处分自己的民事权利和诉讼权利。处分原则的内容包括：①处分权是双方当事人都享有的权利。②当事人在整个诉讼过程中都可依法行使处分权。③处分权的对象是当事人所享有的民事实体权利和民事诉讼权利。对实体权利的处分可以表现为：原告可以自由确定诉讼请求的范围以及诉讼请求的实体法律关系的性质；原告在诉讼中有权变更、增加或者放弃诉讼请求，被告可以反驳、全部或者部分承认诉讼请求，也可以决定是否提出反诉。对诉讼权利的处分主要表现为：当事人对程序的开始（如原告起诉）、进行（如上诉人的上诉）、结束（如当事人撤诉）有选择权；当事人可以决定诉讼权利如何行使。④当事人对自己权利的处分应符合法律规定。

### 5. 法院调解原则

法院调解原则，是指民事诉讼过程中，对于能够调解或者应当调解的案件，法院应当在当事人自愿和合法的基础上，组织双方当事人依法定程序对争议的问题进行协商达成协议，以调解方式解决民事纠纷。法院调解原则内容包括：①法院调解活动贯穿审判程序整个过程；②法院调解要在自愿和合法的基础上进行；③对调解不成的案件法院应当及时判决。

### 6. 民事检察监督原则

民事检察监督原则，是指检察院有权对民事诉讼实行法律监督。民事检察监督原则的内容包括：①监督审判人员违法行为。各级检察院对审判监督程序以外的其他审判程序中审判人员的违法行为，有权向同级法院提出检察建议。②监督法院审判活动。③监督生效判决和裁定。法院已经发生法律效力的判决、裁定，上级检察院对下级法院已经发生法律效力的判决、裁定，发现有申请再审法定情形的，应当提出抗诉或者提出再审检察建议。④检察院有权对生效调解书实行法律监督。检察院发现调解书损害国家利益、社会公共利益的，应当提出抗诉或者提出再审检察建议。⑤对民事执行活动实施法律监督。

## 三、民事审判基本制度

民事审判基本制度是法院审判民事案件必须遵循的基本操作规程，体现审判的规律，反映审判的目的，在民事诉讼中具有关键性的作用。

### 1. 公开审判制度

公开审判制度，是指依照法律规定，法院审理民事案件，除合议庭评议外，应当公开进行的制度。公开审判制度的内容包括：①审判主体和情况的公开。审判主体的公开，是指审理案件的审判人员及记录人员应当向当事人和社会公开，同时，对于公开审理的案件，法院应当在开庭前将审理案件的情况、时间、地点予以公告。②向当事人和社会公开。向当事人公开，是指法院审判活动应在当事人参与下进行。社会公开，是指允许群众旁听开庭审理和判决宣告。③审判阶段的公开。审判阶段的公开，是指除合议庭评议阶段以外的审判其他过程都应当公开。无论案件是否公开审理，法院宣判都应当公开进行。所谓全过程包括立案公开、庭审公开、执行公开、听证公开、文书公开和审务公开等。④审判公开。它包括形式公开和实质公开。形式公开指公开开庭、允许旁听等。实质公开指要求法院依法公开审理案件，案件事实未经法庭公开调查不能认定。证明案件事实的证据未在法庭公开举证、质证，不能进行认证，但无须举证的事实除外。缺席审理的案件，法庭可以结合其他事实和证据进行认证。另外，法院制作的判决书应当写明判决认定的事实和理由以及适用的法律和理由。⑤除涉及国家秘密、商业秘密和个人隐私的内容外，公众可以查阅发生法律效力的判决书、裁定书。⑥凡是依法应当公开审理的案件没有公开审理的，当事人提起上诉的，第二审法院应当裁定撤销原判决、发回重审；当事人申请再审的，人民法院可以决定再审；人民检察院按照审判监督程序提起抗诉的，人民法院应当决定再审。发回重审或者裁定再审的案件，法院应当公开审理。根据《民事诉讼法》第137条规定，公开审判是一项基本审判制度，但是针对下列特殊案件，法院不公开审理：①不能公开审理的案件，包括涉及国家秘密的案件、涉及个人隐私的案件或者法律另有规定不公开审理的案件。②可以不公开审理的案件，包括离婚案件、涉及商业秘密的案件。③法院调解解决民事纠纷不公开进行。根据最高人民法院《关于适用〈中华人民共和国民事诉讼法〉的解释》（法释〔2015〕5号，2022年修正，以下简称《民事诉讼法司法解释》）规定，法院审理民事案件，调解过程不公开，但当事人同意公开的除外。

::: tip 【提示】公开审判制度
（1）学习该项制度应当掌握公开审判与隐私保护的平衡。比如，如何在保障当事人隐私和商业秘密的同时，实现公开审判的要求。为此，在学习相关法律规定，了解哪些内容可以公开和哪些内容需要保密的同时，掌握司法实践中如何处理公开与保密的平衡。

（2）掌握不公开审理的例外情形。理解哪些案件属于不公开审理的范围，以及正确认识不公开审理的条件。这需要学习《民事诉讼法》及相关司法解释中关于不公开审理的具体规定，并结合案例进行分析，理解和适用不公开审理的条件。

（3）了解公开审判的程序细节。公开审判涉及的程序细节较多，如公告、通知、旁听管理等，它们之间容易混淆。应需要通过案例分析和模拟庭审等方式，熟悉公开审判的具体程序要求。同时，注意法律条文中的细节规定，如公告的时间、通知的方式等。

（4）了解裁判文书公开的范围和方式。裁判文书公开涉及的内容较多，如何确定“公开”的范围和方式是一个难点。这需要学习有关司法解释，了解裁判文书公开的具体要求，包括公开的内容、公开的方式以及不公开的情形。
:::

### 2. 合议制度

合议制度，是指由三名以上审判人员组成审判组织，代表法院对民事案件进行集体审理和裁判的制度。合议制与独任制相对。独任制，是指由一名审判人员独立对案件审理，并作出裁判的制度。根据我国《民事诉讼法》的有关规定，独任制原则上只适用于基层法院审理的民事案件，如基层法院适用简易程序、小额诉讼程序审理的民事纠纷；基层法院审理的基本事实清楚、权利义务关系明确的第一审民事案件，可以由审判员一人适用普通程序独任审理；某些特殊性程序（如特别程序、督促程序以及公示催告程序）审理的简单、特殊民事案件。当然也有例外，如法律规定中级法院、专门法院对第一审简易程序审理结案或者不服民事裁定提起上诉的第二审民事案件，事实清楚、权利义务关系明确的，经双方当事人同意，也可以由审判员独任审理。合议制度是法院审理民事案件审判组织的基本制度。为了防止实务中法院随意扩大独任制适用范围，损害当事人程序利益，《民事诉讼法》第42条规定，法院审理的下列案件，不得由审判员一人独任审理：①涉及国家利益、社会公共利益的；②涉及群体性纠纷，可能影响社会稳定的；③人民群众广泛关注或者其他社会影响较大的；④属于新类型或者疑难复杂的；⑤法律规定应当组成合议庭审理的；⑥其他不宜由审判员一人独任审理的案件。审判组织制度既是对法院审理民事案件审判庭组成方式的要求，也是对当事人的程序保障，因此《民事诉讼法》第43条规定，法院在案件审理过程中，发现案件不宜由审判员一人独任审理的，应当裁定转由合议庭审理。当事人认为案件由审判员一人独任审理违反法律规定的，可以向法院提出异议。法院对当事人提出的异议，应当审查。异议成立的，裁定转由合议庭审理；异议不成立的，裁定驳回。

### 3. 回避制度

回避制度，是指审判人员、辅助审判工作的有关人员遇有法律规定不宜参加案件审理或者参加有关诉讼活动的情形时，退出案件审理活动或者有关诉讼活动的制度。回避制度的内容包括：回避适用人员和回避的法定事由两项。回避适用的人员包括：①审判人员；②法官助理、书记员、司法技术人员、翻译人员、鉴定人、勘验人；③检察人员从事民事检察活动，遇有法定情形也应依法回避。回避的法定事由包括：①是本案当事人或者当事人、诉讼代理人近亲属的；②与本案有利害关系的；③与本案当事人、诉讼代理人有其他关系，可能影响对案件公正审理的；④审判人员接受当事人、诉讼代理人请客送礼，或者违反规定会见当事人、诉讼代理人的，当事人有权要求他们回避。

### 4. 两审终审制度

两审终审制度，是指民事纠纷经过两级法院审判后即告终结的制度。两审终审制度的内容包括：①对于允许上诉的民事纠纷，在一审裁判作出以后，当事人不服一审裁判提出上诉，只要符合法定的上诉条件，二审法院都应当受理。由于二审法院作出的裁判为终审裁判，因此当事人不得就此再提起上诉。需要说明的是，并非所有的民事案件都实行两审终审。如最高人民法院作为一审法院所作的裁判都是终审裁判；《民事诉讼法》规定按照小额诉讼程序、特别程序、督促程序以及公示催告程序审理的案件，一律实行一审终审：②两审终审反映的是法律允许上诉的案件可以经过两个不同的审级法院独立进行审理。只有在一审法院裁判后，当事人不服，在法定期间内提交上诉书，一审法院将有关诉讼文书、案卷移交二审法院，才能使两个审级相互衔接、协调，从而发挥两个审级的不同作用。③虽然两个审级法院都对案件事实和适用法律进行审理，但是由于二审法院对一审法院具有的监督作用，因此，一审、二审的审理方式、所作的裁判种类以及裁判的效力等方面都有所不同。
