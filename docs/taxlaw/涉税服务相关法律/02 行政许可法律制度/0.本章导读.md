# 第二章 行政许可法律制度

## 本章导读

作为行政行为法的重要组成部分，本章主要内容包括有关行政许可的基本概念、理论以及有关行政许可设定和实施的一些基本制度。学习本章时，应全面学习行政许可及其相关概念、行政许可法的基本原则、行政许可设定，以及实施行政许可的基本程序要求。有关行政许可实施，主要是全面理解和把握关于行政许可实施程序的规范要求、许可监管制度以及违反行政许可法的法律责任。

**【学习方法提示】**

学习本章内容，应将行政许可与行政审批、行政确认、行政登记等相关基本概念进行比较，有助于准确理解行政许可的法律内涵、判断行政许可行为。行政许可听证制度需要与行政处罚听证制度进行比较学习；有关行政许可设定权限，需要与行政处罚、行政强制设定权限对照学习；行政许可的撤销、注销、撤回、吊销，同样宜采用对比学习法。同时，需要将行政许可理论和制度与有关税务行政许可具体实践结合起来理解，用以指导税务行政许可实践。
