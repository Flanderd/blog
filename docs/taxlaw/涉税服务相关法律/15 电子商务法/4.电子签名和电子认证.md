# 第四节 电子签名和电子认证

## 一、电子签名的概念和特征

电子签名，是指数据电文中以电子形式所含、所附用于识别签名人身份并表明签名人认可其中内容的数据。数据电文，是指以电子、光学、磁或者类似手段生成、发送、接收或储存的信息。在现实社会中，以电子的形式开展交易时，传统交易时的手书签字和盖章无法进行，必须依靠电子技术手段替代传统的手书签字和盖章，这种电子技术手段就是电子签名。电子签名具有以下特征：①电子签名是以电子形式出现的数据。电子签名可以确保电子文件在传输和存储过程中的完整性。②电子签名表达了签署者的意愿。电子签名是附着于数据电文的。电子签名可以是数据电文的一个组成部分，也可以是数据电文的附属，与数据电文具有某种逻辑关系，能够使数据电文与电子签名相联系。③具有身份识别功能。电子签名必须能够识别签名人身份并表明签名人认可与电子签名相联系的数据电文的内容。④电子签名具有不可抵赖性。签署者不能否认自己对电子文件的签名行为。

电子签名形式多样，如电子化签名、密码签名、生物特征签名、数字签名等。

::: tip 【电子签名形式示例】
**1. 电子化签名**

甲公司与员工订立电子合同，员工先在纸上手写签名，然后使用扫描仪将签名扫描为图像文件，再将该图像插入到电子合同的签名栏中，最后保存合同。

**2. 密码签名**

乙在在线交易平台确认交易时，输入预先设置的密码“123456”，系统验证密码正确后，自动记录签名行为，并在交易记录中标注签名时间。

**3. 生物特征签名**

某金融机构客户丙在签署贷款文件时，通过指纹识别设备按压手指，设备采集指纹数据并与客户预先注册的指纹模板匹配，验证通过后自动完成签名。

**4. 数字签名**

丁向戊发送了一份电子文档，丁先对文档内容计算哈希值（注：是指通过哈希函数对输入数据进行数学运算生成的固定长度输出），然后用自己的私钥对哈希值加密生成数字签名，将签名和文档一起发送给乙。戊收到后，用丁的公钥解密签名得到哈希值，再对文档计算哈希值，对比两个哈希值是否一致，以验证文档的真实性和完整性。
:::

《电子签名法》规定，电子签名与手写签名、盖章具有同等的法律效力。民事活动中的合同或者其他文件、单证等文书，当事人可以约定使用或不使用电子签名、数据电文。当事人约定使用电子签名、数据电文的文书，不得仅因为其采用电子签名、数据电文的形式而否定其法律效力。能够有形地表现所载内容，并可以随时调取查用的数据电文，视为符合法律、法规要求的书面形式。可靠的电子签名与手写签名或者盖章具有同等的法律效力。可靠的电子签名应具备的条件：①电子签名制作数据用于电子签名时，属于电子签名人专有；②签署时电子签名制作数据仅由电子签名人控制；③签署后对电子签名的任何改动能够被发现；④签署后对数据电文内容和形式的任何改动能够被发现。法律规定当事人也可以选择使用符合其约定的可靠条件的电子签名。妥善保管电子签名制作数据是电子签名人的法律义务。电子签名人知悉电子签名制作数据已经失密或者可能已经失密时，应当及时告知有关各方，并终止使用该电子签名制作数据。根据法律规定，不适用电子签名的情形包括：①涉及婚姻、收养、继承等人身关系；②供水、供气、供电、供热等公共事业服务；③法律法规规定的不适用电子文书的其他情形。

::: tip 【提示】电子签名的法律效力
电子签名是数据电文中以电子形式所含、所附，用于识别签名人身份并表明签名人认可其中内容的数据。可靠的电子签名与手写签名或盖章具有同等法律效力。

在学习电子签名的法律效力的内容时，应当掌握电子签名的可靠性条件是电子签名制作数据的专有性、控制性，以及对签名和数据电文内容、形式改动的可发现性。电子签名的适用范围，尤其应当注意到电子签名不适用的特定情形，如涉及婚姻、继承等文书。关注司法实践中法院是如何通过第三方电子认证和数字签名验证报告等证据，来认定电子签名的法律效力。

对于伪造、冒用、盗用他人电子签名可能构成犯罪，并需承担相应的法律责任。
:::

## 二、电子认证的规则

### 1. 电子认证的概念和特征

电子认证是利用电子技术对某个实体的身份、信息或合法性的确认过程。它通过数字证书、时间戳和其他安全机制来验证信息的来源、完整性和真实性。电子认证的特征：①安全性。电子认证利用加密技术确保数据在传输过程中的完整性和保密性。②身份验证。它能够验证参与电子交易的各方身份真实性。③不可否认性。电子认证可以确保一方发送信息，无法否认曾发送过的该信息，为争议的事实提供证据。④便捷性。电子认证的验证过程快速且安全。

根据不同的认证需求和使用场景，电子认证可以分为：①数字证书认证。由可信的第三方机构（如数字证书认证中心）颁发的电子文档，确认持证人身份。②时间戳认证。为特定信息生成唯一的时间戳，证实信息在某一时刻存在。③生物特征认证。利用个体独特的生物特征（如指纹、面部识别等）进行生物验证。④单点登录认证。用户只需一次登录即可访问多个应用系统。电子认证可以在电子商务、电子政务、金融服务、医疗健康、教育等多个场景中得到应用。

::: tip 【电子认证种类示例】
**1. 数字证书认证**

中国金融期货交易所以为了满足金融行业对安全的要求，选择国内权威第三方电子认证服务机构上海 CA 构建基于数字证书的身份认证体系。

操作过程：部署基于数字证书的强身份认证体系，用数字证书取代传统的“账号＋口令”的弱身份认证方式，对系统用户进行强身份认证升级，确保用户的身份有效性。部署 SSL 通道，实现加密传输，为信息系统部署 SSL 加密传输，确保信息在传输过程中的安全与完整。其作用是为实现网络应用信息传输的保密性、数据交换的完整性、发送信息的不可否认性、交易者身份的确定性。

**2. 时间戳认证**

甲律师事务所向国内权威第三方可信时间戳服务机构联合信任时间戳服务中心申请证据保全，联合信任时间戳服务中心签发《可信时间戳认证证书》。

操作过程：登录“联合信任时间戳服务中心”网站，点击“电子证据固化保全服务”，注册账号。在“网页取证”页面输入申请人信息和要取证的网址，点击在线充值，支付费用后点击取证。取证完成后，点击立即固化证据，下载证据。使用 Adobe PDF 阅读器打开认证证书，查看证书附件，将 .tee 格式文件保存到电脑中并重命名为 .zip 格式，解压缩后即可查看证据内容。其作是为证明电子文件在某一时间点是已经存在的、完整的、可验证的，具备法律效力，主要用于电子文件防篡改和事后抵赖，确定电子文件产生的准确时间。

**3. 生物特征认证**

华为云介绍了生物特征识别技术的应用案例。
操作过程：这种技术通过识别生物体的生理特征，如指纹、人脸、虹膜等，实现身份验证、门禁控制、金融支付等功能。其作是提供了一种便捷、安全的身份认证方式，相比传统的密码或卡片认证，生物特征认证具有更高的安全性和难以复制性。

4. 单点登录认证

单点登录认证通常用于企业内部系统或多个相关联的系统中，用户只需登录一次，即可访问所有相互信任的应用系统。

操作过程：用户在首次登录时进行身份认证，系统会生成一个令牌或会话标识，用户在访问其他系统时，系统通过验证令牌或会话标识来确认用户身份，无需再次输入用户名和密码。其作用是提高了用户体验，减少了重复登录的麻烦，同时也有助于提高系统的安全性，因为用户只需记住一个用户名和密码。

:::

### 2. 电子认证的规则

电子认证的规则主要包括认证机构的管理、证书的签发与管理、用户的责任与义务等方面。

（1）认证机构的管理规则。①资质与合规性。电子认证服务机构必须依法取得资质，并遵守国家相关法律法规和主管部门的规定。主张电子签名有效的一方当事人为了证明是“可靠的电子签名”，一般会向法院提交电子认证服务提供者出具的相关证明材料，其中包括用以证明第三方认证机构具备提供电子认证服务资质的有关证书，如《电子认证服务许可证》、营业执照等。②安全与保密。认证机构需建立完善的安全机制，确保私钥的安全存放和保护，防止信息泄露。③业务规范。认证机构应制定详细的业务规则，明确证书签发、更新、吊销等流程，并向用户公开。

（2）证书的签发与管理规则。认证机构在收到用户申请后，需对申请信息进行验证和鉴别，确保信息真实准确后签发证书。证书持有者可在证书到期前或到期后一定期限内申请更新，更新时需验证原证书及相关信息。认证机构在发现证书被不当使用或存在安全风险时，有权吊销证书，并及时通知用户。

（3）用户的责任与义务。①信息真实性。用户在申请证书时必须提供真实、完整、准确的信息，并在信息变更时及时通知认证机构。②密钥管理。用户需妥善保管私钥和密码，防止泄露或被未经授权使用。如私钥丢失或泄露，用户应立即申请吊销证书。③合法使用。用户应将证书用于合法目的，遵守用户协议约定的使用范围和条件。
