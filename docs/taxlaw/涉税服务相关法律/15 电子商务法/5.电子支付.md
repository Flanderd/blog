# 第五节 电子支付

## 一、电子支付的概念和特征

电子支付，是指通过电子方式，利用电子设备和网络技术进行的货币支付或资金转移的行为。电子支付具有以下特征：①技术性。电子支付都是通过数字化的方式进行款项支付的。②安全性。电子支付以加密技术、数字签名、身份认证等手段确保支付过程的安全。③高效性和便捷性。电子支付需要使用先进的通信手段，它具有便利、快捷、高效、经济的优点。④国际化。电子支付支持跨境支付，满足国际贸易和跨国商务需求。⑤可溯源性。电子支付的每一笔交易都会留下详细的电子记录，它可为审计、对账、和纠纷解决提供证据。电子支付的常见形式可以有网上支付、移动支付、电话支付、销售点终端交易（POS）和自动柜员机交易（ATM）。

## 二、电子支付法律关系

电子支付的法律关系，是指在电子支付活动中，各参与主体之间依法形成的权利义务关系。电子支付法律关系的主体包括发端人、受益人、银行及支付机构和认证机构。发端人（电子支付中的付款人），是指根据其与发端人银行所订立的服务协议，向发端人银行发出付款指示的人。受益人（电子支付中的收款人），是指根据其与受益人银行的服务协议，要求受益人银行适当接受所划拨资金的人。银行及支付机构（包括发端人银行、受益人银行、中间银行以及非银行支付机构），是指电子支付中承担支付中介和结算中介的金融信用机构。认证机构，是指在网上为参与电子商务各方提供各种认证要求、证书服务、确认用户身份而建立的一种权威的、可信赖的、公正的第三方机构。电子支付法律关系的内容涉及多种合同关系：①商务合同关系，如发端人与受益人交易形成的商务合同关系；②金融服务合同关系，如发端人、受益人与银行或支付机构之间基于服务协议形成的金融服务合同关系；③委托保管关系，在第三方支付中，买卖双方委托支付机构代为收取、保管和转移资金，形成委托合同或保管合同关系；④担保关系，第三方支付机构在一些业务中为确保资金安全而可能承担的担保责任；⑤认证服务合同关系，认证机构与用户之间因提供身份认证服务而形成的认证服务合同。电子支付法律关系的客体，是指电子支付行为，如通过电子终端发出支付指令，实现货币支付与资金转移的行为。

::: info 【电子支付法律关系示例】
电子支付法律关系涉及多个主体和多种合同关系，其法律性质和效力受到相关法律法规的规范。在实际操作中，各主体需明确自身的权利和义务，确保电子支付的安全性和合法性。

1. 电子转账

主体：付款人（发端人）、付款人银行（发端人银行）、收款人（受益人）、收款人银行（受益人银行）。

过程：买卖合同中，付款人向付款人银行发出付款指示，要求将指定金额移转给收款人。付款人银行按支付程序向收款人银行传送该金额。收款人银行在收款人账户中贷记该金额，完成托收。

法律关系：付款人与收款人之间存在买卖合同关系，电子支付为付款手段。付款人与付款人银行之间存在金融服务合同关系。收款人与收款人银行之间存在金融服务合同关系。付款人银行与收款人银行之间存在资金清算关系。

2. 第三方支付（如支付宝）

主体：付款人（消费者）、收款人（商家）、第三方支付平台、银行。

过程：付款人通过第三方支付平台向收款人发起支付请求。第三方支付平台将付款请求转发至付款人银行。付款人银行从付款人账户中扣除相应金额，并将资金划转至第三方支付平台。第三方支付平台将资金划转至收款人银行，收款人银行在收款人账户中贷记该金额。
法律关系：付款人与收款人之间存在买卖合同关系。付款人与第三方支付平台之间存在支付服务合同关系。第三方支付平台与银行之间存在资金清算关系。收款人与收款人银行之间存在金融服务合同关系。

3. 自动划账

主体：收款人（受益人）、收款人银行（受益人银行）、付款人（发端人）、付款人银行（发端人银行）。

过程：收款人通过收款人银行向付款人银行发起借记请求。付款人银行从付款人账户中扣除相应金额。付款人银行将资金划转至收款人银行。收款人银行在收款人账户中贷记该金额。

法律关系：收款人与付款人之间存在债权债务关系。收款人与收款人银行之间存在金融服务合同关系。付款人与付款人银行之间存在金融服务合同关系。付款人银行与收款人银行之间存在资金清算关系。

4. 电子支付中的认证服务

主体：付款人、收款人、银行、认证机构。

过程：付款人和收款人在进行电子支付时，通过认证机构进行身份认证。认证机构验证双方身份，确保交易的安全性。

法律关系：付款人与认证机构之间存在认证服务合同关系。收款人与认证机构之间存在认证服务合同关系。认证机构为银行提供认证服务，确保交易的合法性。
