# 第十五章 电子商务法

## 本章导读

本章是关于电子商务法的内容。电子商务法，是指调整电子商务活动中形成的各种法律关系、规范电子商务活动的法律规范的总和。本章内容包括电子商务法概述、电子商务经营主体、电子商务合同的订立和履行、电子签名和电子认证、电子支付、电子商务税收法律等。电子商务法概述是掌握电子商务法知识体系的起点和基础。它定义了“什么是电子商务”“什么是电子商务法”，并明确了法律的基本原则和调整对象。电子商务经营主体是电子商务活动的起点。法律规定了电子商务经营者（如平台、平台内商家、自建网站经营者等）的准入条件、资质审核、信息公示等义务。只有明确了合法的“玩家”，后续的交易行为才有了明确的主体。电子签名与认证是为电子商务活动正常开展提供信任基础。它为经营主体提供了在网络空间中的“数字身份证”，通过可靠的电子签名和第三方认证，确保了交易主体的真实性和不可抵赖性，为订立具有法律效力的合同扫清了障碍。电子商务合同的订立与履行是电子商务活动的核心。它规范了从商品展示（要约邀请/要约）、下单（承诺）到合同成立、履行、违约责任的整个流程。这个环节将前序的“主体”和“信任”转化为具体的、受法律保护的商业承诺。电子支付是电子商务合同履行的核心步骤。它规范了支付指令的发出、资金的转移以及支付过程中各方的权利义务。没有安全、高效的电子支付，合同的履行就无法完成，交易也就无从谈起。电子商务税收是电子商务经营主体的最终法定义务。它确保了线上交易与线下交易一样，需要依法纳税，维护了市场的公平竞争和国家财政收入。这是整个交易闭环的最后一环，也是对经营活动的最终法律规制。

## 学习方法提示

在本章学习中，应熟悉电子商务经营主体的不同种类，各类电子商务主体的各自权利义务。在学习电子商务合同内容时，应掌握电子商务合同订立过程、履行及相关责任的法律规则。在学习电子支付相关内容时，应正确理解电子支付的基本概念，辨析电子支付涉及的各种法律关系、支付方式、支付流程、安全机制以及相关法律责任。在学习电子签名、电子认证内容时，应明辨行为的真实性、法律效力、技术要求、操作流程以及相关的法律责任。学习电子商务税收法律内容时，应当从纳税主体的确定、纳税地点的确认、纳税义务的发生时间、税收征管的法律依据、电子发票的管理、税收优惠政策等方面把握。学习电子商务法需要有体系化思维的学习方法。应以《电子商务法》为绝对核心，重点在于认识并理解经营者的定义、平台的义务、争议解决等基础规则。电子商务法是跨领域的，必须结合其他法律来理解。如：在交易环节应结合《民法典》（特别是合

同编），理解电子合同何时成立、电子签名的效力；在数据环节结合《个人信息保护法》和《网络安全法》，理解数据合规的底线。
