# 第十四章 破产法

## 本章导读

本章主要介绍企业破产的法律规定。企业破产法是规范市场主体退出的法律，兼具实体法与程序法双重性质，其核心在于通过规范重整、和解与清算三种程序，公平清理债权债务，保护各方合法权益，维护市场经济秩序。企业破产法属于社会主义市场经济的基础性法律，适用于中国境内的所有企业法人，并对债务人在中国境外的财产发生效力。

破产制度由清算制度、重整制度与和解制度三部分构成。破产清算制度能够让债务人依法退出市场，破产重整制度与和解制度能够让“濒临死亡”的债务人“起死回生”，通过破产程序焕发新的生机与活力。

为正确适用《中华人民共和国企业破产法》（以下简称《企业破产法》），最高人民法院陆续发布了多项司法解释，如《关于适用〈中华人民共和国企业破产法〉若干问题的规定》（一）、（二）、（三）（即《企业破产法》解释一、二、三）。其中，解释一对破产原因的认定、破产申请的受理，解释二对债务人财产的认定和处理，解释三对债权人权利行使等具体法律适用问题做出了更加细致的规定，为破产清算的顺利进行提供了法律保障。

本章分六节对企业破产法进行讲解。其中：

第一节破产法概述，包括破产与破产法、破产原因、破产案件的管辖、破产管理人。

第二节破产申请，包括破产申请的提出、破产申请的受理与驳回、破产申请受理的法律后果。

第三节破产债权，包括破产债权概述、破产债权申报、债权人会议、债权人委员会。

第四节债务人财产，包括债务人财产的范围、债务人财产的认定处分与保全、债务人财产处分的撤销与追回、破产别除权取回权与抵销权、破产费用与共益债务。

第五节重整与和解，包括重整、和解。

第六节破产清算，包括破产宣告、破产财产的变价与分配、破产终结。

## 学习方法提示

学习本章，应重点关注破产企业清算、重整、和解等不同程序的适用条件，以及债权人权益保护。按照考试大纲的要求，重点掌握破产原因、破产申请的提出与受理的法律后果、破产债权申报、债权人会议、债务人财产的范围及债务人财产处分的撤销与追回等内容；了解破产案件管辖、破产债权、和解、破产终结等内容；熟悉破产申请的受理，债权人委员会，债务人财产的认定处分与保全，破产别除权、取回权、抵销权，破产费用和共益债务，重整，破产宣告，破产财产的变价与分配等内容。此外，还需结合实际案例理解掌握并综合运用《企业破产法》有关条文及其司法解释的相关规定。
