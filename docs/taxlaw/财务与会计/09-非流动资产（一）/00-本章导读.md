# 第九章 非流动资产（一）

## 本章导读

本章主要介绍非流动资产中固定资产、无形资产的取得、后续计量、处置、减值的核算。

1. 固定资产是企业为了生产商品、提供劳务、出租或经营管理而持有的，同时其具有一定的耐用性，使用寿命要超过一个会计年度并具有实物特征。企业取得固定资产应按成本进行初始计量。

2. 企业应对所有固定资产计提折旧，但是，已提足折旧仍继续使用的固定资产和单独计价入账的土地除外。企业可选用的折旧方法包括年限平均法、工作量法、双倍余额递减法和年数总和法等。

3. 无形资产是企业拥有或控制的没有实物形态的可辨认非货币性资产，主要包括专利权、非专利技术、商标权、著作权、土地使用权、特许权、数据资源等。

4. 企业取得无形资产应按成本进行初始计量。企业内部研究开发项目的支出，应当区分研究阶段支出与开发阶段支出，进行相应的会计处理。后续计量中，使用寿命有限的无形资产，应在使用寿命内系统合理摊销其成本；使用寿命不确定的无形资产，其成本不做摊销处理，期末开展减值测试并确定其价值。

5. 固定资产、无形资产等资产存在减值迹象的，应当估计其可收回金额，根据资产的公允价值减去处置费用后的净值与资产预计未来现金流量的现值两者之间较高者确定。减值损失一经确认，在以后会计期间不得转回。

6. 企业主要通过出售而非持续使用一项非流动资产或处置组收回其账面价值，应当将其划分为持有待售类别。持有待售的非流动资产或处置组中的非流动资产不应计提折旧或摊销，若账面价值高于公允价值减去出售费用后的净额的，应确认资产减值损失和计提持有待售资产减值准备。
