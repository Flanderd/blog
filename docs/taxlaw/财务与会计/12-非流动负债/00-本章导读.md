# 第十二章 非流动负债

## 本章导读

本章主要介绍借款费用的核算、应付债券的核算、其他非流动负债的核算、预计负债的核算。

1. 借款费用是指企业因借入资金所付出的代价，在会计处理上分为资本化和费用化。借款费用的核算包括其确认、计量和账务处理。

2. 应付债券是企业举借长期债务、依照法定程序对外发行、约定在一定期限内还本付息的有价证券。其核算包括利息费用的确认和计量、普通公司债券的账务处理、应付可转换公司债券的账务处理。

3. 其他非流动负债核算包括长期借款、长期应付款、专项应付款的相关账务处理。

4. 预计负债核算是对与或有事项相关的义务进行的会计处理，包括确认、计量和账务处理。
