# 第十一章 流动负债

## 本章导读

本章主要介绍应付账款和应付票据的核算、应交税费的核算、应付职工薪酬的核算、其他流动负债的核算。

1. 应付账款和应付票据是企业日常经营购进业务产生的负债。
2. 企业应对应交税费的确认、计提和缴纳情况进行全面准确的会计核算，尤其是增值税、消费税、资源税、土地增值税，包括科目设置、记账依据、税款确认与计量、账务处理等。
3. 职工薪酬是指企业为获得职工提供的服务或解除劳动关系而给予的各种形式的报酬或补偿。应付职工薪酬的核算包括各类薪酬的确认和计量、账务处理，以及现金结算的股份支付的账务处理。
4. 其他流动负债包括短期借款、预收账款、受托代销商品款、以公允价值计量且其变动计入当期损益的金融负债、应付利息、应付股利、其他应付款，其他流动负债的核算包括这些项目的确认和计量、账务处理。
