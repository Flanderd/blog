# 第五章 营运资金管理

## 本章导读

本章主要介绍营运资金管理的概念及其策略、现金管理的方法、应收账款的成本及其管理、存货的成本及其日常控制。

1. 营运资金是指在企业生产经营活动中占用在流动资产上的资金。营运资金的管理既包括流动资产的管理，也包括流动负债的管理。

2. 采用存货模式确定最佳现金持有量时，主要考虑机会成本和转换成本，持有现金的总成本为两者之和。最佳现金持有量是使持有现金总成本最低的现金持有量。

3. 应收账款作为企业为增加销售和盈利进行的投资，会发生一定的成本，主要包括应收账款的机会成本、管理成本、坏账成本和收账成本四部分。

4. 存货的总成本包括取得成本、储存成本和缺货成本。企业存货的最优化就是使企业存货总成本最小。

5. 短期借款是企业根据借款合同向银行和其他非银行金融机构借入的期限在 1 年以内的款项。短期借款的信用条件包括信用额度、周转信用协议、补偿性余额、借款抵押、偿还条件和其他承诺。短期借款的成本计算方法主要有收款法、贴现法和加息法。

6. 商业信用产生于企业生产经营的商品、劳务交易之中，是一种“自发性筹资”。商业信用的形式主要包括应付账款、应付票据、预收货款和应计未付款。
