# 2026 年税务师《财务与会计》

> **本板块定位**：税务师（CTA）考试科目《财务与会计》的全套教材笔记，按 2026 年度官方教材（中国税务出版社）逐章整理，内容分**上编 财务管理**（第 1–6 章）与**下编 财务会计**（第 7–19 章）两部分，覆盖从财务管理基础到破产清算会计的全部考点。

## 快速入口

- [教材目录](./00-目录.md)：全部 19 章的节级清单，附原书 PDF 页码，便于回查；
- [考试大纲（2026 年度）](./附录/《财务与会计》考试大纲（2026年度）.md)：官方考纲原文。

## 内容结构

| 编 | 章节 | 主题 |
| --- | --- | --- |
| 上编 财务管理 | 第 1–6 章 | 财管概论与基础、预测与预算、筹资与股利分配、投资管理、营运资金管理、财务分析与评价 |

## 阅读提示

1. 全书按「章一文件夹、节一文件」组织：`00-本章导读.md` 为章首导读，`01-…`、`02-…` 依次为各节；每节末尾以 HTML 注释标注对应的 PDF 页码，便于回查原书核对；
2. 例题统一用 `::: info` 提示框包裹，框内保留题干与解析；原书的灰底【提示】【注意】方框用 `::: tip` 保留；
3. 公式统一转为 LaTeX：行内符号用 `$…$`（如 $F_1$、$\mathrm{TC}_a$、$\sigma_p$、$P/E$），独立成行的公式用 `$$…$$`，多行连等式用 `aligned` 环境，渲染后与教材排版一致；
4. 会计分录以 `text` 代码块保留「借／贷」层级与金额；财务报表类表格转为 Markdown 表格，跨页续表在表前标注「（续表）」；
5. 原书插图（图 5-1 流动资产融资策略、图 6-1 杜邦分析图、图 14-1 产品成本核算程序）已裁切为图片单独保留；
6. 上下编相互独立又彼此支撑：上编的货币时间价值、风险与收益是下编长期资产折现计量（如资产减值测试）的工具基础，建议先读上编第 1 章。
