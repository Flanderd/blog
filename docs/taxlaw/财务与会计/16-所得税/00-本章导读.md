# 第十六章 所得税

## 本章导读

本章主要介绍所得税会计的相关知识和资产、负债的计税基础及暂时性差异，递延所得税资产及递延所得税负债的确认与计量，所得税费用的确认和计量。

1. 我国所得税会计采用资产负债表债务法，资产负债表债务法较为完全地体现了资产负债观，在所得税的会计核算方面贯彻了资产、负债的界定。

2. 暂时性差异是资产、负债的账面价值与其计税基础不同产生的差额。根据暂时性差异对未来期间应纳税所得额的影响，可分为应纳税暂时性差异和可抵扣暂时性差异。

3. 在计算确定可抵扣暂时性差异与应纳税暂时性差异后，应按照准则规定的原则确认相关的递延所得税资产与递延所得税负债。
