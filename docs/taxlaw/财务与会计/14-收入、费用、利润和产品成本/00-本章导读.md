# 第十四章 收入、费用、利润和产品成本

## 本章导读

本章主要介绍收入的确认和计量、期间费用的种类、产品成本核算与利润的计算以及政府补助的会计核算。

1. 企业应当在客户取得相关商品控制权时确认收入，收入的金额应当反映企业因转让这些商品或提供这些服务而预期有权收取的对价金额，以如实反映企业的生产经营成果。

2. 企业应按照权责发生制和配比原则划清生产费用和非生产费用的界限，生产费用和产品成本的界限，以及生产费用和期间费用的界限，期间费用应直接计入当期损益。

3. 利润是企业在一定期间的经营成果，包括收入减去费用后的净额、直接计入当期利润的利得和损失。企业实现的净利润应按照一定的顺序分配。

4. 政府补助是指企业从政府无偿取得的货币性资产或非货币性资产，但不包括政府作为企业所有者投入的资本。可以选择总额法和净额法进行会计处理。

5. 产品成本是企业在生产产品过程中所发生的材料费用、职工薪酬等，以及不能直接计入而按一定标准分配计入的各种间接费用。产品成本计算方法主要有品种法、批发和分步法。
