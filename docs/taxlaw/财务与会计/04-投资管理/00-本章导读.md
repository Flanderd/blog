# 本章导读

## 【本章导读】

本章主要介绍固定资产投资管理、有价证券投资管理、公司并购与收缩的相关内容。

1.固定资产投资决策建立在投资项目现金流估算基础上，项目的现金流量由建设期现金流量、经营期现金流量、终结期现金流量三部分组成。

2. 固定资产投资决策方法分为非贴现法和贴现法。其中，非贴现法包括投资回收期法和投资回报率法。贴现法包括净现值法、年金净流量法、内含报酬率法和现值指数法。

3. 股票的估价模型主要有股票估价的基本模型、零增长模型、固定增长模型和阶段性增长模型四种。债券的估价模型主要有一年付息一次的债券估价模型、到期一次还本付息的债券估价模型以及贴现发行债券的估价模型三种。

4.企业价值评估是并购方制定合理支付价格范围的主要依据。企业价值评估模式大致可分为两类：折现式价值评估模式和非折现式价值评估模式。其中，现金流量折现模式是折现式价值评估模式中最为科学的一种，非折现式价值评估模式包括市盈率法、账面资产净值法和清算价值法等。

5.公司收缩是指对公司的股本或资产进行重组从而缩减主营业务范围或缩小公司规模的各种资本运作方式。其主要方式有资产剥离、公司分立和分拆上市等。

投资是指企业把资金直接或间接投放于一定对象，以期望在未来获取收益的经济活动，它对企业的重要意义在于：①投资是企业获得利润的前提。②投资是企业生存和发展的必要手段。③投资是企业降低风险的重要途径。

与日常经营活动相比，企业投资的主要特点表现在以下三方面：①属于企业的战略性决策。企业的投资活动一般涉及其未来的经营发展方向、生产能力与规模等问题，如厂房设备的新建与更新、新产品的研制与开发、对其他企业的股权控制等，对企业经营活动的方向产生重大影响。②属于企业的非程序化管理。企业的投资项目涉及的资金数额较大。

企业对于这类非重复性特定经济活动，应根据特定的影响因素、相关条件和具体要求来进行审查和抉择。③投资价值的波动性大。投资项目的价值是由投资标的物资产的内在获利能力决定的。这些标的物资产的形态是不断转换的，未来收益的获得具有较强的不确定性，其价值也具有较强的波动性。

投资是一项很复杂的经济活动，为了加强管理和提高投资收益，有必要对投资进行科学的分类。比如，按投资回收期限的长短，投资可分为短期投资和长期投资；按投资活动资金投出的方向，投资可分为对内投资与对外投资：按投资活动与公司本身的生产经营活动的关系，投资可分为直接投资与向接投资。
