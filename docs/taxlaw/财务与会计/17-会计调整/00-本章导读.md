# 第十七章 会计调整

## 本章导读

本章主要介绍会计政策变更、会计估计变更、前期差错更正以及资产负债表日后事项的概念及其会计处理。

1. 按照会计信息质量的可比性原则，企业采用的会计政策，在每一会计期间和前后各期应当保持一致，不得随意变更。如需变更，应根据不同情况采用追溯调整法或未来适用法的进行会计处理。

2. 企业应当根据会计准则的规定，结合本企业的实际情况，确定会计估计。企业的会计估计一经确定，不得随意变更。如需变更应采用未来适用法进行会计处理。

3. 前期差错通常包括计算错误、应用会计政策错误、疏忽或曲解事实以及舞弊产生的影响等。前期差错更正应根据不同情况采用追溯重述法或未来适用法进行会计处理。

4. 资产负债表日至财务报告批准报出日之间发生的有利或不利事项，都属于资产负债表日后事项，具体包括资产负债表日后调整事项和资产负债表日后非调整事。
