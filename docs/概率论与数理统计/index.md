# 概率论与数理统计

> **一句话概括**：概率论研究"随机现象有什么规律"，数理统计研究"如何用有限的观测反推这些规律"。前者从模型推数据，后者从数据推模型，方向相反，工具相连。

## 这门课在讲什么

很多人学完一学期，公式记了一堆，却说不清这课到底在干嘛。其实整门课只有一条主线：

```
现实中的随机现象
   │  ① 抽象
   ▼
概率模型（样本空间 + 概率分布 + 参数 θ）        ← 概率论：已知模型，算数据
   │  ② 抽样
   ▼
观测数据 x₁, x₂, …, xₙ
   │  ③ 反推
   ▼
关于 θ 的结论 + 不确定性                          ← 数理统计：已知数据，猜模型
```

- **第 1–8 章是概率论**：给定模型，推断"数据会长什么样"。核心问题是"分布"。
- **第 9–14 章是数理统计**：给定数据，反推"模型长什么样"。核心问题是"估计与检验"。

第 8 章（大数定律与中心极限定理）是两部分的**铰链**：它解释了为什么"样本均值"能稳定地指向总体均值——没有它，后面所有推断都失去合法性。

## 学习路径

**零基础路线（推荐，约 60–80 小时）**

1. **第 1–3 章**：建立"随机"的语言。重点不是算得多快，而是能把一段文字翻译成事件与条件。
2. **第 4–5 章**：进入"分布"的世界。务必把二项、泊松、正态三者的关系画在一张图上。
3. **第 6–7 章**：多维与数字特征。协方差与相关系数是后面回归的地基。
4. **第 8 章**：全书最重要的一章。中心极限定理不理解的，后面全是背公式。
5. **第 9–11 章**：统计推断三部曲——抽样分布 → 估计 → 检验。这三章要连着学，不要拆开。
6. **第 12–14 章**：应用方法，按需选学。

**考前速通路线**：第 2、3、5、7、8、10、11 章，覆盖 80% 的考点。

## 符号约定

| 符号 | 含义 |
| --- | --- |
| $\Omega$ | 样本空间；$\omega$ 为样本点 |
| $A, B, C$ | 随机事件（$\Omega$ 的子集） |
| $\bar{A}$ | $A$ 的对立事件（也写作 $A^c$） |
| $P(A)$ | 事件 $A$ 的概率 |
| $X, Y, Z$ | 随机变量；取值记作 $x, y, z$ |
| $F(x)$ | 分布函数，$F(x)=P(X\le x)$ |
| $f(x)$ | 连续型的概率密度 |
| $E(X),\ \mathrm{Var}(X)$ | 期望、方差（也写作 $DX$、$\sigma^2$） |
| $\mu,\ \sigma^2$ | 总体均值、总体方差（参数） |
| $\bar{X},\ S^2$ | 样本均值、样本方差（统计量） |
| $\Phi(x)$ | 标准正态分布函数 |
| $z_\alpha,\ t_\alpha(n),\ \chi^2_\alpha(n)$ | 上 $\alpha$ 分位数 |

::: tip 关于"零基础"的三个提醒
1. **不要跳过例题**。概率的难点不在公式，而在"把中文翻译成事件"。这一步只能靠例题喂出来。
2. **每章末的习题请先自己做**，参考答案折叠着，是为了防止你"看懂了"的错觉。
3. **公式要手推一遍**。看懂推导和能独立推出来，是两种完全不同的掌握程度。
:::
