# 线性代数

> **一句话概括**：线性代数研究"线性关系"——可以相加、可以按比例放大的东西之间的关系。它把一堆方程、一组数据、一个变换，统一写成矩阵，再用同一套语言处理。

## 这门课的主线

很多教材按"行列式 → 矩阵 → 向量 → 方程组 → 特征值 → 二次型"排列，学完却不知道它们为什么在一起。其实整门课只有一条因果链：

```
线性方程组（问题）
   │  消元时只用到系数，于是把系数单独排成表
   ▼
矩阵（工具）── 运算、行列式、逆、秩
   │  把每一列看成一个向量，方程组的本质就露出来了
   ▼
向量组与线性相关性（本质）
   │  解的个数 = 未知数个数 − 秩
   ▼
解的结构（答案）
   │  换一个视角：矩阵是空间的变换
   ▼
特征值与对角化（变换的"骨架"）
   │  对称矩阵的对角化给出几何分类
   ▼
二次型与正定性（应用）
```

一句话记忆：**矩阵是方程组的"骨头"，向量是矩阵的"意思"，特征值是变换的"方向"，二次型是对称矩阵的"形状"。**

## 学习路径

1. **入门（1–4 章）**：先学会"解方程组"和"矩阵运算"，这是全课程的手艺活。行列式只需掌握计算与性质，不必纠结逆序数证明。
2. **核心（5–6 章）**：线性相关性与解的结构是整门课的思想核心。能否用"秩"解释"为什么有无穷多解"，是学没学懂的试金石。
3. **抽象（7 章）**：向量空间把所有具体例子统一起来。若目标是应试，可先略读，学完第九、十章再回看。
4. **主线（8–10 章）**：特征值 → 对角化 → 二次型，是一条完整的推理链，不要拆开背。
5. **应用（11 章）**：内积与最小二乘连接数据科学，SVD 是推荐系统与降维的数学基础。

## 符号约定

| 符号 | 含义 |
| --- | --- |
| $A, B$ | 矩阵；$a_{ij}$ 表示第 $i$ 行第 $j$ 列元素 |
| $A^{\mathrm{T}}$ | 转置；$A^{-1}$ 逆矩阵；$A^{*}$ 伴随矩阵 |
| $|A|$ 或 $\det A$ | 行列式 |
| $r(A)$ | 矩阵的秩 |
| $\alpha, \beta$ | 列向量 |
| $\mathbf{0}$ | 零向量或零矩阵（按上下文） |
| $E$ 或 $I$ | 单位矩阵 |
| $\lambda$ | 特征值；$\xi$ 特征向量 |
| $\mathbb{R}^n$ | $n$ 维实向量空间 |

::: tip 三个学习建议
1. **每一章都回到方程组**。秩、相关性、解的结构，说的其实是同一件事的三种语言。
2. **矩阵乘法不要背位置，要背"行乘列"**。$c_{ij}$ = 第 $i$ 行与第 $j$ 列对应相乘再相加。
3. **计算必须动手**。线性代数最容易"看懂了但算错了"，行列式与秩的计算要练到不出错。
:::
