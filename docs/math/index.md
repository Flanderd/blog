## 学习路径建议

1. **一元微积分**：第一至第五章，极限—导数—积分是整门课的主线；
2. **多元微积分**：第六至第八章，重点掌握链式法则与三大积分公式；
3. **级数与方程**：第九、第十章，级数判别与微分方程解法需要多练；
4. **几何与场论**：第十一、十二章，为后续物理与工程课程打基础。

::: tip 学习方法
微积分的关键是"定义—定理条件—计算方法"三层：先弄清定义，再记住定理成立的条件，最后才是刷题技巧。
每章的例题建议遮住解答独立完成，再对照检查。
:::
