# 第十章 常微分方程

> **本章定位**：微分方程是"含未知函数及其导数的方程"。本章按"一阶 → 可降阶 → 二阶常系数"的顺序，给出可解类型的识别方法与标准解法。

## 10.1 基本概念

- **阶**：方程中出现的最高阶导数的阶数；
- **通解**：含独立任意常数个数等于阶数的解；
- **特解**：确定常数后的解；
- **初值问题**：附加初始条件（如 $y(x_0)=y_0$）求特解；
- **线性/非线性**：未知函数及其各阶导数都是一次的为线性。

**方向场**：一阶方程 $y' = f(x,y)$ 在每点给出一个斜率，积分曲线处处与方向场相切。

## 10.2 可分离变量方程

形如

$$
\frac{\mathrm{d}y}{\mathrm{d}x} = f(x)g(y)
$$

当 $g(y)\ne0$ 时分离：

$$
\frac{\mathrm{d}y}{g(y)} = f(x)\,\mathrm{d}x
$$

两边积分得隐式通解：

$$
\int\frac{\mathrm{d}y}{g(y)} = \int f(x)\,\mathrm{d}x + C
$$

**例** $y' = xy$：

$$
\frac{\mathrm{d}y}{y} = x\,\mathrm{d}x \Rightarrow \ln|y| = \frac{x^2}{2} + C
\Rightarrow y = Ce^{x^2/2}
$$

::: warning 别忘了 $g(y)=0$ 的解
分离变量时除以 $g(y)$，可能丢掉 $g(y)=0$ 对应的常数解，需单独检查。
:::

## 10.3 齐次方程

形如

$$
\frac{\mathrm{d}y}{\mathrm{d}x} = \varphi\left(\frac{y}{x}\right)
$$

令 $u = \dfrac{y}{x}$，即 $y = ux$，则

$$
y' = u + xu'
$$

代入得

$$
u + xu' = \varphi(u) \Rightarrow x\frac{\mathrm{d}u}{\mathrm{d}x} = \varphi(u) - u
$$

化为可分离方程。

**例** $y' = \frac{y}{x} + \frac{x}{y}$：令 $u = y/x$，

$$
u + xu' = u + \frac{1}{u} \Rightarrow u\,\mathrm{d}u = \frac{\mathrm{d}x}{x}
\Rightarrow \frac{u^2}{2} = \ln|x| + C
$$

回代得 $y^2 = 2x^2\ln|x| + Cx^2$。

## 10.4 一阶线性方程

标准形：

$$
\frac{\mathrm{d}y}{\mathrm{d}x} + P(x)y = Q(x)
$$

### 10.4.1 常数变易法

先解齐次方程 $y' + Py = 0$：

$$
y = Ce^{-\int P\mathrm{d}x}
$$

设非齐次解为 $y = C(x)e^{-\int P\mathrm{d}x}$，代入得

$$
C'(x)e^{-\int P\mathrm{d}x} = Q(x)
\Rightarrow C(x) = \int Q(x)e^{\int P\mathrm{d}x}\mathrm{d}x + C
$$

故通解

$$
y = e^{-\int P\mathrm{d}x}\left[\int Q(x)e^{\int P\mathrm{d}x}\mathrm{d}x + C\right]
$$

**例** $y' + 2xy = x$：

$$
P = 2x,\quad e^{\int P\mathrm{d}x} = e^{x^2}
$$

$$
y = e^{-x^2}\left[\int xe^{x^2}\mathrm{d}x + C\right]
= \frac{1}{2} + Ce^{-x^2}
$$

::: warning 先化标准形
使用公式前必须把系数化为 1：$y' + P(x)y = Q(x)$，否则 $P$、$Q$ 取错。
:::

## 10.5 伯努利方程

$$
y' + P(x)y = Q(x)y^n\qquad(n\ne0,1)
$$

令 $z = y^{1-n}$，则

$$
z' = (1-n)y^{-n}y'
$$

两边乘 $(1-n)y^{-n}$ 化为线性方程：

$$
z' + (1-n)P(x)z = (1-n)Q(x)
$$

**例** $y' + \frac{y}{x} = y^2$：$n=2$，令 $z = y^{-1}$，得

$$
z' - \frac{z}{x} = -1
$$

解得 $z = Cx - x\ln|x|$，回代 $y = 1/z$。

## 10.6 可降阶的高阶方程

| 类型 | 代换 | 化为 |
| --- | --- | --- |
| $y^{(n)} = f(x)$ | 逐次积分 | $n$ 次积分 |
| $y'' = f(x,y')$ | $p = y'$ | $p' = f(x,p)$ |
| $y'' = f(y,y')$ | $p = y'$，$y'' = p\frac{\mathrm{d}p}{\mathrm{d}y}$ | 一阶方程 |

**例** $y'' = y'$：令 $p = y'$，$p' = p$，$p = Ce^x$，再积分得 $y = C_1e^x + C_2$。

## 10.7 二阶常系数齐次线性方程

$$
y'' + py' + qy = 0
$$

特征方程

$$
r^2 + pr + q = 0
$$

| 判别式 | 特征根 | 通解 |
| --- | --- | --- |
| $\Delta>0$ | $r_1\ne r_2$ | $y = C_1e^{r_1x} + C_2e^{r_2x}$ |
| $\Delta=0$ | $r_1=r_2=r$ | $y = (C_1 + C_2x)e^{rx}$ |
| $\Delta<0$ | $r = \alpha\pm\beta i$ | $y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$ |

**推导思路**：设 $y = e^{rx}$，代入得特征方程；重根时用降阶法得第二个线性无关解 $xe^{rx}$；复根时用欧拉公式拆成实解。

## 10.8 二阶常系数非齐次线性方程

$$
y'' + py' + qy = f(x)
$$

**结构定理**：通解 = 齐次通解 + 一个特解。

### 10.8.1 待定系数法

| $f(x)$ | 特解形式 | 说明 |
| --- | --- | --- |
| $P_m(x)e^{\lambda x}$ | $x^kQ_m(x)e^{\lambda x}$ | $k$ 为 $\lambda$ 是特征根的重数 |
| $e^{\alpha x}[P\cos\beta x + Q\sin\beta x]$ | $x^ke^{\alpha x}[R_m\cos\beta x + S_m\sin\beta x]$ | $k$ 由 $\alpha\pm\beta i$ 是否为特征根决定 |

**例** $y'' - 3y' + 2y = e^{3x}$：

特征根 $1,2$，$\lambda=3$ 不是特征根，设 $y^* = Ae^{3x}$，代入得

$$
(9 - 9 + 2)Ae^{3x} = e^{3x} \Rightarrow A = \frac{1}{2}
$$

通解 $y = C_1e^x + C_2e^{2x} + \frac{1}{2}e^{3x}$。

### 10.8.2 叠加原理

若 $f = f_1 + f_2$，可分别求 $y_1^*, y_2^*$，则 $y_1^* + y_2^*$ 是原方程特解。

## 10.9 例题

**例 1** 解 $y' = \frac{y}{x} + 1$（$x>0$）。

齐次解 $y = Cx$，常数变易得 $y = x\ln x + Cx$。

**例 2** 解 $y'' + 4y = 0$。

特征根 $\pm2i$，通解 $y = C_1\cos 2x + C_2\sin 2x$。

**例 3** 解 $y'' - 2y' + y = 0$。

特征根 $r=1$（二重），通解 $y = (C_1 + C_2x)e^x$。

**例 4** 解 $y'' + y = \sin x$。

齐次解 $C_1\cos x + C_2\sin x$；$\pm i$ 是特征根，设

$$
y^* = x(A\cos x + B\sin x)
$$

代入得 $A = -\frac{1}{2}$，$B = 0$，故 $y^* = -\frac{x}{2}\cos x$。

**例 5** 求 $y' = 2xy$，$y(0)=1$ 的特解。

分离变量得 $y = Ce^{x^2}$，由 $y(0)=1$ 得 $C=1$，故 $y = e^{x^2}$。

**例 6** 解 $y'' = 1 + (y')^2$。

令 $p = y'$，$p' = 1+p^2$，$\arctan p = x + C_1$，$p = \tan(x+C_1)$，再积分得

$$
y = -\ln|\cos(x+C_1)| + C_2
$$

## 10.10 易错清单

::: warning
1. **通解常数个数不对**：$n$ 阶方程要有 $n$ 个独立常数。
2. **分离变量丢解**：检查 $g(y)=0$。
3. **一阶线性未化标准形**：系数必须为 1。
4. **特解形式与齐次解重复**：需乘 $x^k$。
5. **不验算**：代回原方程检查，尤其是待定系数。
:::

## 10.11 练习

1. 解 $y' = \frac{x}{y}$。
2. 解 $y' + y = e^{-x}$。
3. 解 $y'' - 5y' + 6y = 0$。
4. 解 $y'' + y = e^x$。
5. 解 $y'' - 4y' + 4y = e^{2x}$。

::: details 参考答案
1. $y^2 = x^2 + C$。
2. $y = (x + C)e^{-x}$。
3. $y = C_1e^{2x} + C_2e^{3x}$。
4. $y = C_1\cos x + C_2\sin x + \frac{1}{2}e^x$。
5. $\lambda=2$ 为二重根，设 $y^* = Ax^2e^{2x}$，得 $A = \frac{1}{2}$，通解 $y = (C_1 + C_2x)e^{2x} + \frac{x^2}{2}e^{2x}$。
:::

## 小结

- 一阶方程：可分离、齐次、线性、伯努利四类，各有固定代换；
- 高阶可降阶：缺 $y$ 或缺 $x$ 分别用 $p=y'$ 降阶；
- 二阶常系数：特征方程定齐次解，待定系数求特解。
