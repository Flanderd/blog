# 第三章 微分中值定理与导数应用

> **本章定位**：中值定理把"函数增量"与"某点的导数"联系起来，是证明不等式、研究单调性、推导泰勒公式的总枢纽；导数应用则是这些定理的直接落地。

## 3.1 费马引理

若 $f$ 在 $x_0$ 处取得极值且在 $x_0$ 可导，则

$$
f'(x_0) = 0
$$

**证明**：不妨设 $x_0$ 为极大值点。当 $\Delta x > 0$ 时差商 $\le 0$，当 $\Delta x < 0$ 时差商 $\ge 0$；左右导数都存在且相等，故只能为 0。

**意义**：可导极值点必为驻点，这是罗尔定理的基石。

## 3.2 罗尔定理

设 $f$ 在 $[a,b]$ 连续、$(a,b)$ 可导，且 $f(a) = f(b)$，则存在 $\xi \in (a,b)$ 使

$$
f'(\xi) = 0
$$

**证明思路**：

1. $f$ 在闭区间连续，必有最大值 $M$ 与最小值 $m$；
2. 若 $M = m$，$f$ 为常数，任意点导数为 0；
3. 否则 $M > m$，因 $f(a) = f(b)$，最值至少有一个在 $(a,b)$ 内取得；
4. 由费马引理，该点导数为 0。

**几何意义**：两端等高的曲线上，必有一点切线水平。

## 3.3 拉格朗日中值定理

条件同罗尔（去掉端点等高），则存在 $\xi \in (a,b)$ 使

$$
f(b) - f(a) = f'(\xi)(b-a)
$$

或写成

$$
f'(\xi) = \frac{f(b) - f(a)}{b - a}
$$

**证明（辅助函数法）**：构造

$$
F(x) = f(x) - f(a) - \frac{f(b)-f(a)}{b-a}(x-a)
$$

则 $F(a) = F(b) = 0$，对 $F$ 用罗尔定理即得。

::: tip 辅助函数是这类证明的通用套路
要证 $f'(\xi) = k$，就构造"原函数减去过端点的直线"；
要证含 $f'(\xi)$ 与 $f(\xi)$ 的关系式，常构造 $e^{\lambda x}f(x)$ 或 $f(x)/x$ 等。
:::

**推论**：若在区间内 $f'(x) \equiv 0$，则 $f$ 为常数；若 $f' = g'$，则 $f - g$ 为常数。

## 3.4 柯西中值定理

设 $f, g$ 在 $[a,b]$ 连续、$(a,b)$ 可导，$g'(x) \ne 0$，则存在 $\xi$ 使

$$
\frac{f(b)-f(a)}{g(b)-g(a)} = \frac{f'(\xi)}{g'(\xi)}
$$

**证明**：构造

$$
F(x) = [f(x)-f(a)][g(b)-g(a)] - [g(x)-g(a)][f(b)-f(a)]
$$

验证 $F(a) = F(b) = 0$，再用罗尔定理。

## 3.5 洛必达法则

### 3.5.1 基本形式

对 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 型，若

$$
\lim\frac{f'(x)}{g'(x)} = L
$$

则 $\lim\frac{f(x)}{g(x)} = L$（$L$ 可为 $\infty$）。

**使用前提**：分子分母都趋于 0 或都趋于 $\infty$；右端极限存在或为无穷；$g'(x) \ne 0$。

### 3.5.2 其他未定式

| 类型 | 处理 |
| --- | --- |
| $0\cdot\infty$ | 化为 $\frac{0}{1/\infty}$ 或 $\frac{\infty}{1/0}$ |
| $\infty - \infty$ | 通分或提取公因子 |
| $1^\infty$ | 取对数，化为 $0\cdot\infty$ |
| $0^0$、$\infty^0$ | 取对数 |

**例 1** $\lim_{x\to0}\frac{e^x - 1 - x}{x^2}$（两次洛必达）：

$$
= \lim\frac{e^x - 1}{2x} = \lim\frac{e^x}{2} = \frac{1}{2}
$$

**例 2** $\lim_{x\to\infty}\frac{\ln x}{x} = \lim\frac{1/x}{1} = 0$。

**例 3** $\lim_{x\to0^+}x\ln x = \lim\frac{\ln x}{1/x} = \lim\frac{1/x}{-1/x^2} = 0$。

**例 4** $\lim_{x\to0}(1+x)^{1/x}$：取对数得 $\frac{\ln(1+x)}{x} \to 1$，故极限为 $e$。

::: warning 洛必达失灵的情形
- 求导后极限不存在（如 $\frac{x+\sin x}{x}$，洛必达后振荡），但原极限存在；
- 循环求导不收敛（如 $\frac{e^x - e^{-x}}{e^x + e^{-x}}$ 反复循环，应直接除以 $e^x$）；
- 不是未定式时使用会得到错误结果。
:::

## 3.6 泰勒公式

### 3.6.1 带佩亚诺余项

$$
f(x) = \sum_{k=0}^{n}\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k + o((x-x_0)^n)
$$

用于求极限、判断无穷小阶数。

### 3.6.2 带拉格朗日余项

$$
f(x) = \sum_{k=0}^{n}\frac{f^{(k)}(x_0)}{k!}(x-x_0)^k
+ \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}
$$

用于误差估计、证明不等式。

### 3.6.3 常用麦克劳林展开

$$
e^x = 1 + x + \frac{x^2}{2!} + \cdots + \frac{x^n}{n!} + o(x^n)
$$

$$
\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots
$$

$$
\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots
$$

$$
\ln(1+x) = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots
$$

$$
(1+x)^a = 1 + ax + \frac{a(a-1)}{2!}x^2 + \cdots
$$

**推导示例**：对 $f(x) = e^x$ 在 0 处逐阶求导，$f^{(k)}(0) = 1$，代入泰勒公式即得。

::: tip 展开到几阶
求极限时展开到"分子分母同阶"为止：若分母是 $x^3$，分子展开到 $x^3$；若展开后发现主部抵消，再往后展开一阶。
:::

## 3.7 单调性、极值与最值

### 3.7.1 单调性

$f'(x) > 0$ 严格递增；$f'(x) < 0$ 严格递减。证明不等式常用此法：

**例** 证明 $x > 0$ 时 $\ln(1+x) < x$。

令 $f(x) = x - \ln(1+x)$，$f(0)=0$，$f'(x) = \frac{x}{1+x} > 0$，故 $f$ 递增，结论成立。

### 3.7.2 极值判别

- **第一充分条件**：$f'$ 在 $x_0$ 两侧由正变负为极大，由负变正为极小；
- **第二充分条件**：$f'(x_0)=0$，$f''(x_0)>0$ 极小，$f''(x_0)<0$ 极大；
- $f''(x_0)=0$ 时第二条件失效，需用第一条件或高阶导数。

### 3.7.3 最值

闭区间上比较：驻点、不可导点、端点的函数值。实际问题中若唯一驻点且为极大（小），即为最大（小）值。

**例** 求 $f(x) = x^3 - 3x$ 在 $[-2, 3]$ 上的最值。

$f' = 3x^2 - 3$，驻点 $\pm1$。计算 $f(-2)=-2$、$f(-1)=2$、$f(1)=-2$、$f(3)=18$，故最大值 18，最小值 $-2$。

## 3.8 凹凸性、拐点、渐近线与曲率

### 3.8.1 凹凸性

- $f'' > 0$：凹（下凸），曲线在切线上方；
- $f'' < 0$：凸（上凸），曲线在切线下方；
- 拐点：$f''$ 变号的点，可能出现在 $f'' = 0$ 或 $f''$ 不存在处。

### 3.8.2 渐近线

| 类型 | 求法 |
| --- | --- |
| 水平 | $\lim_{x\to\infty}f(x) = b$ |
| 垂直 | $\lim_{x\to a}f(x) = \infty$ |
| 斜 | $k = \lim\frac{f(x)}{x}$，$b = \lim[f(x)-kx]$ |

**例** $f(x) = \frac{x^2}{x-1}$：垂直渐近线 $x=1$；斜渐近线 $y = x+1$。

### 3.8.3 曲率

$$
K = \frac{|y''|}{(1+y'^2)^{3/2}}, \qquad R = \frac{1}{K}
$$

直线曲率为 0，圆上各点曲率为 $1/R$。

## 3.9 综合例题

**例 1** 证明当 $x > 0$ 时，$e^x > 1 + x + \frac{x^2}{2}$。

令 $f(x) = e^x - 1 - x - \frac{x^2}{2}$，$f(0)=0$，$f'(x) = e^x - 1 - x$，$f''(x) = e^x - 1 > 0$（$x>0$），故 $f'$ 递增且 $f'(0)=0$，$f' > 0$，$f$ 递增，结论成立。

**例 2** 求 $\lim_{x\to0}\frac{x - \sin x}{x^3}$。

泰勒：$\sin x = x - \frac{x^3}{6} + o(x^3)$，故极限为 $\frac{1}{6}$。

**例 3** 求 $f(x) = x e^{-x}$ 的单调区间、极值、凹凸区间与拐点。

$f' = (1-x)e^{-x}$，$f'' = (x-2)e^{-x}$。

- 增区间 $(-\infty,1)$，减区间 $(1,+\infty)$，极大值 $f(1) = e^{-1}$；
- $x<2$ 时 $f''<0$（凸），$x>2$ 时 $f''>0$（凹），拐点 $\left(2, 2e^{-2}\right)$。

**例 4** 设 $f$ 在 $[0,1]$ 上连续、$(0,1)$ 内可导，$f(0)=0$，$f(1)=1$。证明存在 $\xi$ 使 $f'(\xi) = 1$。

对 $f$ 用拉格朗日中值定理：$f'(\xi) = \frac{f(1)-f(0)}{1-0} = 1$。

**例 5** 证明方程 $x^3 - 3x + 1 = 0$ 在 $(0,1)$ 内有且仅有一个实根。

存在性：$f(0)=1$，$f(1)=-1$，零点定理。唯一性：$f' = 3x^2-3 < 0$ 在 $(0,1)$，单调递减。

## 3.10 易错清单

::: warning
1. **驻点当极值点**：$y=x^3$ 在 0 处导数为 0 但非极值。
2. **极值点当驻点**：$y=|x|$ 在 0 处不可导却是极小。
3. **拐点只看 $f''=0$**：还需变号。
4. **洛必达滥用**：非未定式、求导后极限不存在时不能用。
5. **泰勒展开阶数不足**：主部抵消后要补阶。
:::

## 3.11 练习

1. 求 $\lim_{x\to0}\frac{e^x - 1 - x - x^2/2}{x^3}$。
2. 证明 $x>0$ 时 $\sin x < x$。
3. 求 $f(x) = x^4 - 2x^2 + 3$ 的极值与凹凸区间。
4. 求曲线 $y = \frac{x^2}{x+1}$ 的渐近线。
5. 设 $f$ 在 $[a,b]$ 连续、$(a,b)$ 可导，证明存在 $\xi$ 使 $f(b)-f(a) = \xi f'(\xi)\ln\frac{b}{a}$（$0<a<b$）。

::: details 参考答案
1. 泰勒展开到 $x^3$，极限 $\frac{1}{6}$。
2. 令 $f(x)=x-\sin x$，$f(0)=0$，$f'(x)=1-\cos x>0$。
3. 极小值 $f(\pm1)=2$，极大值 $f(0)=3$；$|x|>1/\sqrt{3}$ 凹，$|x|<1/\sqrt{3}$ 凸。
4. 垂直 $x=-1$，斜渐近线 $y=x-1$。
5. 令 $F(x)=f(x)$，$G(x)=\ln x$，用柯西中值定理。
:::

## 小结

- 费马引理 → 罗尔 → 拉格朗日 → 柯西，一条证明链；
- 洛必达处理未定式，泰勒处理更精细的极限与误差；
- 单调性证明不等式，二阶导判定凹凸与拐点，渐近线刻画无穷远行为。
