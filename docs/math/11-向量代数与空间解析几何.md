# 第十一章 向量代数与空间解析几何

> **本章定位**：用向量把空间中的点、线、面、曲面统一描述。三种乘法（点积、叉积、混合积）分别对应"投影/夹角""面积/垂直""体积/共面"，是解决空间几何问题的三把钥匙。

## 11.1 向量及其线性运算

向量 $\boldsymbol{a} = (a_x, a_y, a_z)$，模

$$
|\boldsymbol{a}| = \sqrt{a_x^2 + a_y^2 + a_z^2}
$$

**单位向量**：$\boldsymbol{a}^0 = \dfrac{\boldsymbol{a}}{|\boldsymbol{a}|}$。

**方向余弦**：

$$
\cos\alpha = \frac{a_x}{|\boldsymbol{a}|},\quad
\cos\beta = \frac{a_y}{|\boldsymbol{a}|},\quad
\cos\gamma = \frac{a_z}{|\boldsymbol{a}|}
$$

且 $\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$。

**线性运算**：加减、数乘按分量进行；$\boldsymbol{b} = \lambda\boldsymbol{a}$ 表示共线。

## 11.2 数量积（点积）

$$
\boldsymbol{a}\cdot\boldsymbol{b} = |\boldsymbol{a}||\boldsymbol{b}|\cos\theta
= a_xb_x + a_yb_y + a_zb_z
$$

**用途**：

- 求夹角：$\cos\theta = \dfrac{\boldsymbol{a}\cdot\boldsymbol{b}}{|\boldsymbol{a}||\boldsymbol{b}|}$；
- 判垂直：$\boldsymbol{a}\cdot\boldsymbol{b} = 0$；
- 求投影：$\operatorname{Prj}_{\boldsymbol{b}}\boldsymbol{a} = \dfrac{\boldsymbol{a}\cdot\boldsymbol{b}}{|\boldsymbol{b}|}$。

**运算律**：交换律、分配律、与数乘可结合；**不满足结合律**（点积结果是数）。

## 11.3 向量积（叉积）

$$
\boldsymbol{a}\times\boldsymbol{b} =
\begin{vmatrix}
\boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k}\\
a_x & a_y & a_z\\
b_x & b_y & b_z
\end{vmatrix}
$$

**性质**：

- $|\boldsymbol{a}\times\boldsymbol{b}| = |\boldsymbol{a}||\boldsymbol{b}|\sin\theta$，等于以 $\boldsymbol{a},\boldsymbol{b}$ 为邻边的平行四边形面积；
- 方向：右手法则，同时垂直于 $\boldsymbol{a},\boldsymbol{b}$；
- 反交换：$\boldsymbol{a}\times\boldsymbol{b} = -\boldsymbol{b}\times\boldsymbol{a}$；
- 判平行：$\boldsymbol{a}\times\boldsymbol{b} = \boldsymbol{0}$。

**应用**：求平面法向量、三角形面积 $S = \frac{1}{2}|\boldsymbol{a}\times\boldsymbol{b}|$、力矩 $\boldsymbol{M} = \boldsymbol{r}\times\boldsymbol{F}$。

## 11.4 混合积

$$
[\boldsymbol{a}\boldsymbol{b}\boldsymbol{c}] = (\boldsymbol{a}\times\boldsymbol{b})\cdot\boldsymbol{c}
=
\begin{vmatrix}
a_x & a_y & a_z\\
b_x & b_y & b_z\\
c_x & c_y & c_z
\end{vmatrix}
$$

**几何意义**：绝对值等于以三向量为棱的平行六面体体积；三向量共面 $\iff [\boldsymbol{a}\boldsymbol{b}\boldsymbol{c}] = 0$。

**轮换对称性**：$[\boldsymbol{a}\boldsymbol{b}\boldsymbol{c}] = [\boldsymbol{b}\boldsymbol{c}\boldsymbol{a}] = [\boldsymbol{c}\boldsymbol{a}\boldsymbol{b}]$，交换两个向量变号。

## 11.5 平面方程

### 11.5.1 点法式

过 $P_0(x_0,y_0,z_0)$，法向量 $\boldsymbol{n} = (A,B,C)$：

$$
A(x-x_0) + B(y-y_0) + C(z-z_0) = 0
$$

**推导**：设平面上任一点 $P$，则 $\overrightarrow{P_0P}\perp\boldsymbol{n}$，即 $\boldsymbol{n}\cdot\overrightarrow{P_0P} = 0$。

### 11.5.2 一般式与截距式

一般式：$Ax + By + Cz + D = 0$，法向量 $(A,B,C)$。

截距式：$\dfrac{x}{a} + \dfrac{y}{b} + \dfrac{z}{c} = 1$（$abc\ne0$）。

### 11.5.3 点到平面距离

$$
d = \frac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2+B^2+C^2}}
$$

**例** 点 $(1,1,1)$ 到 $x+2y+2z-6=0$ 的距离：

$$
d = \frac{|1+2+2-6|}{3} = \frac{1}{3}
$$

## 11.6 空间直线

### 11.6.1 对称式与参数式

过 $P_0$，方向向量 $\boldsymbol{s} = (m,n,p)$：

$$
\frac{x-x_0}{m} = \frac{y-y_0}{n} = \frac{z-z_0}{p}
$$

参数式：

$$
x = x_0 + mt,\quad y = y_0 + nt,\quad z = z_0 + pt
$$

### 11.6.2 一般式

两个平面的交线：

$$
\begin{cases}
A_1x + B_1y + C_1z + D_1 = 0\\
A_2x + B_2y + C_2z + D_2 = 0
\end{cases}
$$

方向向量 $\boldsymbol{s} = \boldsymbol{n}_1\times\boldsymbol{n}_2$。

### 11.6.3 夹角

- 两直线夹角：$\cos\theta = \dfrac{|\boldsymbol{s}_1\cdot\boldsymbol{s}_2|}{|\boldsymbol{s}_1||\boldsymbol{s}_2|}$；
- 直线与平面夹角：$\sin\theta = \dfrac{|\boldsymbol{s}\cdot\boldsymbol{n}|}{|\boldsymbol{s}||\boldsymbol{n}|}$；
- 两平面夹角：$\cos\theta = \dfrac{|\boldsymbol{n}_1\cdot\boldsymbol{n}_2|}{|\boldsymbol{n}_1||\boldsymbol{n}_2|}$。

## 11.7 位置关系

| 关系 | 条件 |
| --- | --- |
| 直线 $\parallel$ 直线 | $\boldsymbol{s}_1\parallel\boldsymbol{s}_2$ |
| 直线 $\perp$ 直线 | $\boldsymbol{s}_1\cdot\boldsymbol{s}_2 = 0$ |
| 直线 $\parallel$ 平面 | $\boldsymbol{s}\cdot\boldsymbol{n} = 0$ 且点不在平面内 |
| 直线 $\perp$ 平面 | $\boldsymbol{s}\parallel\boldsymbol{n}$ |
| 平面 $\parallel$ 平面 | $\boldsymbol{n}_1\parallel\boldsymbol{n}_2$ |
| 平面 $\perp$ 平面 | $\boldsymbol{n}_1\cdot\boldsymbol{n}_2 = 0$ |

## 11.8 曲面

### 11.8.1 球面

$$
(x-a)^2 + (y-b)^2 + (z-c)^2 = R^2
$$

### 11.8.2 柱面

方程缺一个变量时，母线平行于该变量对应的坐标轴。例如 $x^2+y^2=R^2$ 是母线平行于 $z$ 轴的圆柱面。

### 11.8.3 旋转曲面

曲线 $f(y,z)=0$ 绕 $z$ 轴旋转：用 $\pm\sqrt{x^2+y^2}$ 替换 $y$：

$$
f\left(\pm\sqrt{x^2+y^2},\ z\right) = 0
$$

**例** $y^2 = 2z$ 绕 $z$ 轴旋转得 $x^2+y^2 = 2z$（旋转抛物面）。

### 11.8.4 二次曲面

| 名称 | 标准方程 |
| --- | --- |
| 椭球面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}+\dfrac{z^2}{c^2}=1$ |
| 单叶双曲面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=1$ |
| 双叶双曲面 | $\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}-\dfrac{z^2}{c^2}=1$ |
| 椭圆抛物面 | $z=\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}$ |
| 双曲抛物面 | $z=\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}$ |
| 圆锥面 | $\dfrac{x^2}{a^2}+\dfrac{y^2}{a^2}=z^2$ |

## 11.9 空间曲线

**参数方程**：$x=x(t)$，$y=y(t)$，$z=z(t)$。

**一般方程**：两个曲面联立。

**投影**：消去 $z$ 得投影柱面，再与 $z=0$ 联立得 $xOy$ 面上的投影曲线。

**例** 曲线 $x^2+y^2+z^2=1$，$z=x$ 在 $xOy$ 面的投影：

消去 $z$：$x^2+y^2+x^2=1$，即 $2x^2+y^2=1$，投影为椭圆。

## 11.10 例题

**例 1** 求过 $(1,2,3)$ 且垂直于 $(2,-1,4)$ 的平面。

$$
2(x-1)-(y-2)+4(z-3)=0 \Rightarrow 2x-y+4z-12=0
$$

**例 2** 求过点 $(1,0,-1)$ 且平行于向量 $(1,2,3)$ 与 $(0,1,1)$ 的平面。

法向量 $\boldsymbol{n} = (1,2,3)\times(0,1,1) = (-1,-1,1)$，平面：

$$
-(x-1) - y + (z+1) = 0 \Rightarrow -x - y + z + 2 = 0
$$

**例 3** 判断直线 $\frac{x-1}{2}=\frac{y}{-1}=\frac{z+1}{3}$ 与平面 $x+y+z=0$ 的位置关系。

$\boldsymbol{s}\cdot\boldsymbol{n} = 2-1+3 = 4 \ne 0$，斜交；夹角 $\sin\theta = \frac{4}{\sqrt{14}\sqrt3}$。

**例 4** 求点 $(2,3,1)$ 到直线 $\frac{x-1}{1}=\frac{y-1}{2}=\frac{z}{2}$ 的距离。

用叉积：$d = \dfrac{|\overrightarrow{P_0P}\times\boldsymbol{s}|}{|\boldsymbol{s}|}$。

**例 5** 求过三点 $(1,0,0)$、$(0,1,0)$、$(0,0,1)$ 的平面。

截距式：$x+y+z=1$。

## 11.11 易错清单

::: warning
1. **叉积顺序**：$\boldsymbol{a}\times\boldsymbol{b} = -\boldsymbol{b}\times\boldsymbol{a}$，方向搞反会得到相反法向量。
2. **平面法向量与直线方向向量混淆**：平面用 $\boldsymbol{n}$，直线用 $\boldsymbol{s}$。
3. **旋转曲面替换错变量**：绕哪个轴转，哪个变量保持不变。
4. **线面夹角用 $\cos$**：应为 $\sin$（方向向量与法向量夹角的余角）。
5. **点到直线距离忘记叉积**：$d = |\overrightarrow{P_0P}\times\boldsymbol{s}|/|\boldsymbol{s}|$。
:::

## 11.12 练习

1. 已知 $\boldsymbol{a}=(1,2,2)$，$\boldsymbol{b}=(2,-1,0)$，求 $\boldsymbol{a}\cdot\boldsymbol{b}$、$\boldsymbol{a}\times\boldsymbol{b}$。
2. 求过点 $(1,1,1)$ 且平行于平面 $x+y+z=0$ 的平面。
3. 求直线 $\frac{x}{1}=\frac{y-1}{2}=\frac{z}{3}$ 与平面 $2x-y+z=3$ 的交点。
4. 判断四点 $(0,0,0)$、$(1,0,0)$、$(0,1,0)$、$(0,0,1)$ 是否共面。
5. 求 $z=x^2+y^2$ 与 $z=1$ 的交线在 $xOy$ 面的投影。

::: details 参考答案
1. $\boldsymbol{a}\cdot\boldsymbol{b}=0$；$\boldsymbol{a}\times\boldsymbol{b}=(2,4,-5)$。
2. $x+y+z=3$。
3. 令参数 $t$，代入得 $2t-(1+2t)+3t=3\Rightarrow t=\frac{4}{3}$，交点 $\left(\frac43,\frac{11}{3},4\right)$。
4. 混合积 $=1\ne0$，不共面。
5. $x^2+y^2=1$（单位圆）。
:::

## 小结

- 点积管夹角与投影，叉积管面积与法向量，混合积管体积与共面；
- 平面用点法式，直线用对称式，位置关系看 $\boldsymbol{n}$ 与 $\boldsymbol{s}$；
- 旋转曲面"绕谁转谁不变"，二次曲面记标准方程。
