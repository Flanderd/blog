# 第六章 多元函数微分学

> **本章定位**：一元微分的"变化率"思想推广到多元后，出现偏导、全微分、梯度等新概念。核心问题是：多个自变量同时变化时，函数如何响应？本章讲清可微性、链式法则、极值与条件极值。

## 6.1 二元函数、极限与连续

**定义**：$z = f(x,y)$，定义域 $D \subseteq \mathbb{R}^2$。

**极限**：$\lim_{(x,y)\to(x_0,y_0)} f(x,y) = A$ 要求**沿任意路径**趋近都得到 $A$。

**连续**：$\lim_{(x,y)\to(x_0,y_0)}f(x,y) = f(x_0,y_0)$。

::: warning 路径依赖
$f(x,y) = \dfrac{xy}{x^2+y^2}$ 在原点无定义。沿 $y = kx$ 趋近：

$$
f = \frac{kx^2}{(1+k^2)x^2} = \frac{k}{1+k^2}
$$

随 $k$ 变化，故极限不存在。
:::

## 6.2 偏导数

**定义**：

$$
\frac{\partial z}{\partial x}\bigg|_{(x_0,y_0)}
= \lim_{\Delta x\to0}\frac{f(x_0+\Delta x, y_0) - f(x_0,y_0)}{\Delta x}
$$

求 $\partial z/\partial x$ 时把 $y$ 当常数，反之亦然。

**几何意义**：曲面与平面 $y = y_0$ 的交线在 $x$ 方向的切线斜率。

**高阶偏导**：$z_{xx}, z_{xy}, z_{yx}, z_{yy}$。

**混合偏导定理**：若 $z_{xy}$ 与 $z_{yx}$ 在区域内连续，则二者相等。

## 6.3 全微分

**定义**：若

$$
\Delta z = A\Delta x + B\Delta y + o(\rho), \qquad \rho = \sqrt{\Delta x^2 + \Delta y^2}
$$

则称 $z$ 在点 $(x_0,y_0)$ 可微，且

$$
\mathrm{d}z = \frac{\partial z}{\partial x}\mathrm{d}x + \frac{\partial z}{\partial y}\mathrm{d}y
$$

**可微的必要条件**：偏导存在，且 $A = z_x$，$B = z_y$；可微必连续。

**可微的充分条件**：偏导在点的某邻域内存在且**连续**。

**证明思路**：用拉格朗日中值定理把 $\Delta z$ 拆成两段

$$
\Delta z = [f(x_0+\Delta x, y_0+\Delta y) - f(x_0, y_0+\Delta y)]
+ [f(x_0, y_0+\Delta y) - f(x_0,y_0)]
$$

每段对相应变量用中值定理，再由偏导连续性控制余项。

::: warning 偏导存在 ≠ 可微
经典反例：

$$
f(x,y) = \begin{cases}
\dfrac{xy}{\sqrt{x^2+y^2}}, & (x,y)\ne(0,0)\\[6pt]
0, & (x,y)=(0,0)
\end{cases}
$$

偏导存在，但 $\Delta z - (z_x\Delta x + z_y\Delta y)$ 不是 $o(\rho)$，故不可微。
:::

## 6.4 复合函数求导

### 6.4.1 链式法则

设 $z = f(u,v)$，$u = u(x,y)$，$v = v(x,y)$，则

$$
\frac{\partial z}{\partial x}
= \frac{\partial z}{\partial u}\frac{\partial u}{\partial x}
+ \frac{\partial z}{\partial v}\frac{\partial v}{\partial x}
$$

**树形图法**：从 $z$ 出发到目标变量 $x$ 的每条路径上的偏导相乘，再把所有路径相加。

**例** $z = f(x^2y, xy^2)$，则

$$
z_x = 2xy f_1 + y^2 f_2, \qquad z_y = x^2 f_1 + 2xy f_2
$$

### 6.4.2 全导数

若 $z = f(u,v)$，$u = u(t)$，$v = v(t)$：

$$
\frac{\mathrm{d}z}{\mathrm{d}t}
= f_u\frac{\mathrm{d}u}{\mathrm{d}t} + f_v\frac{\mathrm{d}v}{\mathrm{d}t}
$$

### 6.4.3 隐函数求导

由 $F(x,y,z) = 0$ 确定 $z = z(x,y)$：

$$
z_x = -\frac{F_x}{F_z}, \qquad z_y = -\frac{F_y}{F_z}
$$

**推导**：两边对 $x$ 求导，$F_x + F_z z_x = 0$。

## 6.5 方向导数与梯度

**方向导数**（沿单位向量 $\boldsymbol{l} = (\cos\alpha,\cos\beta)$）：

$$
\frac{\partial f}{\partial l}
= \lim_{t\to0^+}\frac{f(x_0+t\cos\alpha, y_0+t\cos\beta) - f(x_0,y_0)}{t}
= f_x\cos\alpha + f_y\cos\beta
$$

**梯度**：

$$
\nabla f = (f_x, f_y)
$$

于是

$$
\frac{\partial f}{\partial l} = \nabla f\cdot\boldsymbol{l}^0
= |\nabla f|\cos\theta
$$

其中 $\theta$ 为梯度与方向的夹角。

**结论**：

- 沿梯度方向方向导数最大，最大值为 $|\nabla f|$；
- 梯度垂直于等值线（等值面）。

## 6.6 极值

### 6.6.1 无条件极值

**必要条件**：可微极值点处 $f_x = f_y = 0$（驻点）。

**充分条件**：设驻点处

$$
A = f_{xx},\quad B = f_{xy},\quad C = f_{yy},\quad \Delta = AC - B^2
$$

| 判别式 | 结论 |
| --- | --- |
| $\Delta > 0$，$A < 0$ | 极大值 |
| $\Delta > 0$，$A > 0$ | 极小值 |
| $\Delta < 0$ | 非极值（鞍点） |
| $\Delta = 0$ | 需另行判断 |

**证明思路**：把 $\Delta z$ 用二阶泰勒展开，$\Delta$ 正负决定二次型的定性。

### 6.6.2 条件极值：拉格朗日乘数法

求 $f(x,y)$ 在约束 $\varphi(x,y) = 0$ 下的极值，构造

$$
L(x,y,\lambda) = f(x,y) + \lambda\varphi(x,y)
$$

解方程组

$$
\begin{cases}
L_x = f_x + \lambda\varphi_x = 0\\
L_y = f_y + \lambda\varphi_y = 0\\
L_\lambda = \varphi(x,y) = 0
\end{cases}
$$

**几何解释**：极值点处 $f$ 的等值线与约束曲线相切，即 $\nabla f \parallel \nabla\varphi$。

多个约束时引入多个乘数。

## 6.7 例题

**例 1** 设 $z = x^2y + e^{xy}$，求 $z_x, z_y, z_{xy}$。

$$
z_x = 2xy + ye^{xy},\quad z_y = x^2 + xe^{xy}
$$

$$
z_{xy} = 2x + e^{xy} + xye^{xy}
$$

**例 2** 求 $z = x^3 + y^3 - 3xy$ 的极值。

$z_x = 3x^2 - 3y = 0$，$z_y = 3y^2 - 3x = 0$，得驻点 $(0,0)$、$(1,1)$。

在 $(1,1)$：$A = 6$，$B = -3$，$C = 6$，$\Delta = 27 > 0$，$A>0$，极小值 $z = -1$。

在 $(0,0)$：$\Delta = -9 < 0$，非极值。

**例 3** 用拉格朗日乘数法求 $xy$ 在 $x + y = 2$ 下的最大值。

$L = xy + \lambda(x+y-2)$，由 $L_x = y + \lambda = 0$，$L_y = x + \lambda = 0$ 得 $x = y = 1$，最大值 1。

**例 4** 求 $z = x^2 + y^2$ 在 $x + 2y = 5$ 上的最小值。

$L = x^2 + y^2 + \lambda(x + 2y - 5)$，解得 $x = 1$，$y = 2$，最小值 5。

**例 5** 求 $f(x,y) = x^2 - xy + y^2$ 在单位圆上的最值。

$L = x^2 - xy + y^2 + \lambda(x^2 + y^2 - 1)$，解得极值点为 $(\pm\frac{1}{\sqrt{2}}, \mp\frac{1}{\sqrt{2}})$ 与 $(\pm\frac{1}{\sqrt{2}}, \pm\frac{1}{\sqrt{2}})$，最大 $\frac{3}{2}$，最小 $\frac{1}{2}$。

**例 6** 设 $z = f(x+y, xy)$，求 $z_x + z_y$。

$z_x = f_1 + y f_2$，$z_y = f_1 + x f_2$，故

$$
z_x + z_y = 2f_1 + (x+y)f_2
$$

## 6.8 易错清单

::: warning
1. **把偏导存在当可微**：还需偏导连续或直接验证定义。
2. **链式法则漏项**：中间变量有几个就加几项。
3. **梯度方向弄反**：梯度指向函数增大方向，不是减小方向。
4. **条件极值忘记约束**：拉格朗日乘数法中 $\varphi = 0$ 必须联立。
5. **混合偏导直接相等**：需连续性条件。
:::

## 6.9 练习

1. 求 $z = \ln(x^2 + y^2)$ 的偏导与全微分。
2. 设 $z = f(x^2 - y^2)$，求 $z_x, z_y$。
3. 求 $f(x,y) = x^2 + xy + y^2 - 3x$ 的极值。
4. 用拉格朗日乘数法求 $x + y + z = 1$ 下 $xyz$ 的最大值。
5. 求 $u = xy + yz$ 在点 $(1,1,1)$ 处沿方向 $(1,1,1)$ 的方向导数。

::: details 参考答案
1. $z_x = \frac{2x}{x^2+y^2}$，$z_y = \frac{2y}{x^2+y^2}$，$\mathrm{d}z = z_x\mathrm{d}x + z_y\mathrm{d}y$。
2. $z_x = 2x f'$，$z_y = -2y f'$。
3. 驻点 $(2,-1)$，极小值 $-3$。
4. $x=y=z=\frac{1}{3}$，最大值 $\frac{1}{27}$。
5. 方向单位化后 $u_l = \frac{2+1+1}{\sqrt3} = \frac{4}{\sqrt3}$（$u_x = y$，$u_y = x+z$，$u_z = y$）。
:::

## 小结

- 偏导是"单方向"变化率，全微分是"整体线性近似"，可微比偏导存在更强；
- 链式法则用树形图，隐函数用 $F_x/F_z$；
- 梯度给出最快增长方向，条件极值用拉格朗日乘数法。
