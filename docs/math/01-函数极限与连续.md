# 第一章 函数、极限与连续

> **本章定位**：极限是整个微积分的"操作系统"，导数、积分、级数都建立在它之上。本章把极限的定义、性质、计算方法一次讲透，并完成从"数列"到"函数"、从"极限"到"连续"的过渡。

## 1.1 函数复习：先把对象说清楚

**函数**：设 $D \subseteq \mathbb{R}$，若对每个 $x \in D$ 按法则 $f$ 有唯一 $y$ 与之对应，记 $y = f(x)$，$D$ 为定义域。

**复合函数**：$y = f[g(x)]$ 要求 $g$ 的值域落在 $f$ 的定义域内。

**反函数**：$y = f(x)$ 严格单调时存在反函数 $x = f^{-1}(y)$，图像关于 $y = x$ 对称。

**初等函数**：由基本初等函数（幂、指数、对数、三角、反三角）经有限次四则运算与复合而成，在其定义区间内连续。

**四个基本性质**：

| 性质 | 定义 | 用途 |
| --- | --- | --- |
| 有界性 | 存在 $M$，$\vert f(x)\vert \le M$ | 夹逼、无穷小乘有界 |
| 单调性 | $x_1 < x_2 \Rightarrow f(x_1) \le f(x_2)$ | 反函数存在、最值 |
| 奇偶性 | $f(-x) = \pm f(x)$ | 对称区间积分 |
| 周期性 | $f(x+T) = f(x)$ | 三角函数、傅里叶 |

::: tip 定义域优先
做题第一步永远是确定定义域：分母不为零、偶次根号内非负、对数真数为正、$\arcsin$ 的变量在 $[-1,1]$。
:::

## 1.2 数列极限

### 1.2.1 定义

数列 $\{x_n\}$ 以 $a$ 为极限，记 $\lim_{n \to \infty} x_n = a$，若

$$
\forall \varepsilon > 0,\ \exists N \in \mathbb{N},\ \text{当 } n > N \text{ 时},\ |x_n - a| < \varepsilon
$$

**几何意义**：任给 $a$ 的 $\varepsilon$ 邻域，数列从某一项之后全部落入其中。

### 1.2.2 用定义证明极限

**例** 证明 $\lim_{n \to \infty}\dfrac{2n+1}{n} = 2$。

证：对任意 $\varepsilon > 0$，要使

$$
\left|\frac{2n+1}{n} - 2\right| = \frac{1}{n} < \varepsilon
$$

只需 $n > \dfrac{1}{\varepsilon}$。取 $N = \left\lfloor \dfrac{1}{\varepsilon} \right\rfloor + 1$，则当 $n > N$ 时上式成立。故极限为 2。

**方法总结**：先"倒推"找到 $n$ 与 $\varepsilon$ 的关系，再"正写"取 $N$。放缩时把分子放大、分母缩小，得到更宽松但足够用的界。

### 1.2.3 收敛数列的性质

1. **唯一性**：极限若存在必唯一；
2. **有界性**：收敛数列必有界（反之不成立，如 $(-1)^n$）；
3. **保号性**：若 $\lim x_n = a > 0$，则从某项起 $x_n > 0$；
4. **子列性**：若 $\lim x_n = a$，则任意子列也收敛到 $a$。

::: warning 有界不一定收敛
$x_n = (-1)^n$ 有界但发散；$x_n = \sin n$ 也有界但发散。判断发散可用"找两个子列极限不同"。
:::

## 1.3 函数极限

### 1.3.1 定义

**$x \to x_0$**：

$$
\forall \varepsilon > 0,\ \exists \delta > 0,\ \text{当 } 0 < |x - x_0| < \delta \text{ 时},\ |f(x) - A| < \varepsilon
$$

**$x \to \infty$**：

$$
\forall \varepsilon > 0,\ \exists X > 0,\ \text{当 } |x| > X \text{ 时},\ |f(x) - A| < \varepsilon
$$

**单侧极限**：$f(x_0^-)$ 与 $f(x_0^+)$，极限存在 $\iff$ 左右极限存在且相等。

### 1.3.2 极限与函数值无关

极限只关心 $x$ 趋近 $x_0$ 的过程，与 $f(x_0)$ 是否有定义、取什么值无关。这正是"可去间断点"可以补定义的原因。

## 1.4 无穷小与无穷大

### 1.4.1 定义与基本性质

若 $\lim f(x) = 0$，称 $f$ 为无穷小；若 $\lim |f(x)| = +\infty$，称无穷大。二者互为倒数（在非零意义下）。

**性质**：

- 有限个无穷小的和、积仍是无穷小；
- **有界函数 × 无穷小 = 无穷小**（求极限的常用工具）；
- 无穷大与无穷小之积不一定——需具体分析。

### 1.4.2 无穷小的比较

设 $\alpha, \beta \to 0$：

| 极限 | 关系 | 记号 |
| --- | --- | --- |
| $\lim \frac{\alpha}{\beta} = 0$ | 高阶 | $\alpha = o(\beta)$ |
| $\lim \frac{\alpha}{\beta} = \infty$ | 低阶 | — |
| $\lim \frac{\alpha}{\beta} = c \ne 0$ | 同阶 | $\alpha = O(\beta)$ |
| $\lim \frac{\alpha}{\beta} = 1$ | 等价 | $\alpha \sim \beta$ |

### 1.4.3 等价无穷小表（$x \to 0$）

$$
\sin x \sim x,\quad \tan x \sim x,\quad \arcsin x \sim x,\quad \arctan x \sim x
$$

$$
1 - \cos x \sim \frac{x^2}{2},\quad \ln(1+x) \sim x,\quad e^x - 1 \sim x
$$

$$
(1+x)^a - 1 \sim ax,\quad a^x - 1 \sim x\ln a,\quad x - \sin x \sim \frac{x^3}{6}
$$

**推导示例**：由 $\lim_{x\to0}\frac{\sin x}{x}=1$ 得 $\sin x \sim x$；由半角公式

$$
1 - \cos x = 2\sin^2\frac{x}{2} \sim 2\left(\frac{x}{2}\right)^2 = \frac{x^2}{2}
$$

### 1.4.4 等价替换定理

若 $\alpha \sim \alpha'$，$\beta \sim \beta'$ 且 $\lim \frac{\alpha'}{\beta'}$ 存在，则

$$
\lim\frac{\alpha}{\beta} = \lim\frac{\alpha'}{\beta'}
$$

::: warning 只能用于乘除
加减项替换会改变主部。例如

$$
\lim_{x\to0}\frac{\tan x - \sin x}{x^3}
$$

若把两项都换成 $x$，得 0；正确做法是提取 $\tan x(1-\cos x)$，得 $\frac{1}{2}$。
:::

## 1.5 极限计算的九种方法

| 方法 | 适用 | 要点 |
| --- | --- | --- |
| 直接代入 | 连续点 | 先判断是否连续 |
| 因式分解 | $\frac{0}{0}$ 有理式 | 消去零因子 |
| 有理化 | 含根号 | 乘共轭 |
| 等价替换 | 乘除结构 | 只换因子 |
| 两个重要极限 | 三角、$1^\infty$ | 凑标准形 |
| 夹逼准则 | 和式、有界振荡 | 找上下界 |
| 单调有界 | 递推数列 | 先证有界再求极限 |
| 洛必达 | $\frac{0}{0},\frac{\infty}{\infty}$ | 见第三章 |
| 泰勒展开 | 复杂抵消 | 展开到同阶 |

**例 1（因式分解）**

$$
\lim_{x\to2}\frac{x^2-4}{x-2} = \lim_{x\to2}(x+2) = 4
$$

**例 2（有理化）**

$$
\lim_{x\to0}\frac{\sqrt{1+x}-1}{x}
= \lim_{x\to0}\frac{x}{x(\sqrt{1+x}+1)} = \frac{1}{2}
$$

**例 3（重要极限）**

$$
\lim_{x\to0}\frac{\tan 3x}{x} = \lim_{x\to0}\frac{\sin 3x}{x\cos 3x} = 3
$$

**例 4（$1^\infty$ 型）**

$$
\lim_{x\to\infty}\left(1+\frac{2}{x}\right)^{3x}
= \left[\left(1+\frac{2}{x}\right)^{x/2}\right]^{6} \to e^{6}
$$

**例 5（夹逼）**

$$
0 \le \frac{\sin x}{x} \le 1 \Rightarrow \lim_{x\to\infty}\frac{\sin x}{x} = 0
$$

**例 6（单调有界）** 设 $x_1 = \sqrt{2}$，$x_{n+1} = \sqrt{2 + x_n}$，求极限。

先证有界：$x_n < 2$（归纳）；再证单调递增：$x_{n+1}^2 - x_n^2 = 2 + x_n - x_n^2 = (2-x_n)(1+x_n) > 0$。故极限存在，设为 $a$，由 $a = \sqrt{2+a}$ 得 $a = 2$。

## 1.6 连续与间断

### 1.6.1 连续的定义

$f$ 在 $x_0$ 连续：

$$
\lim_{x\to x_0}f(x) = f(x_0)
$$

等价形式：$\lim_{\Delta x\to0}\Delta y = 0$，即"自变量的微小变化只引起函数的微小变化"。

**运算**：连续函数的和、差、积、商（分母非零）、复合仍连续；初等函数在定义区间内连续。

### 1.6.2 间断点分类

| 类型 | 左右极限 | 例子 |
| --- | --- | --- |
| 可去 | 都存在且相等，但不等于函数值/无定义 | $\frac{\sin x}{x}$ 在 0 |
| 跳跃 | 都存在但不相等 | 分段函数在分界点 |
| 无穷 | 至少一侧为 $\infty$ | $\frac{1}{x}$ 在 0 |
| 振荡 | 不存在且非无穷 | $\sin\frac{1}{x}$ 在 0 |

**例** 讨论 $f(x) = \dfrac{x^2-1}{x-1}$ 在 $x=1$ 处的连续性。

$f$ 在 $x=1$ 无定义，但 $\lim_{x\to1}\frac{(x-1)(x+1)}{x-1} = 2$，为可去间断点；补充 $f(1)=2$ 后连续。

## 1.7 闭区间上连续函数的性质

设 $f \in C[a,b]$，则：

1. **有界性**：存在 $M$ 使 $|f(x)| \le M$；
2. **最值定理**：存在 $\xi, \eta \in [a,b]$ 使 $f(\xi) = \min$、$f(\eta) = \max$；
3. **介值定理**：对任意 $\mu$ 介于 $f(a)$ 与 $f(b)$ 之间，存在 $c \in [a,b]$ 使 $f(c) = \mu$；
4. **零点定理**：若 $f(a)f(b) < 0$，存在 $c \in (a,b)$ 使 $f(c) = 0$。

**证明思路（零点定理）**：用二分法构造区间套 $[a_n,b_n]$，长度趋于 0，端点函数值异号；由区间套定理存在唯一 $c$，再由连续性得 $f(c) = 0$。

::: tip 介值定理的典型用法
证明方程有根：构造函数 $F(x)$，找两点使 $F$ 异号，再由零点定理得结论。
例如证明 $x = \cos x$ 在 $(0,1)$ 内有根：令 $F(x) = x - \cos x$，$F(0) = -1 < 0$，$F(1) = 1 - \cos 1 > 0$。
:::

## 1.8 综合例题

**例 1** 求 $\lim_{x\to0}\dfrac{1-\cos x}{x\sin x}$。

$$
\frac{1-\cos x}{x\sin x} \sim \frac{x^2/2}{x\cdot x} = \frac{1}{2}
$$

**例 2** 求 $\lim_{x\to0}\left(\dfrac{1}{x} - \dfrac{1}{e^x-1}\right)$。

通分：

$$
\frac{e^x - 1 - x}{x(e^x-1)} \sim \frac{x^2/2}{x\cdot x} = \frac{1}{2}
$$

其中 $e^x - 1 - x \sim \frac{x^2}{2}$ 由泰勒展开得到。

**例 3** 设 $f(x) = \begin{cases}\dfrac{\sin ax}{x}, & x \ne 0\\ 2, & x = 0\end{cases}$ 在 $x=0$ 连续，求 $a$。

$\lim_{x\to0}\frac{\sin ax}{x} = a$，故 $a = 2$。

**例 4** 求 $\lim_{x\to\infty}\left(\sqrt{x^2+x} - x\right)$。

有理化：

$$
\frac{x}{\sqrt{x^2+x}+x} \to \frac{1}{2}
$$

**例 5** 证明 $\lim_{n\to\infty}\sqrt[n]{n} = 1$。

令 $\sqrt[n]{n} = 1 + h_n$（$h_n > 0$），由二项式展开

$$
n = (1+h_n)^n \ge \frac{n(n-1)}{2}h_n^2
\Rightarrow 0 < h_n \le \sqrt{\frac{2}{n-1}} \to 0
$$

由夹逼得 $h_n \to 0$。

## 1.9 易错清单

::: warning
1. **极限存在 ≠ 函数连续**：连续还要求极限等于函数值。
2. **等价替换用于加减**：只在乘除因子中成立。
3. **$\infty - \infty$ 直接得 0**：必须先通分或有理化。
4. **分段点忘记讨论左右极限**。
5. **$\lim \frac{\sin x}{x}$ 在 $x\to\infty$ 时也等于 1**：错，此时为 0。
:::

## 1.10 练习

1. 求 $\lim_{x\to0}\dfrac{\tan x - x}{x^3}$。
2. 求 $\lim_{x\to\infty}\left(1-\dfrac{1}{x}\right)^{2x}$。
3. 讨论 $f(x) = \dfrac{|x|}{x}$ 在 $x=0$ 的间断类型。
4. 证明方程 $x^3 - 4x + 1 = 0$ 在 $(0,1)$ 内有根。
5. 设 $x_1 = 1$，$x_{n+1} = \sqrt{2x_n}$，证明极限存在并求之。

::: details 参考答案
1. 泰勒：$\tan x = x + \frac{x^3}{3} + o(x^3)$，极限 $\frac{1}{3}$。
2. $\left[(1-\frac{1}{x})^{-x}\right]^{-2} \to e^{-2}$。
3. 左极限 $-1$，右极限 $1$，跳跃间断点。
4. 令 $F(x) = x^3-4x+1$，$F(0)=1>0$，$F(1)=-2<0$，零点定理。
5. 有界 $x_n < 2$，单调递增，极限 $a=\sqrt{2a}\Rightarrow a=2$。
:::

## 小结

- 极限的定义是"$\varepsilon$ 语言"，证明题按"倒推—取 $N/\delta$—正写"三步走；
- 无穷小的阶与等价替换是计算的核心，但只能用于乘除；
- 连续性是"极限等于函数值"，闭区间连续函数具有有界、最值、介值、零点四大性质。
