## 《审计》内容结构

CPA《审计》按执业流程组织，共 **8 编 24 章**——从基本原理与职业道德起步，沿「风险导向审计流程」展开，再落到各业务循环的实质性程序，最后是报告、特殊事项、内控审计与质量管理：

1. **第一编 审计基本原理和职业道德**（第 1–5 章）：审计概述（概念/要素/目标/基本要求/风险/过程/执业责任）、职业道德基本原则与概念框架、独立性要求（收费、经济利益、贷款担保、人员交流、长期业务关系、非鉴证服务）、审计证据（程序、函证、分析程序）、审计抽样方法。
2. **第二编 风险导向审计流程**（第 6–9 章）：审计计划（初步业务活动、总体策略与具体计划、重要性）、风险评估（了解被审计单位及其环境、内部控制体系各要素、识别评估重大错报风险）、风险应对（总体应对措施、进一步审计程序、控制测试、实质性程序）、信息技术对审计的影响。
3. **第三编 各类交易和账户余额的审计**（第 10–13 章）：销售与收款、采购与付款、生产与存货、货币资金四个循环的特点、内部控制、重大错报风险、控制测试与实质性程序。
4. **第四编 审计中对特殊事项的考虑**（第 14–18 章）：舞弊与法律法规、审计沟通、利用他人工作（内部审计/专家）、集团财务报表审计、其他特殊项目（会计估计、关联方、持续经营、期初余额）。
5. **第五编 完成审计工作与出具审计报告**（第 19–21 章）：完成审计工作（期后事项、书面声明）、审计报告（意见形成、基本内容、关键审计事项、非无保留意见、强调事项段、比较信息、其他信息）、审计工作底稿。
6. **第六编 企业内部控制审计**（第 22 章）：概念、计划、自上而下方法、控制有效性测试、各层面控制测试、缺陷评价、报告。
7. **第七编 企业可持续信息鉴证**（第 23 章）：业务概述、承接与保持、计划、风险评估、应对重大错报风险、报告、质量管理。
8. **第八编 质量管理**（第 24 章）：会计师事务所质量管理体系、项目质量复核、财务报表审计的质量管理。

## 《税法》内容结构

CPA《税法》按「税种 + 程序法」组织，记忆主线是「纳税人—征税对象—税率—计税依据—优惠—征管」：

1. **总论**（第 1 章）：税法概念、原则、要素、立法体系、税收执法、税务权利义务、国际税收关系；
2. **货物与劳务税**（第 2–3 章）：增值税（征税范围、一般/简易计税、进出口、优惠、征管）、消费税；
3. **所得税**（第 4–5 章）：企业所得税（应纳税所得额、资产税务处理、重组、优惠）、个人所得税（综合与分类所得、特殊问题）；
4. **财产行为税与小税种**（第 6–11 章）：城建税与烟叶税、关税与船舶吨税、资源税与环境保护税、城镇土地使用税与耕地占用税、房产税/契税/土地增值税、车辆购置税/车船税/印花税；
5. **国际税收与征管**（第 12–14 章）：国际税收协定、非居民与境外所得、反避税与转让定价、税收征管法、税务行政法制。

## 《会计》内容结构

CPA《会计》是全科体系中体量最大的一科，主线是「确认—计量—记录—报告」：

1. **基础与要素**（第 1–12 章）：总论、存货、固定资产、无形资产、投资性房地产、长期股权投资、资产减值、负债、职工薪酬、股份支付、借款费用、或有事项；
2. **金融工具与租赁**（第 13–15 章）：金融工具的分类计量与转移、套期会计、保险合同概述、租赁（承租人与出租人）、持有待售与终止经营；
3. **权益、收入与特殊交易**（第 16–22 章）：所有者权益、收入费用利润、政府补助、所得税、非货币性资产交换、债务重组、外币折算；
4. **报告与合并**（第 23–28 章）：财务报告、会计政策与估计变更及差错更正、资产负债表日后事项、企业合并、合并财务报表、每股收益；
5. **计量与特殊主体**（第 29–30 章）：公允价值计量、政府及民间非营利组织会计。

## 阅读约定

1. 每节文件以 `# 第X节 节名` 开头，层级为 `## 一、` → `### （一）` → `#### 1.` → `##### （1）`；
2. **例题**统一为 `::: info 【例 X-Y】` 提示框，框内保留题干、计算过程与答案；
3. **会计分录**用 `text` 代码块保留借／贷层级与金额，例如：

   ```text
   借：存货跌价准备　20000
     贷：资产减值损失　20000
   ```

4. **公式**：居中成行的公式转为 LaTeX（`$$ … $$`，中文用 `\text{}`、分式用 `\frac`），与正文同段的算式保留原样；
5. 每节末尾以 HTML 注释标注对应 PDF 页码，可回查原书扫描页。
