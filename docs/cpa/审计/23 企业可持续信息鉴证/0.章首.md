# 第二十三章 企业可持续信息鉴证

随着可持续发展理念的不断深化，企业的对外报告责任正从传统的财务报告拓展至对环境、社会和治理（ESG）等多维度可持续发展信息的综合报告。2024年11月，财政部等九部委联合印发《企业可持续披露准则——基本准则（试行）》（以下简称企业可持续信息披露准则），拉开了我国企业披露可持续信息的序幕。企业向信息使用者披露与可持续发展相关的风险、机遇和影响信息，有助于信息使用者作出理性决策、优化资源配置。由独立第三方对可持续信息进行鉴证，不仅可以提高信息披露质量，增强信息使用者对可持续信息的信任程度，还可以帮助企业建立完善的可持续信息管理体系，持续改进和提升企业可持续实践，促进企业高质量发展。2026年1月9日，财政部印发《可持续信息鉴证业务准则第6101号——基本准则（试行）》，对会计师事务所等第三方机构执行可持续信息鉴证业务作出了规定。
