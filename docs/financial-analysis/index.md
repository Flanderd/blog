# 财务分析

> **一句话概括**：财务分析回答的问题是"这家公司到底赚不赚钱、健不健康、值不值得投"。它不是把公式套进报表算出一堆比率，而是**从数字反推经营真相**——通过报表数据，判断企业的盈利能力、偿债能力、营运效率和成长质量。

## 财务分析 vs 财务管理

两门课常被混淆，其实分工明确：

| | 财务分析 | 财务管理 |
| --- | --- | --- |
| 核心问题 | "过去和现在怎么样" | "未来该怎么做" |
| 立场 | 外部视角（投资者、债权人、分析师）为主 | 内部视角（经营者、CFO）为主 |
| 主要工具 | 比率、趋势、结构、质量分析 | 折现、估值、预算、资本成本 |
| 产出 | 结论与判断（好不好、能不能投） | 决策与行动（投不投、借不借、分不分） |

一句话：**财务分析是"诊断"，财务管理是"治疗"**。先诊断清楚，才能对症下药。

## 分析的主体与立场

同一张报表，不同的人关心不同的东西：

| 使用者 | 关心 | 重点指标 |
| --- | --- | --- |
| 股东/投资者 | 盈利能力、成长性 | ROE、EPS、毛利率 |
| 债权人/银行 | 偿债能力、现金流 | 流动比率、利息保障倍数、经营现金流/负债 |
| 供应商 | 短期偿付能力 | 流动比率、应付账款周转 |
| 管理层 | 经营效率、短板 | 各类周转率、杜邦分解 |
| 监管/税务 | 合规、真实性 | 报表勾稽、异常波动 |

**立场的差异决定了结论的差异**：对债权人来说"稳健"的公司，对股东可能意味着"增长乏力"。没有绝对好坏的指标，只有"对谁而言"的指标。

## 分析方法总览

财务分析有四类基本方法，贯穿全书：

1. **比较分析**：与自身历史比（趋势）、与预算比（差异）、与同行比（标杆）；
2. **比率分析**：把两个相关数字相除，消除规模影响，让不同规模企业可比；
3. **结构分析**：计算各项目占总体的比重（共同比报表），看结构是否合理；
4. **因素分析**：杜邦分解、连环替代法，找出指标变动的真正驱动因素。

## 符号约定

| 符号 | 含义 |
| --- | --- |
| $EBIT$ | 息税前利润 |
| $EBITDA$ | 息税折旧摊销前利润 |
| $ROE,\ ROA$ | 净资产收益率、总资产收益率 |
| $EPS,\ BPS$ | 每股收益、每股净资产 |
| $PE,\ PB,\ PS$ | 市盈率、市净率、市销率 |
| $FCF$ | 自由现金流 |
| $SGR$ | 可持续增长率 |
| $D/E$ | 产权比率（负债/权益） |

::: tip 三个学习建议
1. **先看结构再看比率**。同一张报表，先算共同比（各项目占营业收入或总资产的比例），找出异常项，再针对异常项算比率。
2. **比率必须横竖比较**。单独一个比率没有意义，至少要和"自己过去、同行现在"两个参照系比。
3. **利润表是"面子"，现金流量表是"里子"**。分析任何盈利指标前，先看它有没有现金流支撑。
:::
