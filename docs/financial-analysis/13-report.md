# 第十三章 财务分析报告的撰写

> **本章定位**：前面十二章教的是"算"——算比率、算现金流、算杜邦、算行业位置。这一章教的是"写"——把你脑子里已经形成的判断，落成一份别人能看懂、能采信、能据此决策的报告。财务分析报告的本质不是"展示你会算多少比率"，而是"把一个结论，用证据讲清楚，并诚实地提示风险"。写不好报告，前面的所有分析都白费。

## 13.1 分析报告的类型与读者导向

### 13.1.1 三类报告，三类读者

写报告的第一步，不是动笔，而是问一句：**"这份报告是写给谁看的？"** 读者不同，结构、重点、语气都不同。按目的与读者，财务分析报告大致分三类：

| 类型 | 读者 | 核心诉求 | 分析重点 |
| --- | --- | --- | --- |
| **投资建议报告** | 投资者/分析师 | 值不值得买/持有/卖 | 盈利能力、成长性、估值 |
| **信贷评估报告** | 银行/债权人 | 借了钱能不能还 | 偿债能力、现金流、担保 |
| **内部经营分析报告** | 管理层 | 哪里有问题、怎么改进 | 营运效率、短板、改进路径 |

### 13.1.2 读者导向决定结构与重点

同一家公司，三类报告会得出不同的"重点结论"。以一家盈利尚可但负债偏高的公司为例：

- 写给**投资者**：强调成长空间与 ROE，负债是"适度杠杆"；
- 写给**银行**：强调偿债压力，同样的负债变成"风险点"，现金流是第一关注；
- 写给**管理层**：强调哪条业务线拖了后腿、存货积压在哪、如何周转更快。

::: tip 生活化类比
同样是描述一个人："他月入 2 万"——对催债的债主，你想知道他每月能还多少；对丈母娘，你想知道他有没有房、会不会升职；对他老板，你想知道他的产出值不值这个工资。同一份数据，不同读者要听的重点完全不同。
:::

### 13.1.3 三类报告的结构差异

读者导向不仅改变"重点"，还改变"结构"：

| 结构要素 | 投资建议 | 信贷评估 | 内部经营 |
| --- | --- | --- | --- |
| 摘要核心 | 评级 / 目标价 | 授信额度建议 | 经营改进方向 |
| 分析重心 | 盈利、成长、估值 | 偿债、现金流 | 效率、短板 |
| 风险关注 | 行业与经营风险 | 违约与抵押风险 | 运营与执行风险 |
| 建议形态 | 买入 / 持有 / 卖出 | 放款条件与增信 | 具体改进行动 |

**先定位读者，再搭结构**，是报告写作的第一原则。写之前不妨自问三句："写给谁？他关心什么？他看完要做什么决定？"

## 13.2 报告的黄金结构

### 13.2.1 金字塔原理：结论先行

财务分析报告最忌讳"流水账式"——按报表顺序把比率从头念到尾，读者读完还不知道结论。**金字塔原理**要求反过来：**结论先行，再逐层展开支撑论据。**

金字塔结构自上而下：

```
                总结论（观点）
               /       |        \
       分论点 1      分论点 2      分论点 3
       /   \          /   \          /   \
     证据  证据      证据  证据      证据  证据
```

三层逻辑：

1. **塔尖（总结论）**：一句话说清判断，例如"建议买入 / 建议维持授信 / 成本端是利润下滑主因"；
2. **塔身（分论点）**：支撑总结论的几个子判断，彼此**相互独立、完全穷尽**（MECE 原则）；
3. **塔基（证据）**：每个分论点下的具体数据、比率、事实。

结论先行的好处：读者 10 秒就能抓住主旨，再决定要不要细读证据；即便只读摘要，也不会错过核心判断。

**完整示例**——以"建议买入"为总结论的金字塔：

```
总结论：建议买入
  ├── 分论点 1：盈利能力强且稳定（毛利率 40%、ROE 18%，均居行业前三）
  ├── 分论点 2：成长确定（新产能明年投产，收入增速预计 20%）
  └── 分论点 3：估值合理（PE 15 倍，低于行业均值 20 倍）
```

三个分论点彼此独立（分别谈盈利、成长、估值，不重叠），合起来又完整覆盖了"买入"所需的全部理由（不遗漏），符合 MECE 原则。

### 13.2.2 SCQA 框架：把问题讲清楚

结论先行解决"先说结论"，但报告还需要一个"叙事入口"，让读者理解"为什么要分析这个问题"。SCQA 框架提供四步：

| 步骤 | 含义 | 例句 |
| --- | --- | --- |
| **S 情境**（Situation） | 交代背景共识 | "公司近三年收入年增 20%，行业景气。" |
| **C 冲突**（Complication） | 抛出意外变化 | "但最新季度毛利率骤降 8 个百分点。" |
| **Q 问题**（Question） | 提出要回答的问题 | "盈利能力是否出现拐点？" |
| **A 答案**（Answer） | 给出结论 | "是。主因是原材料涨价，建议关注提价能力。" |

SCQA 负责"开场"，金字塔负责"展开"。两者结合，就是"先讲一个有张力的故事，再给出一个站得住的结论"。

**完整示例**——一份关于某零售公司报告的开场：

- **S（情境）**："公司是区域龙头连锁超市，过去五年收入年增 15%，盈利稳定。"
- **C（冲突）**："但 2025 年三季报显示，毛利率下滑 3 个百分点，同店销售首次负增长。"
- **Q（问题）**："这是短期波动，还是行业拐点的开始？"
- **A（答案）**："是行业拐点叠加竞争加剧所致，盈利能力下行趋势已确立，建议下调评级。"

短短四句话，读者就被带入"问题情境"，并立刻得到答案，这正是 SCQA 的威力。

## 13.3 报告的标准框架

### 13.3.1 六段式结构

一份完整的财务分析报告，通常按以下六段展开（与金字塔原理一致，结论放在最前）：

```
1. 摘要（结论先行）
2. 公司概况
3. 经营与财务分析（偿债 / 营运 / 盈利 / 成长 / 现金流）
4. 综合评价
5. 风险提示
6. 结论与建议
```

### 13.3.2 各部分要点

| 部分 | 要回答的问题 | 要点 |
| --- | --- | --- |
| **摘要** | 结论是什么 | 一段话讲清核心判断 + 关键依据，可独立阅读 |
| **公司概况** | 分析对象是谁 | 主营、行业、规模、股权，篇幅宜短 |
| **经营与财务分析** | 数据说明了什么 | 五维度逐个分析，**每个比率都要有解读** |
| **综合评价** | 整体强不强 | 用杜邦等综合视角收拢，形成整体判断 |
| **风险提示** | 哪里会出错 | 单独成段，逐条列出，不可省略 |
| **结论与建议** | 该怎么办 | 呼应摘要，给出明确、可执行的立场 |

::: tip 生活化类比
六段式就像体检报告：先看"结论摘要"（有没有大问题），再看"基本情况"（年龄、性别），再看"各项指标"（血压、血糖逐项解读），最后是"风险提示"（哪些指标超标要注意）和"医嘱"（该怎么办）。没有人愿意读一份只罗列化验数字、却不告诉你身体好不好的体检报告。
:::

### 13.3.3 五维度分析的写法

"经营与财务分析"是报告主体，五个维度各有固定的写法套路：

| 维度 | 分析套路 | 常用指标 |
| --- | --- | --- |
| 偿债 | 短期能否还、长期是否安全 | 流动比率、速动比率、资产负债率、利息保障倍数 |
| 营运 | 资金转得快不快 | 存货 / 应收 / 总资产周转率、周转天数 |
| 盈利 | 赚得多不多、质量高不高 | 毛利率、净利率、ROE、ROA |
| 成长 | 增长快不快、能不能持续 | 收入 / 净利润增速、可持续增长率 |
| 现金流 | 利润是不是真金白银 | 经营现金流、净现比、自由现金流 |

每个维度的写法都是"**结论 → 数据 → 解读**"，先给判断再列证据。切忌按五个标题机械罗列指标而不下结论——那又变回了"比率清单"。

### 13.3.4 摘要的写法

摘要是一份报告的"门面"，标准写法是"**一句话结论 + 三个关键依据 + 一句话建议**"：

> "我们建议买入该公司。基于三点：其一，毛利率 40% 且连续三年提升；其二，新产能明年投产，收入增速预计 20%；其三，当前 PE 15 倍，低于行业均值。综合判断其盈利、成长、估值均具吸引力。"

一句话结论，三个依据，一个建议，读者 30 秒读完即得全貌。摘要必须能**独立阅读**——读者即使不看正文，也不应漏掉任何关键判断。

### 13.3.5 公司概况与综合评价怎么写

**公司概况**：篇幅宜短（半页以内），写清五要素即可——主营、行业、规模、股权结构、所处生命周期。切忌把公司简介抄成十页，喧宾夺主。

**综合评价**：用综合视角收拢前面的分项分析，例如用杜邦分解回答"ROE 由什么驱动"，或用"盈利—成长—现金流"三角交叉验证，给出"强在何处、弱在何处"的整体画像。这是从"分项分析"到"整体判断"的关键一跃，很多报告漏掉这一步，导致最后的结论显得突兀、没有来由。

## 13.4 写作原则与关键公式

### 13.4.1 四条写作原则

1. **结论先行**：每个章节、每个段落的第一句应是判断，而非数据；
2. **数据说话**：判断必须有数据支撑，不能只写"盈利能力较强"而不给数字；
3. **避免堆砌比率**：每个比率出现后，必须紧跟一句"解读"——它说明了什么；
4. **风险单独提示**：风险必须单独成段，不能用一句"存在一定风险"带过。

### 13.4.2 关键公式：比率解读的三段式

报告里比率不是用来"秀"的，而是用来"说话"的。每个比率的标准写法是**三段式**：

$$
\text{解读} = \text{指标值} + \text{参照系} + \text{经营含义} \Rightarrow \text{结论}
$$

**推导思路**：孤立的一个数字没有意义，必须把它放进参照系（与历史比、与同行比、与目标比），再翻译成经营语言。例如"毛利率 25%"只有三个字没有信息，但"毛利率 25%，较去年同期下降 5 个百分点，低于行业均值 30%，主因是原材料涨价"才是一个完整的解读。

对应到结构分析，还有一个最常用的定量工具——**共同比**：

$$
\text{共同比} = \frac{\text{某项目}}{\text{基准项目}} \times 100\%
$$

利润表以营业收入为基准，资产负债表以总资产为基准。共同比的作用是"归一化"，让你能一眼看出结构异常，再针对异常下结论。

### 13.4.3 结论要"可证伪"

一个合格的结论，必须**可证伪**——即明确告诉你"什么情况下这个结论是错的"。可证伪的结论才是有价值、可检验的判断：

| 不可证伪（模糊） | 可证伪（清晰） |
| --- | --- |
| 公司盈利能力还不错 | 若原材料价格回落 10%，公司毛利率将回升 3 个百分点 |
| 未来可能增长 | 若新产线如期达产，明年收入增速预计 15% |

可证伪的结论给出了"触发条件 + 预期结果"，读者可以据此跟踪验证，报告也因此从"观点"升级为"可检验的判断"。

### 13.4.4 正例与反例对照

同样是分析盈利能力，两种写法高下立判：

**反例（数据堆砌）**：

> "公司毛利率 35%，净利率 12%，ROE 15%，ROA 8%。"

**正例（结论 + 数据 + 解读）**：

> "公司盈利能力处于行业上游：毛利率 35%，高于行业均值 28%，主因是产品差异化带来的定价权；净利率 12%、ROE 15%，均列行业前三。但需注意 ROA 仅 8%，说明高 ROE 部分依赖财务杠杆，盈利对负债的依赖需警惕。"

**差别**：正例里每个数字后面都跟着"为什么"和"说明什么"，并主动点出潜在风险，让数据真正"说话"。

### 13.4.5 从分析到报告的五步流程

把"分析结果"变成"报告"是有章法的，通常走五步：

```
第一步：明确读者与目的（谁看、为什么写、看完要做什么）
第二步：完成分析（比率、趋势、结构、行业比较）
第三步：提炼核心结论（用一句话说清判断）
第四步：搭建金字塔（结论 + 分论点 + 证据，MECE）
第五步：撰写 + 自查（每个比率有解读、风险成段、结论可证伪）
```

前两步是"想清楚"，后三步是"写清楚"。多数失败的报告，问题不在文笔，而在**没想清楚就动笔**——结论还没定型，就先罗列数据。

### 13.4.6 报告提交前的自查清单

写完别急着交，对照清单自查一遍：

| 检查项 | 标准 |
| --- | --- |
| 结论是否先行 | 摘要第一句即结论 |
| 每个比率是否有解读 | 数字后必有"说明什么" |
| 风险是否单独成段 | 具体、量化、可跟踪 |
| 结论是否可证伪 | 有触发条件与预期结果 |
| 读者导向是否清晰 | 读者能直接找到重点 |
| 结论—证据—风险是否一致 | 三者无矛盾 |

任何一条不满足，都应返回修改后再提交。

## 13.5 典型例题

### 例题 1（结论先行改写）

> 下面是一段"差的"报告片段，请按"结论先行"原则改写：

> "2025 年公司营业收入为 50 亿元，同比下降 10%；毛利率从 30% 下降到 25%；应收账款周转天数从 60 天上升到 90 天；存货周转天数从 80 天上升到 120 天；经营现金流为 -2 亿元。销售费用率从 10% 上升到 12%。"

**解**：

原片段是"数据流水账"，读者读到最后才知道公司情况不妙，且所有数据平铺，没有重点。改写为**结论先行**：

> "公司 2025 年盈利能力与现金流质量同步恶化：收入下滑 10%、毛利率降 5 个百分点，同时应收账款与存货周转双双放缓，经营现金流转负。具体而言，收入由上年 55.6 亿元降至 50 亿元（-10%）；毛利率由 30% 降至 25%；应收账款周转天数由 60 天升至 90 天、存货周转天数由 80 天升至 120 天；经营现金流为 -2 亿元；销售费用率由 10% 升至 12%。"

**改写要点**：第一句先给结论（恶化 + 三点表现），随后用"具体而言"引出支撑数据，让读者一眼抓住主旨。

### 例题 2（给数据提炼结论）

> 某公司近三年核心数据如下，请提炼一份不超过三句话的结论：

| 指标 | 2023 | 2024 | 2025 |
| --- | --- | --- | --- |
| 营业收入（亿元） | 40 | 44 | 48 |
| 净利润（亿元） | 4.0 | 4.4 | 4.8 |
| 经营现金流（亿元） | 6.0 | 5.0 | 3.5 |
| 应收账款（亿元） | 8 | 10 | 13 |

**解**：

先算关键比率：

- 收入增速：$44/40-1 = 10\%$，$48/44-1 \approx 9.1\%$，稳步增长；
- 净利率：$4/40 = 10\%$，$4.4/44 = 10\%$，$4.8/48 = 10\%$，稳定；
- 经营现金流：逐年下滑，$5/6 \approx 83.3\%$（-16.7%），$3.5/5 = 70\%$（-30%）；
- 应收账款增速：$10/8-1 = 25\%$，$13/10-1 = 30\%$，远超收入增速；
- 应收账款占收入比：$8/40 = 20\%$ → $10/44 \approx 22.7\%$ → $13/48 \approx 27.1\%$，持续攀升。

**结论**（三句话）：

"公司收入与净利润稳步增长、净利率稳定在 10%，表面健康；但经营现金流由 6 亿元持续下滑至 3.5 亿元，且应收账款增速（25%、30%）远超收入增速（约 10%），说明利润的'含金量'在下降——增长更多依靠放宽信用、赊销拉动。需警惕后续坏账风险与现金流持续恶化的可能。"

### 例题 3（设计报告提纲）

> 你受聘为某银行撰写一份针对某制造业企业的**信贷评估报告**提纲。请按标准框架设计，并突出债权人关注点。

**解**（读者导向：银行，核心是"还钱能力"）：

```
一、摘要：是否建议授信及授信规模建议（结论先行）
二、公司概况：行业、主营、规模、股权
三、经营与财务分析（突出偿债与现金流）：
    3.1 偿债能力：流动比率、速动比率、利息保障倍数
    3.2 现金流质量：经营现金流对负债的覆盖倍数
    3.3 盈利能力：能否产生持续还本付息的能力
    3.4 营运能力：存货与应收的变现速度
四、综合评价：综合判断企业的偿债安全边际
五、风险提示：行业周期风险、担保/抵押风险、集中度风险
六、结论与建议：授信额度、期限、利率与增信条件
```

**要点**：相比投资报告，信贷报告把"偿债能力"提到最前，现金流覆盖指标取代成长性成为主角，且风险提示更强调抵押、担保与行业下行风险。

### 例题 4（识别逻辑谬误）

> 指出下面这段报告片段中的逻辑问题：

> "公司毛利率为 40%，显著高于行业平均的 25%，因此公司是一家优秀的企业，当前股价值得买入。"

**解**：存在至少四处逻辑谬误：

1. **以偏概全**：仅凭毛利率一个指标，就得出"优秀企业"的整体结论，忽略了净利率、现金流、负债、成长性；
2. **归因不当**：毛利率高于行业，可能源于一次性业务、会计政策差异或行业定位不同，未必是持续竞争力；
3. **结论与证据脱节**："毛利率高"是经营判断，而"股价值得买入"是估值判断——毛利高 ≠ 股价被低估，中间缺少估值环节；
4. **缺风险提示**：通篇只讲优点，未提任何风险，结论不可信。

**正确的写法**：毛利率高只是一个"正向信号"，还需结合净利率、现金流、成长性、估值与风险，才能形成"是否买入"的判断。

### 例题 5（风险提示的写法示范）

> 将下面这句"不合格的风险提示"改写为合格的风险提示：

> "公司存在一定经营风险，请投资者注意。"

**解**：

"合格"的风险提示必须**具体、量化、可跟踪**。改写为：

> "需重点关注以下风险：
> 其一，**客户集中风险**：前五大客户收入占比达 60%，若任一头部客户流失，收入可能大幅下滑；
> 其二，**流动性风险**：公司资产负债率 70%，短期有息负债 20 亿元，而账面货币资金仅 5 亿元，存在较大的短期偿付压力；
> 其三，**成本波动风险**：主要原材料价格近一年上涨 30%，若持续上涨，将明显压缩毛利率；
> 其四，**行业景气风险**：所在行业已进入成熟期，需求增速放缓，价格竞争可能加剧。"

**改写要点**：每条风险都遵循"是什么 + 有多严重（量化）+ 可能后果"的结构，让读者能据此评估并跟踪，而非一句空泛的免责声明。

### 例题 6（报告结构逻辑校验）

> 某报告的摘要写道"建议买入"，但正文的"经营与财务分析"只分析了偿债能力与现金流，未涉及盈利能力与成长性；而风险提示部分却大篇幅强调"行业衰退、客户流失"。请指出这份报告的结构问题。

**解**：

1. **结论与证据脱节**：摘要"建议买入"缺乏正文支撑——最关键的盈利与成长两个维度根本没分析；
2. **风险提示与结论矛盾**：风险部分全是利空，却给出"买入"结论，逻辑断裂；
3. **五维度分析不完整**：偿债、营运、盈利、成长、现金流五维度缺了盈利与成长；
4. **修正方向**：要么补充盈利与成长分析以支撑买入结论，要么根据已识别的风险调整结论（如"下调评级"或"观望"），保证**结论、证据、风险三者一致**。

### 例题 7（比率解读三段式应用）

> 把下面的数据改写为"结论 + 数据 + 解读"的完整段落：
> 资产负债率 65%，流动比率 1.1，经营现金流 2 亿元，短期有息负债 15 亿元。

**解**：

> "公司偿债能力偏弱、存在流动性压力：资产负债率 65%，高于行业均值 50%；流动比率仅 1.1，接近警戒线；账面经营现金流 2 亿元，而短期有息负债高达 15 亿元，现金流对短期负债的覆盖不足 0.2 倍，短期偿付主要依赖再融资。若融资环境收紧，将面临较大的资金链风险。"

**要点**：先下结论（偿债弱、有流动性压力），再用三个指标分别佐证，最后落到风险提示，符合"结论 → 数据 → 解读 → 风险"的完整链条。

## 13.6 常见易错点

::: warning 七条高频错误
1. **把报告写成比率清单**：从流动比率念到 ROE，却通篇没有一个结论。报告的价值在"判断"，不在"罗列"。
2. **只有数据没有解读**：堆砌"毛利率 25%、资产负债率 50%"却不说明含义，等于让读者自己算、自己猜。
3. **结论不可证伪**：写成"未来可能增长""整体尚可"这种模糊判断，无法检验，等于没有结论。
4. **忽视风险提示**：通篇乐观，或用一句"存在一定风险"敷衍，是最常见也最危险的错误。
5. **立场不明确**：读完报告不知道作者到底是建议买、建议贷还是建议改进，结论摇摆。
6. **结论与证据脱节**：开头说"建议买入"，中间证据却全是风险，或反之，逻辑断裂。
7. **读者导向不清**：用写给投资者的语气去写信贷报告，把成长性当重点、把偿债当陪衬，读者找不到自己要的东西。
:::

## 13.7 本章要点总结

::: tip 一页纸回顾
- **先问读者是谁**：投资建议（看成长与估值）、信贷评估（看偿债与现金流）、内部经营（看效率与改进），读者决定结构与重点。
- **黄金结构 = 金字塔 + SCQA**：结论先行、分论点 MECE 支撑、证据落地；SCQA（情境-冲突-问题-答案）负责开场。
- **标准六段式**：摘要 → 公司概况 → 经营与财务分析（五维度）→ 综合评价 → 风险提示 → 结论与建议。
- **四条写作原则**：结论先行、数据说话、比率必带解读、风险单独提示。
- **比率解读三段式**：指标值 + 参照系 + 经营含义 ⇒ 结论；共同比 = 项目 / 基准 × 100%。
- **结论要可证伪**：给出"触发条件 + 预期结果"，从观点升级为可检验的判断。
- **风险提示要具体量化**：是什么 + 有多严重 + 可能后果，杜绝"存在一定风险"式空话。
:::

## 13.8 习题

**一、概念题**

1. 财务分析报告有哪三类？各自的读者与重点是什么？
2. 简述金字塔原理的三层结构与 MECE 原则。
3. SCQA 框架的四步分别是什么？各举一句例句。

**二、改写与判断**

4. 下面这段报告片段违反了哪条写作原则？请改写：

   "公司流动比率 1.8，速动比率 1.2，资产负债率 45%，利息保障倍数 8 倍，应收账款周转率 6 次，存货周转率 5 次。"

5. 判断："报告的风险提示可以简短，用'存在一定风险'概括即可。"对吗？为什么？

6. 判断："分析报告篇幅越长、比率列得越全，质量越高。"对吗？为什么？

**三、分析题**

7. 简述六段式标准框架，并说明"摘要"和"结论与建议"两个部分为何都要保留。

8. 什么是"结论可证伪"？请把"公司偿债能力较强"改写成可证伪的表述。

9. 作为债权人写信贷报告时，五维度分析（偿债/营运/盈利/成长/现金流）应如何排序与取舍？为什么？

10. 某报告开头结论为"建议维持授信"，中间却大篇幅分析盈利能力、未提及偿债与现金流。指出问题并说明如何修正。

11. 简述"金字塔原理"与"SCQA 框架"在一份报告中的分工关系。

12. 举例说明"比率堆砌"与"比率解读"的区别，并说明为什么后者才是分析报告的核心价值。

::: details 参考答案
1. 投资建议报告（投资者，重盈利/成长/估值）、信贷评估报告（债权人，重偿债/现金流）、内部经营分析报告（管理层，重效率/改进）。读者不同，重点不同。

2. 金字塔三层：塔尖总结论、塔身分论点、塔基证据。MECE 即分论点之间"相互独立、完全穷尽"，不重叠、不遗漏。

3. S 情境（交代背景）、C 冲突（抛出意外）、Q 问题（提出要回答的问题）、A 答案（给出结论）。

4. 违反"只有数据没有解读/避免堆砌比率"原则——全是比率、没有一个结论。改写：先给结论，如"公司短期偿债能力稳健、长期负债水平适中"，再列数据并逐项解读。

5. 错。风险提示必须具体、量化、可跟踪，逐条说明"是什么 + 有多严重 + 可能后果"，空泛的风险提示等于没有提示。

6. 错。报告价值在结论清晰、证据扎实，不在篇幅和比率数量；冗长且无结论的报告反而更差。

7. 六段式：摘要→公司概况→经营与财务分析→综合评价→风险提示→结论与建议。"摘要"让读者 10 秒抓住主旨、可独立阅读；"结论与建议"给出明确可执行的行动，两者一前一后呼应，前者定调、后者落地。

8. 可证伪即明确"什么条件下结论不成立"。改写："若下季度流动比率跌破 1.2、经营现金流对短期负债覆盖低于 1 倍，则公司偿债能力将明显恶化。"

9. 债权人应把"偿债能力"提到最前、"现金流"次之，作为绝对主角；盈利与营运作为"能否持续还本付息"的支撑；成长性弱化或靠后。因为还债靠现金与资产变现，不靠利润与成长。

10. 问题：结论与证据脱节、读者导向不清——写"授信"却大谈盈利。修正：结论改为围绕偿债与现金流，或补充偿债能力、现金流覆盖、抵押担保等信贷核心分析，使证据支撑结论。

11. SCQA 负责"开场叙事"——用情境、冲突、问题把读者带入并引出主题；金字塔负责"主体展开"——结论先行、分论点支撑、证据落地。两者一前一后：SCQA 讲清"为什么分析"，金字塔给出"结论是什么、凭什么"。

12. 比率堆砌是"毛利率 35%、净利率 12%、ROE 15%"这种只列数字不下判断；比率解读是"毛利率 35%，高于行业均值 28%，说明产品有定价权"这种数字 + 参照系 + 经营含义。后者的核心价值在于把数字翻译成判断，这正是分析报告的真正产出。
:::
