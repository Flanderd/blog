## 学习路径建议

1. **入门**：第一、二章，先建立"数据—指标—图表"的直觉；
2. **基础**：第三至第六章，掌握概率与分布，理解为什么样本均值会稳定；
3. **推断**：第七至第九章，这是统计学的核心，参数估计与假设检验必须熟练；
4. **模型**：第十至第十三章，方差分析、回归、非参数与时间序列按需学习；
5. **应用**：第十四章，面向实际调查与贝叶斯场景。

::: tip 使用建议
每章的公式建议手推一遍，例题先自己做再看解析；遇到不确定的结论，回到"样本—总体—不确定性"这条主线。
:::
