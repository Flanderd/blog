## 核心公式索引

| 主题 | 公式 |
| --- | --- |
| 样本平均数 | $\bar{x}=\dfrac{\sum_{i=1}^{n}x_i}{n}$ |
| 样本方差 | $s^2=\dfrac{\sum_{i=1}^{n}(x_i-\bar{x})^2}{n-1}$ |
| 标准差 | $s=\sqrt{\dfrac{\sum_{i=1}^{n}(x_i-\bar{x})^2}{n-1}}$ |
| 总体均值的区间估计（σ 已知） | $\bar{x}\pm z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$ |
| 总体均值的区间估计（σ 未知） | $\bar{x}\pm t_{\alpha/2}\dfrac{s}{\sqrt{n}}$ |
| 检验统计量（均值） | $z=\dfrac{\bar{x}-\mu_0}{\sigma/\sqrt{n}}$ |
| χ² 拟合优度统计量 | $\chi^2=\sum_{i=1}^{k}\dfrac{(f_{oi}-f_{ei})^2}{f_{ei}}$ |
| 一元线性回归方程 | $\hat{y}=\hat{\beta}_0+\hat{\beta}_1x$ |
| 判定系数 | $R^2=\dfrac{SSR}{SST}=1-\dfrac{SSE}{SST}$ |

## 阅读约定

1. 每节文件以 `# 4.1 集中趋势的度量` 开头，下级为 `## 4.1.1 …` / `### 一、` / `#### （一）`；
2. **例题**统一为 `::: info 【例4-1】` 提示框，框内保留题干、解与计算过程；
3. **公式**：分式一律 `\frac`，多行推导用 `aligned`，原书右侧编号用 `\tag{4.1}`；
4. **表格**：频数分布表、方差分析表、分布临界值表均为 Markdown 表格，跨页续表标「（续表）」；
5. 图（直方图、箱线图、散点图）不重绘，仅保留图题与 `<!-- 图 -->` 标记；
6. 每节末尾以 HTML 注释标注对应 PDF 页码。
