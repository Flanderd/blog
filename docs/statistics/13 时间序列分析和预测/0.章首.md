# 第13章 时间序列分析和预测

**预测国内生产总值**

在生活和工作中经常需要作出预测。比如，预测一只股票的价格走势，预测下一年度的销售额，等等。研究时间序列的主要目的就是进行预测，也就是根据已有的时间序列数据预测未来的变化。选择时间序列预测方法的关键是确定已有序列的变化模式，并假定这种模式会延续到未来。下图是我国 2015 年第 1 季度至 2023 年第 4 季度的国内生产总值（GDP）变化趋势图。

根据上面的图形，你认为国内生产总值包含什么成分？应该选择什么方法来预测下一年各季度的国内生产总值？本章将回答这些问题。

时间序列数据用于描述现象随时间发展变化的特征。时间序列分析就其发展的历史阶段和使用的统计分析方法来看，有传统时间序列分析和现代时间序列分析。本章主要介绍传统的时间序列分析方法，包括时间序列数据的统计描述和预测方法。
