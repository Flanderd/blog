# 第8章 假设检验

**云雾仙茗的传说**

在江南水乡，有一个古老的村庄，村民们世代以种植茶叶为生。这个村庄出产的茶叶以其独特的香气和味道而闻名，被称为“云雾仙茗”。村民们相信，这种茶叶之所以品质出众，是因为村庄周围的云雾山的神秘力量。

随着时间的推移，村庄的茶叶越来越受欢迎，价格也水涨船高。然而，邻近的村庄也开始种植茶叶，他们声称自己的茶叶品质同样优秀，而且价格更便宜。这引起了云雾村村民的担忧，他们担心自己的茶叶会失去市场。

为了证明“云雾仙茗”的独特之处，村长决定举办一场茶叶品鉴大会。他邀请了来自全国各地的茶叶专家和爱好者，让他们在不知道茶叶来源的情况下，品尝云雾村和其他村庄的茶叶，并评价它们的品质。

品鉴大会的规则是这样的：每位品鉴者将品尝两杯茶，一杯来自云雾村，另一杯来自其他村庄。品鉴者根据茶叶的香气、味道、色泽等方面进行评分。村长希望这次品鉴大会收集到的数据能够证明云雾村的茶叶在品质上确实优于其他村庄。

品鉴大会结束后，村长收集了所有品鉴者的评分数据。比较了云雾村和其他村庄茶叶的平均评分差异。如果云雾村的茶叶平均评分显著高于其他村庄，就表明云雾村的茶叶确实具有独特的品质。

这个故事告诉我们，对于某些感兴趣的问题，我们可以建立假设并进行检验，这也是本章所要讨论的内容。

**参数估计**（parameter estimation）和**假设检验**（hypothesis testing）是统计推断的两个组成部分，它们都是利用样本对总体进行某种推断，但推断的角度不同。参数估计讨论的是用样本统计量估计总体参数的方法，总体参数 $\mu$ 在估计前是未知的。而在假设检验中，则是先对 $\mu$ 的值提出一个假设，然后利用样本信息检验这个假设是否成立。因此可以说，本章讨论的内容是如何利用样本信息，对假设成立与否作出判断的一套程序。
