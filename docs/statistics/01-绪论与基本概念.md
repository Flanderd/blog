# 第一章 绪论与基本概念

统计学是研究**如何收集、整理、分析数据**，并在此基础上对未知总体做出推断的科学。它由两部分组成：描述统计（把数据讲清楚）与推断统计（用样本推测总体）。

## 1.1 描述统计与推断统计

| 分支 | 回答的问题 | 典型方法 |
| --- | --- | --- |
| 描述统计 | 这组数据长什么样？ | 均值、方差、频数表、直方图、箱线图 |
| 推断统计 | 从样本能对总体说什么？ | 参数估计、假设检验、回归、方差分析 |

推断统计的核心逻辑：**样本是总体的一个随机切片**，因此结论必然带有不确定性，需要用概率语言表述（置信水平、显著性水平）。

## 1.2 基本概念

| 概念 | 含义 | 记号 |
| --- | --- | --- |
| 总体 | 研究对象的全体 | — |
| 个体 | 总体中的每个元素 | — |
| 样本 | 从总体中抽取的一部分个体 | $X_1, X_2, \dots, X_n$ |
| 样本量 | 样本中个体的个数 | $n$ |
| 参数 | 描述总体特征的常数（未知） | $\mu, \sigma^2, p$ |
| 统计量 | 由样本构造、不含未知参数的函数 | $\bar{X}, S^2, \hat{p}$ |

::: tip 参数 vs 统计量
参数是总体的"真值"，固定但未知；统计量是样本的函数，随抽样而变，是一个随机变量。
例如总体均值 $\mu$ 是参数，样本均值 $\bar{X}$ 是统计量，$\bar{X}$ 用来估计 $\mu$。
:::

## 1.3 数据类型与测量尺度

### 按性质分

- **定性（分类）数据**：性别、行业、税种。
- **定量（数值）数据**：销售额、税率、利润。
  - 离散型：只能取可数值，如户数、人数；
  - 连续型：可在区间内取任意值，如销售额、时间。

### 四种测量尺度

| 尺度 | 特点 | 允许的运算 | 例子 |
| --- | --- | --- | --- |
| 名义（定类） | 只区分类别，无顺序 | 计数、频数 | 行业、地区 |
| 有序（定序） | 类别有顺序，间距不等 | 比较大小、中位数 | 满意度（低/中/高） |
| 等距（定距） | 有顺序且间距相等，无绝对零点 | 加减、均值 | 摄氏温度 |
| 比率（定比） | 有绝对零点 | 加减乘除 | 收入、销售额 |

尺度的等级决定了能做什么运算：**名义数据算平均没有意义**，有序数据一般用中位数而不是均值。

## 1.4 统计工作的基本流程

1. **明确问题**：要估计什么、检验什么；
2. **研究设计**：抽样方案、样本量、变量定义；
3. **数据收集**：调查、实验、日志、数据库；
4. **数据整理**：清洗、编码、缺失值处理；
5. **描述分析**：图表与汇总指标；
6. **推断分析**：估计、检验、建模；
7. **结论与表达**：区分"相关"与"因果"，说明不确定性。

## 1.5 例题

**例 1** 某市想了解个体工商户的平均月收入，随机抽取 500 户调查。

- 总体：该市全部个体工商户；
- 个体：每一户个体工商户；
- 样本：被抽中的 500 户；
- 参数：全市个体工商户的平均月收入 $\mu$；
- 统计量：样本平均月收入 $\bar{X}$。

**例 2** 判断下列变量的测量尺度：① 企业所属行业；② 客户满意度（很不满意/不满意/一般/满意/很满意）；③ 年销售额。

答：① 名义；② 有序；③ 比率。

## 1.6 常见误区

::: warning 三个高频错误
1. **把统计量当参数**：样本均值 $3.2$ 万不代表总体均值就是 $3.2$ 万，它只是估计值。
2. **样本代表性不足**：只调查某类商户，样本再大也推不出全市情况。
3. **混淆相关与因果**：两个变量同时变化，不一定存在因果关系。
:::

## 小结

- 统计学 = 描述统计 + 推断统计；
- 参数描述总体，统计量描述样本；
- 数据类型决定可用方法，测量尺度决定可用运算；
- 一切推断结论都要附带不确定性说明。
