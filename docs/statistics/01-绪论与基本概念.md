# 第一章 统计学是什么

> **先说人话**：统计学就是"用一小部分信息，去猜整体情况，并且说清楚猜得有多准"的学问。

## 1.1 从一个问题说起

假设你开了一家奶茶店，想知道"附近上班族平均每月喝几杯奶茶"。

你不可能问遍几万人，只能问其中一部分人——比如随机拦下 200 个人。

- 这 200 人的平均答案，能不能代表全部人？
- 如果换一批人问，答案会差多少？
- 我有多大的把握说"附近上班族的平均月消费在 5 到 7 杯之间"？

这三个问题，正好对应统计学的三件核心工作：**描述数据、估计总体、量化不确定性**。

## 1.2 统计学的两条腿

| 分支 | 干什么 | 你熟悉的例子 |
| --- | --- | --- |
| 描述统计 | 把已有数据整理清楚、画图、算指标 | 算班级平均分、画月考成绩分布图 |
| 推断统计 | 用样本推测总体，并说明把握有多大 | 用 200 人推断全市、用抽样判断新药是否有效 |

**一句话区分**：描述统计只回答"我手上这堆数据长什么样"；推断统计回答"我能不能把它推广到没看到的那部分"。

::: tip 为什么不能只看描述统计
你测了 200 人，发现平均每月 6 杯。但"6 杯"只是**样本**的平均值，不是全市的真值。推断统计要回答的是：真值大概在什么范围？我说错的概率有多大？
:::

## 1.3 六个必须分清的词

用一个例子贯穿：**调查全校 3000 名学生的身高**。

| 词 | 含义 | 在这个例子里 |
| --- | --- | --- |
| 总体 | 研究对象的**全部** | 全校 3000 名学生 |
| 个体 | 总体中的**每一个** | 每一名学生 |
| 样本 | 从总体中抽出的**一部分** | 随机抽的 100 人 |
| 样本量 | 样本里个体的个数 | $n = 100$ |
| 参数 | 描述总体的数（**未知**） | 全校平均身高 $\mu$ |
| 统计量 | 由样本算出的数（**已知**） | 抽中 100 人的平均身高 $\bar{x}$ |

**符号约定**（以后会反复出现）：

| 总体（参数） | 样本（统计量） |
| --- | --- |
| 均值 $\mu$ | 均值 $\bar{x}$ |
| 方差 $\sigma^2$ | 方差 $s^2$ |
| 比例 $p$ | 比例 $\hat{p}$ |
| 样本量 $N$ | 样本量 $n$ |

::: warning 最容易混淆的一对
**参数是总体的、固定的、未知的；统计量是样本的、随机变化的、算得出来的。**
"全校平均身高"是参数，"我抽的 100 人的平均身高"是统计量。抽样不同，统计量就不同——这正是推断统计要处理的不确定性来源。
:::

## 1.4 数据分两类

### 1.4.1 定性数据（分类）

只表示"属于哪一类"，不能直接做加减：性别、专业、税种、地区。

### 1.4.2 定量数据（数值）

表示"多少"，可以做运算：销售额、人数、身高、利润率。

- **离散型**：只能取一个个可数的值，如户数、人数、车辆数；
- **连续型**：在区间内可以取任意值，如销售额（可以是 1234.56 元）、时间。

::: tip 一个判断小技巧
问自己："这个数据能不能再细分？"
人数只能 3 人、4 人，不能 3.5 人 → 离散；
销售额可以是 3.5 万元 → 连续。
:::

## 1.5 四种测量尺度（决定了你能算什么）

| 尺度 | 特点 | 能做的运算 | 例子 |
| --- | --- | --- | --- |
| 名义（定类） | 只是标签，无顺序 | 数个数、算比例 | 行业、血型、地区 |
| 有序（定序） | 有顺序，但间距不等 | 比大小、找中位数 | 满意度（差/中/好） |
| 等距（定距） | 有顺序，间距相等，但零点是人为的 | 加减、算均值 | 摄氏温度 |
| 比率（定比） | 有绝对零点 | 加减乘除 | 收入、销售额、身高 |

**为什么重要**：

- 名义数据算"平均行业"毫无意义；
- 有序数据可以说"中位数是'满意'"，但不能说"满意度平均 2.7"；
- 摄氏 20 度不是 10 度的"两倍"（因为 0 度不是"没有温度"），但 20 万元是 10 万元的**两倍**（0 元就是没有）。

## 1.6 一次统计工作的完整流程

1. **提出问题**：要估计什么？（附近上班族月均奶茶消费）
2. **设计调查**：抽谁、抽多少、怎么问？
3. **收集数据**：问卷、访谈、系统导出。
4. **整理数据**：清洗异常值、缺失值、统一格式。
5. **描述分析**：均值、中位数、图表。
6. **推断分析**：给出区间估计或检验结论。
7. **写结论**：说清适用范围与不确定性。

::: warning 第 3 步最容易翻车
调查 200 人，如果只在写字楼门口拦人，就漏掉了外卖骑手、附近居民——这叫**覆盖偏差**。样本再大，偏了就是偏了。
:::

## 1.7 例题

**例 1** 判断下列是参数还是统计量：

① 全市个体工商户的平均月收入；② 抽取的 500 户的平均月收入；③ 全市的真实次品率；④ 抽检 100 件算出的次品率。

答：①③ 是参数（总体的、未知的）；②④ 是统计量（样本的、算出来的）。

**例 2** 判断数据类型与测量尺度：

① 企业所属行业；② 客户满意度（五级）；③ 年销售额；④ 员工人数。

答：① 定性、名义；② 定性、有序；③ 定量、连续、比率；④ 定量、离散、比率。

**例 3** 某班 40 人，随机抽 10 人测视力，平均 4.8。这里的 $n$、$\bar{x}$、$\mu$ 分别是什么？

答：$n = 10$（样本量），$\bar{x} = 4.8$（统计量），$\mu$ 是全班平均视力（参数，未知）。

## 1.8 统计学在生活中的五个场景

1. **医疗检测**：一次阳性结果意味着什么？要结合患病率（基率）才能算准。
2. **天气预报**："降水概率 70%"是频率与模型的结合，不是"一定下雨"。
3. **质量控制**：抽检一批零件，判断整批是否合格——这就是假设检验。
4. **A/B 测试**：新版页面转化率高了 2%，是真实提升还是随机波动？
5. **金融风控**：根据历史违约数据估计新客户的违约概率。

**统计思维三问**（遇到数据结论先问这三句）：

- 样本是怎么来的？能代表总体吗？
- 数字的不确定性有多大？（区间、误差）
- 相关背后有没有别的解释？（混杂因素、因果方向）

## 1.9 新手最容易踩的坑

::: warning 三个高频误区
1. **把样本均值当成总体真值**：$\bar{x} = 4.8$ 只是估计，换个样本可能变成 4.7。
2. **以为样本越大越准**：样本有系统偏差时（只调查某一类人），越大只是越精确地错。
3. **把相关当因果**：夏天冰淇淋销量和溺水人数同时上升，不是冰淇淋导致溺水，而是"夏天"这个共同原因。
:::

## 1.10 练习

1. 想了解某市网约车司机的平均月收入，随机抽取 300 名司机。指出总体、样本、参数、统计量。
2. 判断数据类型：① 婚姻状况；② 子女数量；③ 月用水量；④ 受教育程度（小学/初中/高中/大学）。
3. 下列说法对吗："因为样本均值是 5000 元，所以全市平均工资就是 5000 元。"
4. 为什么名义数据不能算平均数？
5. 如果调查只覆盖市中心的白领，结论能推广到全市吗？为什么？

::: details 参考答案
1. 总体：该市全部网约车司机；样本：被抽中的 300 名；参数：全市司机平均月收入；统计量：300 人的平均月收入。
2. ① 定性名义；② 定量离散；③ 定量连续；④ 定性有序。
3. 不对。5000 元是样本统计量，只是对总体参数的估计，应给出区间与把握程度。
4. 名义数据只是标签，标签之间没有大小和距离，"平均"没有实际含义。
5. 不能。样本缺乏代表性（覆盖偏差），结论只适用于市中心白领群体。
:::

## 小结

- 统计学 = 描述统计（讲清数据）+ 推断统计（由样本推总体）；
- 参数描述总体、统计量描述样本，前者未知、后者可算；
- 数据类型决定方法，测量尺度决定运算；
- 一切推断结论都要说明"范围"和"把握"。
