# 第十四章 抽样调查与贝叶斯统计

## 14.1 抽样设计

| 设计 | 做法 | 适用 | 注意 |
| --- | --- | --- | --- |
| 简单随机 | 等概率抽取 | 抽样框完整、规模不大 | 实施成本高 |
| 分层 | 层内随机、层间独立 | 层内同质、层间异质 | 需分层变量 |
| 整群 | 抽群、群内全查 | 抽样框只有群的名单 | 群内相关大，误差大 |
| 系统 | 等间隔抽取 | 名单有序、无周期 | 警惕周期性 |
| 多阶段 | 分层 + 整群组合 | 大规模调查 | 方差估计复杂 |

## 14.2 估计量与误差

简单随机抽样下，总体均值 $\bar{Y}$ 的估计为样本均值 $\bar{y}$，其方差：

$$
V(\bar{y}) = \left(1 - \frac{n}{N}\right)\frac{S^2}{n}
$$

其中 $\left(1 - \frac{n}{N}\right)$ 为有限总体修正系数。当 $n/N \le 0.05$ 时可忽略。

**比例**的估计类似：

$$
V(\hat{p}) = \left(1 - \frac{n}{N}\right)\frac{p(1-p)}{n-1}
$$

**设计效应**（deff）：

$$
\text{deff} = \frac{\text{实际设计的方差}}{\text{同样本量简单随机抽样的方差}}
$$

整群抽样 deff 通常大于 1，分层抽样通常小于 1。

::: tip 分层为什么更准
分层把总体切成内部同质的层，层内方差小；总方差是各层方差的加权平均，
因此分层估计的方差通常低于简单随机抽样——前提是分层变量与目标变量相关。
:::

## 14.3 非抽样误差

- **覆盖误差**：抽样框不完整（漏掉部分群体）；
- **无回答误差**：拒访、失联，且无回答者往往与回答者不同；
- **计量误差**：问卷设计、访员、回忆偏差；
- **录入与处理误差**。

应对：提高应答率、加权调整、敏感性问题的随机化回答、严格质控。

## 14.4 样本量的确定

估计均值：

$$
n = \frac{z_{\alpha/2}^2 S^2}{E^2}
$$

估计比例（$p$ 未知取 0.5）：

$$
n = \frac{z_{\alpha/2}^2 \times 0.25}{E^2}
$$

分层抽样按层内方差与成本分配（Neyman 分配）：

$$
n_i \propto \frac{N_i S_i}{\sqrt{c_i}}
$$

## 14.5 贝叶斯统计的基本思想

频率学派把参数看作固定常数；贝叶斯学派把参数看作随机变量，用**先验分布**表达已有认识，用数据更新为**后验分布**。

$$
p(\theta \mid x) = \frac{p(x \mid \theta)\,p(\theta)}{p(x)} \propto p(x \mid \theta)\,p(\theta)
$$

- $p(\theta)$：先验；
- $p(x \mid \theta)$：似然；
- $p(\theta \mid x)$：后验。

**共轭先验**：后验与先验同族，计算方便。例如二项分布的共轭先验是 Beta 分布：

$$
\theta \sim \text{Beta}(\alpha, \beta), \quad X \sim B(n,\theta)
\Rightarrow \theta \mid X \sim \text{Beta}(\alpha + X,\ \beta + n - X)
$$

## 14.6 贝叶斯 vs 频率

| | 频率学派 | 贝叶斯学派 |
| --- | --- | --- |
| 参数 | 固定常数 | 随机变量 |
| 概率解释 | 长期频率 | 主观信念程度 |
| 区间 | 置信区间 | 可信区间（可直接说概率） |
| 先验信息 | 不使用 | 显式引入 |
| 小样本 | 依赖大样本性质 | 可结合先验 |

::: warning 先验的选择会影响结论
先验过强会"压过"数据；先验过弱（如均匀先验）则接近频率学派结果。
敏感性分析应报告不同先验下的结论是否稳定。
:::

## 14.7 例题

某产品合格率的先验为 $\text{Beta}(2, 2)$（均值 0.5）。抽检 20 件，18 件合格。

后验为 $\text{Beta}(2 + 18,\ 2 + 2) = \text{Beta}(20, 4)$，后验均值：

$$
\frac{20}{20 + 4} \approx 0.833
$$

相比样本比例 $0.9$，后验被先验拉低了一些——先验起到了"收缩"作用。

## 小结

- 抽样设计决定估计精度，分层与整群各有取舍；
- 非抽样误差无法靠增大样本消除；
- 贝叶斯用先验 + 数据得到后验，适合小样本与有先验知识的场景；
- 报告结论时应说明设计效应、误差来源与先验选择。
