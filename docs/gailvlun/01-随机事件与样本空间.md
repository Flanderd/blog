# 第一章 随机事件与样本空间

> **本章定位**：这一章不涉及任何计算，只做一件事——**把"随机"这件事翻译成数学**。翻译的工具是集合论：试验的所有可能结果构成一个集合，事件就是这个集合的子集。看起来抽象，但它决定了你后面能不能把一道文字题正确写成 $P(A\cup B)$。**概率学不好的人，八成卡在这一步，而不是卡在积分上。**

## 1.1 三种"不确定"

日常生活里有三类现象：

| 类型 | 特征 | 例子 |
| --- | --- | --- |
| **确定性现象** | 条件给定，结果唯一 | 标准大气压下纯水加热到 100°C 会沸腾；$2+3=5$ |
| **随机现象** | 条件给定，结果**不止一个**，事先无法确定哪一个 | 掷骰子的点数；明天是否下雨；抛硬币的正反面 |
| **模糊现象** | 边界不清，"是不是"本身没有明确答案 | "高个子""年轻人""满意" |

概率论与数理统计研究的是**第二类**。

注意"随机"不等于"没有规律"。掷一次骰子无法预测，但掷一万次，每个点数出现的频率都在 $1/6$ 附近。**单次不可预测，大量重复呈现稳定规律**——这就是随机现象的"统计规律性"，也是整门课存在的理由。

::: tip 一个容易混淆的点
"随机"不是"随便"。随机意味着**所有可能结果已知，且每个结果有确定的概率**；"随便"意味着你根本不知道有哪些可能。前者可以建模，后者只能算命。
:::

## 1.2 随机试验

把对随机现象的观察或实验称为**随机试验**（random experiment），记作 $E$。它必须满足三条：

1. **可在相同条件下重复进行**（可重复性）；
2. **所有可能结果事先已知**（结果可预知）；
3. **每次试验前无法确定会出现哪个结果**（不确定性）。

三条缺一不可。举个反例：

- "明天会不会下雨"——结果已知（下/不下），但**不能重复**，严格说不是随机试验（虽然我们仍可用概率描述它，这属于主观概率的范畴）；
- "掷骰子出现几点"——三条全满足，是标准随机试验；
- "测量一个零件的长度"——结果是一个实数，可重复，事先不知，满足。

## 1.3 样本空间：把所有可能结果装进一个集合

### 1.3.1 定义

随机试验 $E$ 的**所有可能结果**组成的集合，称为**样本空间**（sample space），记作 $\Omega$。

$\Omega$ 中的每一个元素（每一个可能结果）称为**样本点**（sample point），记作 $\omega$。

$$
\Omega = \{\omega \mid \omega \text{ 是试验的一个可能结果}\}
$$

### 1.3.2 三类样本空间

| 类型 | 描述 | 例子 |
| --- | --- | --- |
| **有限**（离散） | 样本点个数有限 | 掷一颗骰子：$\Omega=\{1,2,3,4,5,6\}$ |
| **无限可列** | 样本点能一个一个排出来 | 抛硬币直到出现正面：$\Omega=\{正, 反正, 反反正, \dots\}$，对应次数 $\{1,2,3,\dots\}$ |
| **无限不可列** | 样本点连续分布 | 灯泡寿命：$\Omega=[0,+\infty)$；等公交时间：$\Omega=[0,10]$ |

### 1.3.3 写样本空间的三个要点

**要点一：先明确"观察什么"**

掷两颗骰子，观察"点数和"，则

$$
\Omega = \{2,3,4,\dots,12\}
$$

但如果观察"两颗骰子各自的点数"，则

$$
\Omega = \{(i,j)\mid i,j = 1,2,\dots,6\},\qquad |\Omega| = 36
$$

**同一个试验，观察角度不同，样本空间不同。** 这一点非常重要：第一种写法只有 11 个样本点，但它们**不是等可能的**（和为 7 有 6 种方式，和为 2 只有 1 种）；第二种写法 36 个样本点才等可能。第二章算古典概率时，**必须选等可能的那个样本空间**，否则答案必错。

**要点二：样本点必须"互斥且穷尽"**

- 互斥：一次试验只能出现一个样本点；
- 穷尽：所有可能结果都被包含。

漏掉一种可能（比如忘记"平局"）是最常见的建模错误。

**要点三：分清"可列"与"不可列"**

这决定了后面用**分布律**（求和）还是**密度函数**（积分）。灯泡寿命是连续量，写 $\Omega=\{1,2,3,\dots\}$ 就错了。

## 1.4 随机事件

### 1.4.1 定义

样本空间 $\Omega$ 的**子集**称为**随机事件**（random event），简称事件，用大写字母 $A,B,C,\dots$ 表示。

当试验结果 $\omega \in A$ 时，称**事件 $A$ 发生**。

三类特殊事件：

| 名称 | 记号 | 含义 |
| --- | --- | --- |
| **必然事件** | $\Omega$ | 每次试验一定发生 |
| **不可能事件** | $\varnothing$ | 每次试验一定不发生 |
| **基本事件** | $\{\omega\}$ | 只含一个样本点，不能再分 |

**例**：掷一颗骰子，$\Omega=\{1,2,3,4,5,6\}$。

- $A=\{$出现偶数$\}=\{2,4,6\}$ 是复合事件；
- $B=\{$出现 3$\}=\{3\}$ 是基本事件；
- $C=\{$点数小于 7$\}=\Omega$ 是必然事件；
- $D=\{$点数为 7$\}=\varnothing$ 是不可能事件。

::: warning 事件是集合，不是数字
初学最容易犯的错：把"事件 $A$"当成一个数。$A=\{2,4,6\}$，$P(A)=1/2$——$A$ 是集合，$P(A)$ 才是数。后面写 $A\cup B$、$\bar{A}$ 时，操作对象永远是集合。
:::

## 1.5 事件之间的关系

设 $A,B$ 是同一试验的事件（即 $\Omega$ 的子集）。

| 关系 | 记号 | 定义 | 掷骰子例子 |
| --- | --- | --- | --- |
| **包含** | $A\subset B$ | $A$ 发生必然导致 $B$ 发生 | $A=\{2\}$，$B=\{$偶数$\}$ |
| **相等** | $A=B$ | $A\subset B$ 且 $B\subset A$ | $\{$偶数$\}=\{2,4,6\}$ |
| **互斥**（互不相容） | $AB=\varnothing$ | 不能同时发生 | $A=\{1\}$，$B=\{2\}$ |
| **对立**（互逆） | $B=\bar{A}$ | 必有一个发生，且不能同时发生 | $A=\{$偶数$\}$，$\bar{A}=\{$奇数$\}$ |

### 1.5.1 互斥与对立：最容易混的一对

- **互斥**：$AB=\varnothing$，即"不能同时发生"。**不要求必有一个发生。**
- **对立**：$AB=\varnothing$ **且** $A\cup B=\Omega$，即"不能同时发生，且必有一个发生"。

关系：**对立一定互斥，互斥不一定对立。**

**例（掷骰子）**：

- $A=\{1\}$，$B=\{2\}$：互斥，但不对立（因为还可能掷出 3）；
- $A=\{1,3,5\}$，$B=\{2,4\}$：互斥，但不对立（漏了 6）；
- $A=\{1,3,5\}$，$B=\{2,4,6\}$：互斥**且**对立，$B=\bar{A}$。

::: tip 用"分蛋糕"理解
把 $\Omega$ 想成一块蛋糕。互斥 = 两块不重叠的蛋糕；对立 = 两块不重叠**且正好把整块蛋糕分完**。所以对立是互斥的"加强版"。
:::

**一条常用结论**：若 $A,B$ 互斥，则 $P(A\cup B)=P(A)+P(B)$；若 $A,B$ 对立，则 $P(A)+P(B)=1$。

## 1.6 事件的运算

| 运算 | 记号 | 含义 | 通俗读法 |
| --- | --- | --- | --- |
| **和**（并） | $A\cup B$ | $A$ 与 $B$ 至少一个发生 | "或" |
| **积**（交） | $A\cap B$，简记 $AB$ | $A$ 与 $B$ 同时发生 | "且" |
| **差** | $A-B$ | $A$ 发生而 $B$ 不发生 | "$A$ 且非 $B$" |
| **对立** | $\bar{A}$ | $A$ 不发生 | "非 $A$" |

注意：$A-B = A\bar{B} = A - AB$。

### 1.6.1 运算律

$$
\begin{aligned}
&\text{交换律：} && A\cup B = B\cup A, && AB = BA\\
&\text{结合律：} && (A\cup B)\cup C = A\cup(B\cup C), && (AB)C = A(BC)\\
&\text{分配律：} && A(B\cup C) = AB\cup AC, && A\cup(BC) = (A\cup B)(A\cup C)\\
&\text{吸收律：} && A\cup(AB) = A, && A(A\cup B) = A\\
&\text{德摩根律：} && \overline{A\cup B} = \bar{A}\bar{B}, && \overline{AB} = \bar{A}\cup\bar{B}
\end{aligned}
$$

::: warning 分配律的第二个式子是反直觉的
$A\cup(BC) = (A\cup B)(A\cup C)$，看起来像"展开后应该多出一项"。它确实成立，因为它对应集合的分配律（交对并、并对交都分配），与算术里的 $a+(bc)\ne(a+b)(a+c)$ 完全不同。**集合运算和算术运算不是一回事，不要类比。**
:::

### 1.6.2 德摩根律：本章最重要的公式

$$
\overline{A\cup B} = \bar{A}\cap\bar{B},\qquad
\overline{A\cap B} = \bar{A}\cup\bar{B}
$$

**用大白话读**：

- "不是（$A$ 或 $B$）" = "既不是 $A$，也不是 $B$"；
- "不是（$A$ 且 $B$）" = "至少有一个没发生"。

**证明（第一个式子，用集合相等的方法）**：

设 $\omega\in\overline{A\cup B}$。由对立的定义，$\omega\notin A\cup B$，即 $\omega$ 既不属于 $A$ 也不属于 $B$，故 $\omega\in\bar{A}$ 且 $\omega\in\bar{B}$，于是 $\omega\in\bar{A}\bar{B}$。这证明了 $\overline{A\cup B}\subset\bar{A}\bar{B}$。

反过来，设 $\omega\in\bar{A}\bar{B}$，则 $\omega\notin A$ 且 $\omega\notin B$，故 $\omega\notin A\cup B$，即 $\omega\in\overline{A\cup B}$，得 $\bar{A}\bar{B}\subset\overline{A\cup B}$。

两向包含，故相等。$\blacksquare$

**推广到 $n$ 个事件**：

$$
\overline{A_1\cup A_2\cup\cdots\cup A_n} = \bar{A}_1\bar{A}_2\cdots\bar{A}_n,
\qquad
\overline{A_1A_2\cdots A_n} = \bar{A}_1\cup\bar{A}_2\cup\cdots\cup\bar{A}_n
$$

**这条推广在解题中极其常用**：凡是看到"至少有一个"，先取对立变成"一个都没有"，再用乘法（若独立）。这是概率题的第一反射。

### 1.6.3 事件域（选读）

严格地说，并不是 $\Omega$ 的**所有**子集都能被称为事件——在不可列样本空间上，会存在无法赋予概率的"病态集合"。因此公理化定义要求事件构成一个 **$\sigma$-代数** $\mathcal{F}$：

1. $\Omega\in\mathcal{F}$；
2. 若 $A\in\mathcal{F}$，则 $\bar{A}\in\mathcal{F}$；
3. 若 $A_1,A_2,\dots\in\mathcal{F}$，则 $\bigcup_{i=1}^{\infty}A_i\in\mathcal{F}$。

对初学者而言，只需知道：**我们日常处理的事件（区间、有限集合、它们的并与交）都满足这些条件**，可以放心使用。这部分不影响计算，了解即可。

## 1.7 核心技能：把中文翻译成事件

这是本章真正的考点。设 $A,B,C$ 是三个事件。

| 中文表述 | 事件表示 |
| --- | --- |
| $A$ 发生 | $A$ |
| $A$ 不发生 | $\bar{A}$ |
| $A,B$ 都发生 | $AB$ |
| $A,B$ 至少有一个发生 | $A\cup B$ |
| $A,B$ 都不发生 | $\bar{A}\bar{B} = \overline{A\cup B}$ |
| $A,B$ 恰有一个发生 | $A\bar{B}\cup\bar{A}B$ |
| $A,B$ 不都发生 | $\overline{AB} = \bar{A}\cup\bar{B}$ |
| $A,B$ 至多有一个发生 | $\overline{AB}$（等价于"不都发生"） |
| 三个事件至少一个发生 | $A\cup B\cup C$ |
| 三个事件一个都不发生 | $\bar{A}\bar{B}\bar{C}$ |
| 三个事件恰好一个发生 | $A\bar{B}\bar{C}\cup\bar{A}B\bar{C}\cup\bar{A}\bar{B}C$ |
| 三个事件恰好两个发生 | $AB\bar{C}\cup A\bar{B}C\cup\bar{A}BC$ |
| 三个事件至少两个发生 | $AB\cup AC\cup BC$（**不能写成** $ABC$） |
| 三个事件至多一个发生 | $\bar{A}\bar{B}\bar{C}\cup A\bar{B}\bar{C}\cup\bar{A}B\bar{C}\cup\bar{A}\bar{B}C$ |
| 只有 $A$ 发生 | $A\bar{B}\bar{C}$ |

::: danger 三个高频错误
1. **"至少两个发生"写成 $ABC$**。$ABC$ 是"三个都发生"，比"至少两个"窄。正确是 $AB\cup AC\cup BC$。
2. **"至多一个发生"漏掉"一个都没有"**。它等于"恰好零个"+"恰好一个"，或直接用对立"至少两个"的补。
3. **"不都发生"误写成"都不发生"**。"不都发生"只要求不是三个全发生，允许其中两个发生；"都不发生"要求一个都没有。
:::

**验证方法**：代入具体情形检验。例如判断 $AB\cup AC\cup BC$ 是否等于"至少两个发生"：取"$A,B$ 发生、$C$ 不发生"，则 $AB$ 为真，并集为真；而"至少两个"也为真，一致。再看"只有 $A$ 发生"，$AB,AC,BC$ 全假，并集为假，也一致。

## 1.8 典型例题

### 例题 1（写样本空间）

> 写出下列随机试验的样本空间：
> （1）掷一颗骰子，观察点数；
> （2）连续抛一枚硬币 3 次，观察正反面出现的情况；
> （3）测试一只灯泡的寿命（小时）；
> （4）某路口一分钟内通过的车辆数。

**解**：

（1）$\Omega_1 = \{1,2,3,4,5,6\}$，有限。

（2）用 $H$ 表示正面，$T$ 表示反面：

$$
\Omega_2 = \{HHH,\ HHT,\ HTH,\ HTT,\ THH,\ THT,\ TTH,\ TTT\},\quad |\Omega_2|=8
$$

也可写成 $\{H,T\}^3$。

（3）寿命是非负实数：

$$
\Omega_3 = [0,+\infty)
$$

无限不可列。注意**不能**写成 $\{0,1,2,\dots\}$，除非题目规定"只记录整小时数"。

（4）车辆数是计数：

$$
\Omega_4 = \{0,1,2,3,\dots\}
$$

无限可列。

### 例题 2（事件的语言翻译）

> 设 $A,B,C$ 分别表示"甲、乙、丙三人考试及格"。用 $A,B,C$ 表示下列事件：
> （1）三人都及格；
> （2）至少一人及格；
> （3）恰有两人及格；
> （4）至少两人及格；
> （5）三人都不及格；
> （6）只有甲不及格。

**解**：

（1）$ABC$；

（2）$A\cup B\cup C$；

（3）$AB\bar{C}\cup A\bar{B}C\cup \bar{A}BC$；

（4）$AB\cup AC\cup BC$（注意不能写 $ABC$）；

（5）$\bar{A}\bar{B}\bar{C}$；

（6）$\bar{A}BC$。

### 例题 3（互斥与对立的判断）

> 掷一颗骰子，$\Omega=\{1,2,3,4,5,6\}$。判断下列各组事件是否互斥、是否对立：
> （1）$A=\{1,2\}$，$B=\{3,4\}$；
> （2）$A=\{1,2,3\}$，$B=\{4,5,6\}$；
> （3）$A=\{1,3,5\}$，$B=\{2,4\}$；
> （4）$A=\{1,2\}$，$B=\{1,3\}$。

**解**：

| 组 | $AB$ | $A\cup B$ | 互斥？ | 对立？ |
| --- | --- | --- | --- | --- |
| （1） | $\varnothing$ | $\{1,2,3,4\}$ | 是 | 否（漏 5,6） |
| （2） | $\varnothing$ | $\Omega$ | 是 | **是** |
| （3） | $\varnothing$ | $\{1,2,3,4,5\}$ | 是 | 否（漏 6） |
| （4） | $\{1\}$ | $\{1,2,3\}$ | 否 | 否 |

**规律**：先看交集是否为空（判互斥），再看并集是否为 $\Omega$（判对立）。

### 例题 4（用运算律化简）

> 化简下列事件：
> （1）$(A\cup B)(A\cup\bar{B})$；
> （2）$A\cup\bar{A}B$。

**解**：

（1）用分配律（并对交分配）：

$$
(A\cup B)(A\cup\bar{B}) = A\cup(B\bar{B}) = A\cup\varnothing = A
$$

**直观**："$A$ 或 $B$"且"$A$ 或非 $B$"——不管 $B$ 发不发生，$A$ 都得发生；而只要 $A$ 发生，两个括号都满足。所以等价于 $A$。

（2）

$$
A\cup\bar{A}B = (A\cup\bar{A})(A\cup B) = \Omega\cdot(A\cup B) = A\cup B
$$

**直观**："$A$ 发生，或者（$A$ 不发生且 $B$ 发生）"——这正好就是"$A$ 或 $B$ 至少一个发生"。

::: tip 化简的两个套路
把"并"当加法、"交"当乘法来展开（但**只能用集合运算律**），然后消去 $A\bar{A}=\varnothing$、$A\cup\bar{A}=\Omega$、$A\cup AB=A$。
:::

### 例题 5（德摩根律的应用）

> 某系统由三个部件组成，只要有一个部件失效，系统就报警。设 $A_i$ 表示"第 $i$ 个部件失效"，用 $A_i$ 表示：
> （1）系统报警；
> （2）系统不报警。

**解**：

（1）"至少一个失效"：$A_1\cup A_2\cup A_3$。

（2）"不报警"即"没有一个失效"：

$$
\overline{A_1\cup A_2\cup A_3} = \bar{A}_1\bar{A}_2\bar{A}_3
$$

这里已经能看出德摩根律的价值：**"至少一个"的对立是"一个都没有"**。这个转换会在第三章求"至少一次"型概率时反复使用。

## 1.9 常见易错点

::: warning 七条高频错误
1. **样本空间漏项**：如"抛两次硬币"只写 4 个结果（漏了顺序不同的情况），导致分母错误。
2. **样本点不等可能却用古典公式**：如把两颗骰子的和写成 $\{2,\dots,12\}$ 共 11 个样本点，误以为每个概率 $1/11$。
3. **混淆事件与概率**：$A$ 是集合，$P(A)$ 是数，$A$ 不能直接与 $0.5$ 比较。
4. **互斥当对立**：互斥只要求不能同时发生，不要求必有一个发生。
5. **"至少两个"写成 $ABC$**：见 1.7 的警告。
6. **"不都发生"写成"都不发生"**：前者是 $\overline{ABC}$，后者是 $\bar{A}\bar{B}\bar{C}$。
7. **对连续样本空间数点**：$[0,10]$ 上的样本点不可数，不能"数个数"，必须用几何度量（第二章）。
:::

## 1.10 本章要点总结

::: tip 一页纸回顾
- **随机现象**：单次不可预测，大量重复呈现稳定频率——这是概率论的研究对象。
- **随机试验三条件**：可重复、结果已知、事先不确定。
- **样本空间 $\Omega$**：所有可能结果的集合；样本点是元素。分有限、无限可列、无限不可列三类。
- **事件**：$\Omega$ 的子集。必然事件 $\Omega$，不可能事件 $\varnothing$。
- **关系**：包含、相等、互斥（$AB=\varnothing$）、对立（$AB=\varnothing$ 且 $A\cup B=\Omega$）。对立必互斥，反之不然。
- **运算**：并（或）、交（且）、差、对立。分配律对并对交都成立。
- **德摩根律**：$\overline{A\cup B}=\bar{A}\bar{B}$，$\overline{AB}=\bar{A}\cup\bar{B}$。"至少一个"的对立是"一个都没有"。
- **翻译能力是本 chapter 的核心产出**，比任何公式都重要。
:::

## 1.11 习题

**一、基础题**

1. 写出下列试验的样本空间，并指出是有限、无限可列还是无限不可列：
   （1）掷两颗骰子，观察点数之和；
   （2）从一副 52 张牌中任取一张，观察花色；
   （3）记录某电话交换台一分钟内接到的呼叫次数；
   （4）测量某地一年的降水量。

2. 设 $A,B,C$ 是三个事件，用它们表示：
   （1）$A$ 发生而 $B,C$ 不发生；
   （2）$A,B,C$ 中至少有两个发生；
   （3）$A,B,C$ 中恰有一个发生；
   （4）$A,B,C$ 中至多有两个发生。

3. 判断：若 $A$ 与 $B$ 对立，则 $A$ 与 $B$ 一定互斥；反之是否成立？举例说明。

**二、运算题**

4. 化简：
   （1）$(A\cup B)(\bar{A}\cup B)$；
   （2）$AB\cup A\bar{B}$；
   （3）$\overline{\bar{A}\cup B}$。

5. 证明：$A-B = A\bar{B}$，并用文字解释这个等式的含义。

**三、应用题**

6. 某电路中有三个串联开关，只要有一个断开电路就不通。设 $A_i$ 表示"第 $i$ 个开关断开"，用 $A_i$ 表示"电路不通"和"电路通"。

7. 甲、乙两人各射击一次，$A=\{$甲命中$\}$，$B=\{$乙命中$\}$。用 $A,B$ 表示：
   （1）恰有一人命中；
   （2）至少一人命中；
   （3）两人都未命中；
   （4）目标被命中但只有一发子弹命中。

::: details 参考答案
1. （1）$\{2,3,\dots,12\}$，有限（但样本点不等可能，见第二章注意）。
   （2）$\{$黑桃, 红桃, 梅花, 方块$\}$，有限。
   （3）$\{0,1,2,\dots\}$，无限可列。
   （4）$[0,+\infty)$，无限不可列。

2. （1）$A\bar{B}\bar{C}$；
   （2）$AB\cup AC\cup BC$；
   （3）$A\bar{B}\bar{C}\cup\bar{A}B\bar{C}\cup\bar{A}\bar{B}C$；
   （4）$\overline{ABC}$（"至多两个"= "不是三个都发生"）。

3. 前半句对：对立要求 $AB=\varnothing$ 且 $A\cup B=\Omega$，故必互斥。反之不成立：掷骰子中 $A=\{1\}$、$B=\{2\}$ 互斥，但 $A\cup B\ne\Omega$，不对立。

4. （1）$(A\cup B)(\bar{A}\cup B) = B\cup A\bar{A} = B$（分配律展开：$A\bar{A}\cup AB\cup B\bar{A}\cup BB = \varnothing\cup AB\cup\bar{A}B\cup B = B$）。
   （2）$AB\cup A\bar{B} = A(B\cup\bar{B}) = A$。
   （3）$\overline{\bar{A}\cup B} = \overline{\bar{A}}\cdot\bar{B} = A\bar{B}$。

5. 证明：$\omega\in A-B \iff \omega\in A$ 且 $\omega\notin B \iff \omega\in A\bar{B}$，故相等。
   含义："$A$ 发生而 $B$ 不发生"等价于"$A$ 发生且 $B$ 不发生"，即从 $A$ 中挖掉与 $B$ 的公共部分。

6. 电路不通（至少一个断开）：$A_1\cup A_2\cup A_3$；
   电路通（三个都闭合，即都不断开）：$\bar{A}_1\bar{A}_2\bar{A}_3 = \overline{A_1\cup A_2\cup A_3}$。

7. （1）$A\bar{B}\cup\bar{A}B$；
   （2）$A\cup B$；
   （3）$\bar{A}\bar{B}$；
   （4）题干"目标被命中但只有一发命中"即恰有一人命中：$A\bar{B}\cup\bar{A}B$（与（1）相同；若理解为"目标被命中"，则至少一发，二者在本情境下一致）。
:::
